## Usage

A List lays out rows that share a shape: something to recognize, a title, a line of detail and what you can do with it. It is layout only, with no selection, activation or keyboard model of its own, so the controls in a row's `actions` slot keep their own focus and behavior and one row can hold several independent actions. Name every List with `aria-label`; it is announced as a list of that many items. A List item also works on its own, outside a List.

    <tp-button slot="actions" size="sm">Upgrade</tp-button>

/>

The default slot is the title and `description` the line under it; the `title` and `description` slots take over when either needs markup. Empty regions collapse, so a row with only a title needs nothing extra.

### Recent files

<Preview
  code={`<tp-list id="list-files" aria-label="Recent files" style="max-inline-size:30rem">
  <tp-list-item media-treatment="icon" description="Edited by Maya, 12 minutes ago">

  </tp-list-item>
  <tp-list-item media-treatment="icon" description="14 files, shared with Design">
    <tp-icon slot="media" data-icon="folder"></tp-icon>
    Brand assets
  </tp-list-item>
  <tp-list-item media-treatment="icon" description="New sign-in from an unknown device.">
    <tp-icon slot="media" data-icon="alert"></tp-icon>
    Security alert
    <tp-button slot="actions" variant="outline" size="sm">Review</tp-button>
  </tp-list-item>
</tp-list>`}
  script={`import { fileTextIcon } from '@tweakpad/ui/icons/file-text';
import { folderIcon } from '@tweakpad/ui/icons/folder';
import { shieldAlertIcon } from '@tweakpad/ui/icons/shield-alert';

/>

The `media` slot takes an Icon, an Avatar or an image, and `media-treatment` tells the row which, so the media gets the matching extent. With a description, the media lines up with the first line of text.

### Help links

<Preview
  code={`<tp-list id="list-links" aria-label="Help resources" style="max-inline-size:30rem">
  <tp-list-item variant="outline" data-href="#help-links" description="Set up your workspace in ten minutes.">
    Getting started guide
    <tp-icon slot="actions" data-icon="chevron"></tp-icon>
  </tp-list-item>
  <tp-list-item variant="outline" data-href="#help-links" description="Invoices, seats and tax settings.">
    Billing questions
    <tp-button slot="actions" variant="outline" size="sm">Contact sales</tp-button>
  </tp-list-item>
  <tp-list-item variant="outline" data-href="https://status.example.com/" data-external description="Opens the status page in a new tab.">
    System status
    <tp-icon slot="actions" data-icon="external"></tp-icon>
  </tp-list-item>
</tp-list>`}
  script={`import { html } from 'lit';
import { chevronRightIcon } from '@tweakpad/ui/icons/chevron-right';
import { externalLinkIcon } from '@tweakpad/ui/icons/external-link';

const icons = { chevron: chevronRightIcon, external: externalLinkIcon };
for (const item of document.querySelectorAll('#list-links tp-list-item')) {
  const external = item.hasAttribute('data-external');
  item.partContracts = {
    'list-item': {
      renderDelegate: ({ bind, content }) => html\`<a href=\${item.dataset.href} target=\${external ? '_blank' : '_self'} rel=\${external ? 'noopener noreferrer' : ''} \${bind}>\${content}</a>\`,
    },
  };
}
for (const icon of document.querySelectorAll('#list-links tp-icon')) icon.icon = icons[icon.dataset.icon];`}
/>

A whole row becomes a native link when the `list-item` part's render delegate draws an anchor around the supplied `bind` and `content`. The actions render beside the link, so a Button there is a separate tab stop and never follows the link; a decorative Icon there lets clicks reach the link.

For a rich command, put a List item directly inside a Menu item. The Menu item keeps the command semantics, the keyboard navigation and the highlight, and the row drops its own padding; the smallest size keeps the menu compact.

### Variants

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-3);max-inline-size:30rem">
  <tp-list-item variant="ghost" description="No boundary, for rows on a shared surface.">Ghost</tp-list-item>
  <tp-list-item variant="outline" description="A boundary around each row.">Outline</tp-list-item>
  <tp-list-item variant="subdued" description="A muted fill behind each row.">Subdued</tp-list-item>
</div>`}
/>

`variant` is visual treatment only: `ghost` for rows divided by separators or a surrounding surface, `outline` for rows that stand apart, `subdued` for rows that need a quiet fill.
