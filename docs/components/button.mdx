## Usage

A Button performs one action or follows one link. Its label names the action as a verb, "Save changes" rather than "OK", and an area has one default Button for its main action. A Button owns no selection, open or pending state; an on and off state belongs to a Toggle, and something that opens belongs to a disclosure component.

### Submitting a form

<Preview
  align="stretch"
  code={`<tp-form id="button-post" aria-label="New post" style="max-inline-size:28rem">
  <tp-field label="Title">
    <tp-input name="title" required value="Release notes for 2.4"></tp-input>
  </tp-field>
  <div slot="actions">
    <tp-button type="reset" variant="ghost">Reset</tp-button>
    <tp-button type="submit" name="intent" value="draft" variant="outline">Save draft</tp-button>
    <tp-button type="submit" name="intent" value="publish">Publish</tp-button>
  </div>
  <output id="button-post-result" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)"></output>
</tp-form>`}
  script={`const form = document.getElementById('button-post');
const result = document.getElementById('button-post-result');
form.onFormSubmit = (values, { data }) => {
  result.textContent = 'Submitted with intent: ' + data.get('intent');
};
form.addEventListener('tp-reset', () => {
  result.textContent = '';
});`}
/>

A Button submits only with `type="submit"`, so one placed in a form never sends it by accident. Two submit Buttons that share a `name` tell the receiving code which action the person chose, and `type="reset"` restores the initial values.

### Long-running action

<Preview
  code={`<tp-button id="button-save">Save changes</tp-button>`}
  script={`const button = document.getElementById('button-save');
button.addEventListener('click', () => {
  button.loadingPosition = 'leading';
  button.disabled = true;
  button.focusableWhenDisabled = true;
  setTimeout(() => {
    button.loadingPosition = null;
    button.disabled = false;
  }, 2000);
});`}
/>

`loading-position` draws a Spinner beside the label and marks the Button busy, but leaves it enabled. Disable it as well when a second press must not start the work again, and keep it focusable while disabled so focus stays on the Button instead of falling back to the page.

### Editor toolbar

<Preview
  code={`<div style="display:flex;align-items:center;gap:var(--tp-space-1)">
  <tp-button id="button-bold" size="icon-sm" variant="ghost">Bold</tp-button>
  <tp-button id="button-italic" size="icon-sm" variant="ghost">Italic</tp-button>
  <tp-button size="sm" variant="ghost" aria-label="Text color">
    <tp-icon id="button-color" slot="icon-start"></tp-icon>
    <tp-icon id="button-color-chevron" slot="icon-end"></tp-icon>
  </tp-button>
</div>`}
  script={`import { boldIcon, italicIcon, baselineIcon } from '@tweakpad/ui/icons/text-formatting';
import { chevronDownIcon } from '@tweakpad/ui/icons/chevron-down';

document.getElementById('button-bold').icon = boldIcon;
document.getElementById('button-italic').icon = italicIcon;
document.getElementById('button-color').icon = baselineIcon;
document.getElementById('button-color-chevron').icon = chevronDownIcon;`}
/>

In an icon size only the mark shows. The label stays in the content, hidden visually, and names the Button, so write the action as the label instead of adding `aria-label`. Each icon size is a square as tall as the matching text size, so `icon-sm` lines up with `sm` in the same row. A text-size Button with an empty label shows only its marks, here a color and a chevron; nothing visible names it, so it takes an `aria-label`.

### Links and downloads

<Preview
  code={`<tp-button href="#links-and-downloads">Read the guide</tp-button>
<tp-button variant="outline" href="data:text/csv;charset=utf-8,Month%2CRevenue%0AJanuary%2C1200" download="report.csv">
  <tp-icon id="button-download" slot="icon-start"></tp-icon>
  Download report
</tp-button>`}
  script={`import { downloadIcon } from '@tweakpad/ui/icons/download';

document.getElementById('button-download').icon = downloadIcon;`}
/>

With `href` the Button renders a native link: it opens in a new tab on request, offers its address to copy and is announced as a link, while it keeps its visual treatment. The `link` treatment alone changes only the look, for an action that should read as text; anything that goes somewhere takes `href`.

### Variants

<Preview
  code={`<tp-button>Default</tp-button>
<tp-button variant="secondary">Secondary</tp-button>
<tp-button variant="destructive">Destructive</tp-button>
<tp-button variant="outline">Outline</tp-button>
<tp-button variant="ghost">Ghost</tp-button>
<tp-button variant="link">Link</tp-button>`}
/>

`variant` is visual emphasis only: the default for the main action, `destructive` for an action that deletes or cannot be undone, `secondary` and `outline` for the alternatives beside it, `ghost` for repeated actions in toolbars and rows, and `link` for an action inside text.
