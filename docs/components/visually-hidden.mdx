## Usage

Visually hidden keeps text in the accessibility tree while hiding it on screen: screen readers read it like any other content, and sighted readers never see it. Use it for what the layout already tells a sighted reader and the words alone do not. Never put focusable or interactive content inside, since a focused element that cannot be seen leaves keyboard users lost; the element reports a diagnostic when it finds one. It never appears on focus, so it is not a skip link. The `hidden` attribute withdraws the text from assistive technology too, and nothing inside an `aria-hidden` ancestor is read at all.

### Names for icon-only toggles

<Preview
  code={`<tp-toggle-group id="visually-hidden-align" label="Text alignment" spacing="0" variant="outline" default-value='["start"]'>
  <tp-toggle value="start"><tp-icon data-icon="start"></tp-icon><tp-visually-hidden>Align left</tp-visually-hidden></tp-toggle>
  <tp-toggle value="center"><tp-icon data-icon="center"></tp-icon><tp-visually-hidden>Align center</tp-visually-hidden></tp-toggle>
  <tp-toggle value="end"><tp-icon data-icon="end"></tp-icon><tp-visually-hidden>Align right</tp-visually-hidden></tp-toggle>
</tp-toggle-group>`}
  script={`import { textAlignLeftIcon, textAlignCenterIcon, textAlignRightIcon } from '@tweakpad/ui/icons/text-align';

const icons = { start: textAlignLeftIcon, center: textAlignCenterIcon, end: textAlignRightIcon };
for (const icon of document.querySelectorAll('#visually-hidden-align tp-icon')) icon.icon = icons[icon.dataset.icon];`}
/>

The name sits beside the icon, inside the control, and becomes its accessible name exactly as visible text would. An icon-only Button needs no Visually hidden element: in an icon size its label is already hidden, so write the name as the label.

### Announcing filter results

<Preview
  code={`<div id="visually-hidden-filter" style="display:grid;gap:var(--tp-space-3);inline-size:24rem;max-inline-size:100%">
  <tp-field label="Filter members">
    <tp-input type="search" placeholder="Name or role"></tp-input>
  </tp-field>
  <tp-list aria-label="Members">
    <tp-list-item description="Owner">Maya Chen</tp-list-item>
    <tp-list-item description="Designer">Jonas Weber</tp-list-item>
    <tp-list-item description="Engineer">Amara Okafor</tp-list-item>
    <tp-list-item description="Engineer">Priya Natarajan</tp-list-item>
  </tp-list>
  <tp-visually-hidden role="status"></tp-visually-hidden>
</div>`}
  script={`const root = document.getElementById('visually-hidden-filter');
const status = root.querySelector('tp-visually-hidden');
const items = [...root.querySelectorAll('tp-list-item')];
root.querySelector('tp-input').addEventListener('tp-value-change', (event) => {
  const query = String(event.detail.value ?? '').trim().toLowerCase();
  const matches = items.filter((item) => {
    const shown = item.textContent.toLowerCase().includes(query) || (item.getAttribute('description') ?? '').toLowerCase().includes(query);
    item.hidden = !shown;
    return shown;
  });
  status.textContent = query ? matches.length + ' of ' + items.length + ' members match.' : 'All ' + items.length + ' members shown.';
});`}
/>

A sighted reader sees the list shrink while typing; a status in Visually hidden says the same out loud. Keep the element in the page from the start and change only its text, since a region that appears together with its message is often not announced.
