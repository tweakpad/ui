## Usage

Use a Carousel when a set of peers deserves the same prominent spot but only one, or a few, fit at a time: release highlights, testimonials, a row of related items. Each child is one slide. The previous and next buttons, arrow keys, swipe and the indicators all move the same selection, and the current position is announced politely. Give every Carousel a `label` and size it through CSS. Content people must not miss belongs in a list they can read in full, not behind navigation.

Layout, navigation and indicator settings live in `options`. A fractional number of slides in view lets the next card peek in, a cue that the row continues, and moving two at a time keeps steps in proportion to what is shown.

`loop` lets navigation wrap past either end, and `autoplay` advances on an interval with a pause button in front of the slides; hover, focus, reduced motion and hidden tabs pause it on their own. Use autoplay sparingly: moving content is hard to read and easy to miss, so keep it for repeated or decorative content, never the only path to information.

By default the track slides. The `effect` property swaps in a richer transition built by a factory you import, so pages without one bundle none. The crossfade fades between slides and reveals their text in order; the layered effect turns the outgoing photo away in perspective and raises the next caption line by line; the focus effect dims and shrinks the slides away from the center, which suits a row of destinations or products. A parallax effect and a shader transition are available the same way. Every effect follows a drag, plays backwards when navigation reverses and respects reduced motion.

### A long archive from data

<Preview
  align="stretch"
  code={`<div style="display:grid;gap:var(--tp-space-3);max-inline-size:36rem">
  <div id="carousel-archive"></div>
  <span id="carousel-archive-status" style="font-size:var(--tp-text-sm);color:var(--tp-muted-foreground)">Showing invoices 1–2 of 200</span>
</div>`}
  script={`import { html } from 'lit';

// Data and controlled selection are set before the carousel initializes, so it is configured before it connects.
const carousel = document.createElement('tp-carousel');
carousel.label = 'Invoice archive';
const status = document.getElementById('carousel-archive-status');
carousel.items = Array.from({ length: 200 }, (_, index) => ({
  id: 'INV-' + String(3001 + index),
  amount: 180 + ((index * 37) % 900),
}));
carousel.renderItem = (invoice) => html\`
  <tp-card size="sm">
    <h3 slot="header">\${invoice.id}</h3>
    <span slot="description">$\${invoice.amount.toLocaleString('en-US')}.00 · Paid</span>
  </tp-card>\`;
carousel.options = { layout: { itemsPerView: 2, gap: 12 }, virtual: {} };
carousel.value = 0;
carousel.addEventListener('tp-value-change', (event) => {
  carousel.value = event.detail.value;
});
carousel.addEventListener('tp-value-commit', () => {
  status.textContent = 'Showing invoices ' + (carousel.index + 1) + '–' + (carousel.index + 2) + ' of 200';
});
document.getElementById('carousel-archive').append(carousel);`}
/>

With `items` and `renderItem` the slides come from data instead of children, and virtualization keeps only the slides near the viewport in the document, so a long archive stays light. Setting `value` makes the selection controlled: each proposal waits for your listener to publish it, which is where a router or a store steps in.

When something outside the Carousel follows its position, such as a step counter or a matching detail panel, listen for `tp-value-commit`, which fires once a move is accepted, and read `index`. For finer control, the `controller` drives navigation and autoplay from code.

## Keyboard

| Key | Action |
| --- | --- |
| <Keys keys="left" /> <Keys keys="right" /> | Previous or next slide in a horizontal carousel, following the writing direction |
| <Keys keys="up" /> <Keys keys="down" /> | Previous or next slide in a vertical carousel |
| <Keys keys="home" /> <Keys keys="end" /> | First or last slide |

Keys a control inside a slide owns, such as those of a text field or a slider, stay with that control.
