## Usage

The default slot is the Checkbox's inline label, and clicking it toggles the box. Pointer and Space toggle; Enter does not, so a Checkbox never fights a form's submit key. Native HTML labels activate this same Boolean owner: use a wrapping label or a `for` matching the Checkbox host's `id`.

### With a Field

Put a Checkbox in `tp-field` when it needs a description or error. The Field supplies the accessible name and shows validation for `required`, which is satisfied only when checked.

<Preview
  title="Field"
  align="stretch"
  code={`<tp-field label="Email me product updates" description="About one email a month. Unsubscribe anytime." style="max-inline-size:22rem;margin-inline:auto">
  <tp-checkbox name="updates" value="monthly"></tp-checkbox>
</tp-field>`}
/>

### Forms

A checked box submits `name=value` (`value` defaults to `on`). An unchecked box submits nothing unless you set `unchecked-value`, which helps when the server expects an explicit off value. Reset restores `default-checked`. Native reset restores the latest uncontrolled default with `form-reset`; controlled reset does not change or notify the owner.

<Preview
  title="Form values"
  align="stretch"
  code={`<form id="checkbox-form" style="display:grid;gap:var(--tp-space-3);max-inline-size:22rem;margin-inline:auto">
  <tp-checkbox name="notifications" value="email" default-checked>Email</tp-checkbox>
  <tp-checkbox name="notifications" value="push">Push</tp-checkbox>
  <tp-checkbox name="digest" value="weekly" unchecked-value="off">Weekly digest</tp-checkbox>
  <div style="display:flex;gap:var(--tp-space-2)">
    <tp-button type="submit" size="sm">Save</tp-button>
    <tp-button type="reset" size="sm" variant="outline">Reset</tp-button>
  </div>
  <output id="checkbox-form-output" style="font-size:var(--tp-text-sm);color:var(--tp-muted-foreground)">Submit to see the form data.</output>
</form>`}
  script={`const form = document.getElementById('checkbox-form');
form.addEventListener('submit', (event) => {
  event.preventDefault();
  const entries = [...new FormData(form)].map(([key, value]) => key + '=' + value);
  document.getElementById('checkbox-form-output').textContent = entries.join('  ·  ') || 'Nothing submitted';
});`}
/>

### Mixed state

`indeterminate` shows a mixed indicator, typically on a "select all" box whose children are partly checked. A press always proposes checked, and your code clears the mixed state, because only it knows what the children hold.

<Preview
  title="Select all"
  align="stretch"
  code={`<fieldset id="checkbox-mixed" style="display:grid;gap:var(--tp-space-3);margin:0 auto;padding:0;border:0;max-inline-size:22rem">
  <legend style="padding:0;margin-block-end:var(--tp-space-3);font-weight:var(--tp-font-medium)">Export columns</legend>
  <tp-checkbox id="checkbox-mixed-all" indeterminate>All columns</tp-checkbox>
  <div style="display:grid;gap:var(--tp-space-3);padding-inline-start:var(--tp-space-6)">
    <tp-checkbox name="columns" value="name" default-checked>Customer name</tp-checkbox>
    <tp-checkbox name="columns" value="email" default-checked>Email</tp-checkbox>
    <tp-checkbox name="columns" value="plan">Plan</tp-checkbox>
    <tp-checkbox name="columns" value="mrr">Monthly revenue</tp-checkbox>
  </div>
</fieldset>`}
  script={`await customElements.whenDefined('tp-checkbox');
const all = document.getElementById('checkbox-mixed-all');
const items = [...document.querySelectorAll('#checkbox-mixed [name="columns"]')];
let syncing = false;
const sync = () => {
  const count = items.filter((item) => item.checked).length;
  syncing = true;
  all.indeterminate = count > 0 && count < items.length;
  all.setChecked(count === items.length);
  syncing = false;
};
all.addEventListener('tp-value-change', (event) => {
  if (syncing) return;
  const next = event.detail.value;
  syncing = true;
  for (const item of items) item.setChecked(next);
  all.indeterminate = false;
  syncing = false;
});
for (const item of items) {
  item.addEventListener('tp-value-change', () => {
    if (!syncing) queueMicrotask(sync);
  });
}`}
/>

The mixed state is presentation only: the parent's submitted value stays a plain Boolean.

### Group controller

<Preview
  title="CheckboxGroupController"
  align="stretch"
  code={`<fieldset id="checkbox-group" style="display:grid;gap:var(--tp-space-3);margin:0 auto;padding:0;border:0;max-inline-size:22rem">
  <legend style="padding:0;margin-block-end:var(--tp-space-3);font-weight:var(--tp-font-medium)">Notify me about new comments</legend>
  <tp-checkbox parent>All channels</tp-checkbox>
  <div style="display:grid;gap:var(--tp-space-3);padding-inline-start:var(--tp-space-6)">
    <tp-checkbox name="channels" value="email">Email</tp-checkbox>
    <tp-checkbox name="channels" value="push">Push notifications</tp-checkbox>
    <tp-checkbox name="channels" value="slack">Slack</tp-checkbox>
    <tp-checkbox name="channels" value="sms" disabled>SMS (add a phone number first)</tp-checkbox>
  </div>
  <output style="font-size:var(--tp-text-sm);color:var(--tp-muted-foreground)">Channels: email</output>
</fieldset>`}
  script={`import { CheckboxGroupController } from '@tweakpad/ui';

await customElements.whenDefined('tp-checkbox');
const fieldset = document.getElementById('checkbox-group');
const output = fieldset.querySelector('output');
const group = new CheckboxGroupController(fieldset, {
  defaultValue: ['email'],
  allValues: ['email', 'push', 'slack', 'sms'],
});
group.onValueChange = (event) => {
  output.textContent = 'Channels: ' + (event.detail.value.join(', ') || 'none');
};`}
/>

For a plain list with a "select all" box, `CheckboxGroupController` does the bookkeeping above for you. Bind it to an authored `fieldset` that holds a `parent` checkbox and valued children; it shows the parent as checked or mixed, checks or clears every enabled child when the parent is pressed, and keeps the group's value as a list. Each child still submits under its own `name`. Call `group.disconnect()` when the fieldset is removed. Options and writable properties are `value` (controlled string list), `defaultValue` (empty), `allValues`, `disabled` (false), and `onValueChange`. `setValue(list, reason?, event?)`, `reset(event?)`, `refresh()`, and `disconnect()` are public. `allValues` reports registered child values when omitted; parent aggregation is activated only by explicitly supplying it.

### States

<Preview
  title="Disabled and read-only"

Disabled boxes leave the tab order and omit their value from form data. Read-only boxes stay focusable and submit their value, but ignore presses.

### Controlled

Set `checked` before first render to own the state. Each press then emits a cancelable `tp-value-change`; assign `checked` from `event.detail.value` to accept it, or leave it unchanged to reject it.

<Code code={`checkbox.checked = false;
checkbox.onCheckedChange = (event) => {
  checkbox.checked = event.detail.value;
};`} language="typescript" />

### Inline

<Preview
  title="Inline"
  align="stretch"
  code={`<div style="display:grid;gap:var(--tp-space-2);max-inline-size:22rem;margin-inline:auto">
  <tp-checkbox variant="inline" name="reminders" default-checked>Event reminders</tp-checkbox>
  <tp-checkbox variant="inline" name="digest">Weekly digest</tp-checkbox>
  <tp-select variant="inline" label="Reminder time" name="reminder-time" default-value="15">
    <option value="5">5 minutes before</option>
    <option value="15">15 minutes before</option>
    <option value="60">1 hour before</option>
  </tp-select>
</div>`}
/>

`variant="inline"` fits the Checkbox into one row the height of a control, with its label at the start and the box at the end, so it stacks with other inline controls such as an inline Select. A press anywhere on the row toggles it. Inside a Field and without a label of its own, the Field's label moves into the row.
