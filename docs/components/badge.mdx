## Usage

A Badge is a non-focusable label, so it never adds a tab stop. Its text should carry the meaning on its own: "Failed" says more than a red pill. Write counts with their noun, like "12 unread", rather than a bare number, unless the surrounding text supplies it.

    <span>Website redesign</span>

  <div style="display:flex;align-items:center;justify-content:space-between;gap:var(--tp-space-3)">

  </div>
  <div style="display:flex;align-items:center;justify-content:space-between;gap:var(--tp-space-3)">
    <span>Billing migration</span>
    <tp-badge variant="destructive">Blocked</tp-badge>
  </div>
  <div style="display:flex;align-items:center;justify-content:space-between;gap:var(--tp-space-3)">
    <span>Q3 roadmap</span>
    <tp-badge variant="outline">Draft</tp-badge>
  </div>
</div>`}
/>

One badge per row names the row's state. The default variant marks the one thing to notice; neutral states take `secondary` or `outline`, and a blocking problem takes `destructive`.

### Marks and progress

  title="With marks"

  Payment failed
</tp-badge>`}
  script={`import { checkIcon } from '@tweakpad/ui/icons/check';
import { circleAlertIcon } from '@tweakpad/ui/icons/circle-alert';

document.getElementById('badge-verified-icon').icon = checkIcon;
document.getElementById('badge-failed-icon').icon = circleAlertIcon;`}
/>

The label takes text plus an inline mark: an Icon or a Spinner. Keep the mark decorative (an Icon without a label, a Spinner with `label=""`) when the text already says what it means. Badge does not announce changes; put a badge whose state matters to assistive technology in a live region the application owns.

### Counts in buttons

<Preview
  title="Counts in buttons"
  code={`<tp-button variant="outline">Inbox <tp-badge variant="secondary">8</tp-badge></tp-button>
<tp-button variant="ghost">Pull requests <tp-badge variant="outline">3 open</tp-badge></tp-button>`}
/>

A badge inside a Button or link stays passive, so the composition keeps one interactive target: the button owns the action and its accessible name includes the count. A bare number is fine here because the button text supplies the noun.

### Filter chips

<Preview
  title="Interactive badges"
  code={`<div id="badge-filters" style="display:flex;flex-wrap:wrap;align-items:center;gap:var(--tp-space-4);padding-block:var(--tp-space-2)">
  <tp-badge interactive variant="secondary" data-filter="open">Open · 12</tp-badge>
  <tp-badge interactive variant="outline" data-filter="mine">Assigned to me · 4</tp-badge>
  <tp-badge interactive variant="outline" data-filter="archived" disabled>Archived · 0</tp-badge>
  <tp-badge interactive variant="link" data-link>Release notes</tp-badge>
</div>`}
  script={`import { html } from 'lit';

await customElements.whenDefined('tp-badge');
const asButton = {
  badge: {
    renderDelegate: ({ state, bind, content }) =>
      html\`<button type="button" ?disabled=\${state.disabled} \${bind}>\${content}</button>\`,
  },
};
const asLink = {
  badge: {
    renderDelegate: ({ bind, content }) => html\`<a href="#filter-chips" \${bind}>\${content}</a>\`,
  },
};
for (const badge of document.querySelectorAll('#badge-filters tp-badge')) {
  badge.partContracts = badge.hasAttribute('data-link') ? asLink : asButton;
  if (badge.dataset.filter) {
    badge.addEventListener('click', () => {
      badge.variant = badge.variant === 'secondary' ? 'outline' : 'secondary';
    });
  }
}`}
/>

`interactive` declares that a badge acts, and the `badge` part contract supplies the native element that does: a button for a filter chip, a link for navigation. Keep `bind` on that element and render `content` inside it, so the pill keeps its part, its slot and its appearance. The pill keeps its size while its pointer target grows to the minimum, so leave room between interactive badges. The `link` variant alone never navigates; for a full action, form or loading behavior, use Button.

### Variants

<Preview
  title="Variants"
  code={`<tp-badge>Default</tp-badge>

<tp-badge variant="success">Success</tp-badge>

<tp-badge variant="ghost">Ghost</tp-badge>
<tp-badge variant="link">Link</tp-badge>`}
/>

`variant` is visual emphasis only. Use `destructive` for failures and blocking problems, `success` and `warning` for healthy and degraded states, `secondary` or `outline` for neutral metadata, and the default for the one thing you want noticed.
