});`}
/>

## Usage

Put the opening control in the `trigger` slot and the two decisions in the `cancel` and `confirm` slots; `label` and `description` are the visible title and the consequence. An Alert dialog interrupts on purpose: an outside press never closes it, and it has no corner Close button, so the reader answers with Cancel, Confirm or Escape. Keep it for decisions with consequences; a task with fields belongs in a Dialog.

Cancel closes on its own. Confirm only supplies the button: its handler does the work and then closes the dialog with `setOpen(false, 'close-action', event)`.

### Revoking an API key

<Preview
  code={`<tp-alert-dialog
  id="alert-dialog-revoke"
  label="Revoke API key?"
  description="Integrations using the key ending in 4f2a will stop working immediately."
>
  <tp-button slot="trigger" variant="outline">Revoke key</tp-button>
  <tp-button slot="cancel" variant="outline" id="alert-dialog-revoke-cancel">Cancel</tp-button>
  <tp-button slot="confirm" variant="destructive" id="alert-dialog-revoke-confirm">Revoke key</tp-button>
</tp-alert-dialog>`}
  script={`const dialog = document.getElementById('alert-dialog-revoke');
const cancel = document.getElementById('alert-dialog-revoke-cancel');
const confirm = document.getElementById('alert-dialog-revoke-confirm');
confirm.addEventListener('click', async (event) => {
  cancel.disabled = true;
  confirm.loadingPosition = 'leading';
  await new Promise((resolve) => setTimeout(resolve, 1200));
  cancel.disabled = false;
  confirm.loadingPosition = null;
  dialog.setOpen(false, 'close-action', event);
});`}
/>

When the work takes a moment, keep the dialog open: Confirm shows its progress and Cancel waits until the request settles. If the request fails, put the error in the dialog instead of closing it.

### Leaving with unsaved changes

<Preview
  code={`<tp-alert-dialog id="alert-dialog-discard" label="Leave without saving?">
  <tp-button slot="trigger" variant="outline">Close editor</tp-button>
  <tp-icon slot="media" id="alert-dialog-discard-icon"></tp-icon>
  <p slot="description">You have unsaved changes to <strong>Onboarding checklist</strong>. They will be lost if you leave now.</p>
  <tp-button slot="cancel" variant="outline">Keep editing</tp-button>
  <tp-button slot="confirm" id="alert-dialog-discard-confirm">Discard changes</tp-button>
</tp-alert-dialog>`}
  script={`import { triangleAlertIcon } from '@tweakpad/ui/icons/triangle-alert';

document.getElementById('alert-dialog-discard-icon').icon = triangleAlertIcon;
const dialog = document.getElementById('alert-dialog-discard');
document.getElementById('alert-dialog-discard-confirm').addEventListener('click', (event) => {
  dialog.setOpen(false, 'close-action', event);
});`}
/>

The `title`, `description` and `media` slots take rich content when the attributes are not enough, here an Icon that marks a warning and the name of the document at stake. Label both actions with their outcome, such as "Keep editing" and "Discard changes", rather than "OK".

### Publishing changes

<Preview
  code={`<tp-alert-dialog
  id="alert-dialog-publish"
  initial-focus="confirm"
  label="Publish changes?"
  description="Your edits to Pricing will be visible to everyone with the link."
>
  <tp-button slot="trigger">Publish</tp-button>
  <tp-button slot="cancel" variant="outline">Not yet</tp-button>
  <tp-button slot="confirm" id="alert-dialog-publish-confirm">Publish</tp-button>
</tp-alert-dialog>`}
  script={`const dialog = document.getElementById('alert-dialog-publish');
document.getElementById('alert-dialog-publish-confirm').addEventListener('click', (event) => {
  dialog.setOpen(false, 'close-action', event);
});`}
/>

Opening focuses Cancel, so a stray Enter never confirms a destructive action. For a safe, expected confirmation like publishing, `initial-focus="confirm"` puts the reader one key away from the outcome they came for.

## Keyboard

| Key | Action |
| --- | --- |
| <Keys keys="esc" /> | Cancels and closes the dialog. |
| <Keys keys="tab" /> <Keys keys="shift+tab" /> | Moves focus between the dialog's controls, wrapping inside it. |
