## Usage

Every page, Previous and Next target is a real link, so pages can be opened in a new tab, crawled and shared. The current page belongs to the application: Pagination renders the window around the `page` you give it, keeping the first and last pages and collapsing the rest into ellipses, and never moves to another page on its own.

### Client-side routing

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-3);justify-items:start">
  <tp-pagination id="pagination-routed" label="Invoices" page="1" pages="5"></tp-pagination>
  <output id="pagination-routed-output" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Showing invoices 1–20 of 96</output>
</div>`}
  script={`const pagination = document.getElementById('pagination-routed');
const output = document.getElementById('pagination-routed-output');
pagination.addEventListener('tp-value-change', (event) => {
  event.detail.sourceEvent?.preventDefault();
  const page = event.detail.value;
  pagination.page = page;
  const first = (page - 1) * 20 + 1;
  output.textContent = \`Showing invoices \${first}–\${Math.min(page * 20, 96)} of 96\`;
});`}
/>

Each link points at the current URL with its `page` query parameter replaced. A client router listens for `tp-value-change`, prevents the original click and sets `page` itself; clicks with a modifier key keep opening a new tab or window. When the routes use paths, such as `/invoices/page/3`, `hrefForPage` builds each link's destination.

### Rows per page

<Preview
  align="stretch"
  code={`<div id="pagination-rows" style="display:flex;align-items:center;justify-content:space-between;gap:var(--tp-space-4);flex-wrap:wrap">
  <tp-field label="Rows per page" orientation="horizontal">
    <tp-select default-value="25">
      <option value="10">10</option>
      <option value="25">25</option>
      <option value="50">50</option>
      <option value="100">100</option>
    </tp-select>
  </tp-field>
  <output style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">1–25 of 340 orders</output>
  <tp-pagination label="Orders" page="1" pages="14"></tp-pagination>
</div>`}
  script={`await customElements.whenDefined('tp-pagination');
const root = document.getElementById('pagination-rows');
const pagination = root.querySelector('tp-pagination');
const rows = root.querySelector('tp-select');
const output = root.querySelector('output');
const total = 340;
let size = 25;
const report = () => {
  const first = (pagination.page - 1) * size + 1;
  output.textContent = \`\${first}–\${Math.min(pagination.page * size, total)} of \${total} orders\`;
};
pagination.showPageLinks = false;
pagination.addEventListener('tp-value-change', (event) => {
  event.detail.sourceEvent?.preventDefault();
  pagination.page = event.detail.value;
  report();
});
rows.addEventListener('tp-value-change', (event) => {
  if (event.defaultPrevented || event.detail.cancelled) return;
  size = Number(event.detail.value);
  pagination.pages = Math.ceil(total / size);
  pagination.page = 1;
  report();
});`}
/>

Pagination knows nothing about page size. A Select beside it sets the size; the application recomputes `pages` and sends the reader back to page 1.
