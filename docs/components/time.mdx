## Usage

Use Time wherever a date is displayed: an activity feed, a table column, a message header. Set `datetime` to a `Date`, an epoch number or ISO text; without it the element reads its own text. A value keeps the precision it was written with, and the native time element always carries the machine-readable value. Relative text refreshes on one shared timer when it can next change, and hovering or focusing a value shows the full date and time. By default a value within 30 days is relative and an older one absolute.

### Due dates in a task list

<Preview
  align="stretch"
  code={`<tp-list id="time-due" aria-label="Your tasks" style="max-inline-size:28rem">
  <tp-list-item description="Maya Chen">Design review<span slot="footer">Due <tp-time data-days="0"></tp-time></span></tp-list-item>
  <tp-list-separator></tp-list-separator>
  <tp-list-item description="Jonas Weber">Release notes<span slot="footer">Due <tp-time data-days="3"></tp-time></span></tp-list-item>
  <tp-list-separator></tp-list-separator>
  <tp-list-item description="Priya Patel">Vendor contract<span slot="footer" style="color:var(--tp-destructive)">Due <tp-time data-days="-1"></tp-time></span></tp-list-item>
</tp-list>`}
  script={`const pad = (value) => String(value).padStart(2, '0');
for (const time of document.querySelectorAll('#time-due tp-time')) {
  const date = new Date(Date.now() + Number(time.dataset.days) * 86400000);
  time.datetime = \`\${date.getFullYear()}-\${pad(date.getMonth() + 1)}-\${pad(date.getDate())}\`;
}`}
/>

A date without a time stays on its calendar day in every time zone, never midnight UTC, and relative text compares whole days: "today", "in 3 days", "yesterday".

Calendar text names nearby days, "Today at 09:12" or "Last Friday at 16:40", which reads better than "26 hours ago" for events people place by day; beyond a week it is an absolute date. Month and weekday names come from the locale, and the phrases around them from `messages`, so they can be translated or reworded.

### Publication and invoice dates

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-2);font-size:var(--tp-text-sm)">
  <span>Published <tp-time mode="absolute" preset="date-long" datetime="2026-10-05T14:30:00Z" tooltip-pattern="EEEE HH:mm xxx"></tp-time></span>
  <span>Invoice due <tp-time mode="absolute" preset="date-medium" datetime="2026-11-01"></tp-time></span>
  <span>Export file <tp-time mode="absolute" pattern="yyyy-MM-dd'T'HH-mm" datetime="2026-10-05T14:30:00Z" time-zone="UTC"></tp-time></span>
</div>`}
/>

A preset names a locale-aware format; a pattern gives an exact layout in Unicode date-field symbols, with literal words quoted. Write `yyyy-MM-dd`, not `YYYY-MM-DD`: letters Time does not support render literally and raise a diagnostic instead of silently formatting a different year. The tooltip is skipped where it would repeat the visible text.

### Meetings across time zones

<Preview
  code={`<span style="font-size:var(--tp-text-sm)">Standup: <tp-time mode="absolute" preset="time" datetime="2026-10-12T09:30:00Z" time-zone="America/New_York"></tp-time> New York · <tp-time mode="absolute" preset="time" datetime="2026-10-12T09:30:00Z" time-zone="Europe/Berlin" hour-cycle="h23"></tp-time> Berlin</span>`}
/>

Instants format in the reader's own time zone unless `time-zone` names one, and `hour-cycle` forces a 12- or 24-hour clock where the audience expects it.

### Timers and countdowns

<Preview
  code={`<dl id="time-timers" style="display:grid;grid-template-columns:auto auto;gap:var(--tp-space-2) var(--tp-space-6);margin:0;font-size:var(--tp-text-sm)">
  <dt style="color:var(--tp-muted-foreground)">On call for</dt><dd style="margin:0"><tp-time mode="duration" data-offset="-754"></tp-time></dd>
  <dt style="color:var(--tp-muted-foreground)">Sale ends in</dt><dd style="margin:0"><tp-time mode="duration" precision="minute" data-offset="9000"></tp-time></dd>
  <dt style="color:var(--tp-muted-foreground)">Average response</dt><dd style="margin:0"><tp-time datetime="PT2H15M"></tp-time></dd>
  <dt style="color:var(--tp-muted-foreground)">Last heartbeat</dt><dd style="margin:0"><tp-time tense="past" data-offset="3"></tp-time></dd>
</dl>`}
  script={`for (const time of document.querySelectorAll('#time-timers tp-time[data-offset]')) {
  time.datetime = new Date(Date.now() + Number(time.dataset.offset) * 1000);
}`}
/>

The duration mode on an instant shows a ticking length of time until or since it, such as a call timer or a countdown; `precision` sets the smallest unit shown, which also slows the updates. A duration value such as `PT2H15M` shows as a length on its own. `tense="past"` shows an instant slightly in the future, from a server clock running ahead, as "now" rather than "in 3 seconds".

A shorter `relative-style` fits a narrow table column, and assistive technology still hears the long form. `numeric="always"` writes "1 day ago" where the locale would say "yesterday", which keeps a sorted column uniform.

### Server-rendered dates

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-2);font-size:var(--tp-text-sm)">
  <span>Last backup: <tp-time>2026-10-05T14:30:00Z</tp-time></span>
  <span>Last sync: <tp-time>sometime yesterday</tp-time></span>
</div>`}
/>

Text the server already rendered upgrades in place once the element loads. Text that cannot be read as a date, time or duration stays as written and marks the element invalid, so a label never turns into a wrong date.
