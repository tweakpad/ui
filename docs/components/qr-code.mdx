## Usage

Set `value` to the text to encode and `label` to what scanning does. The label names the image for assistive technology and titles SVG exports; the value itself is never announced, because it may be private. Show the link or the text beside the code for people who cannot scan it. The encoder is built in, so there is nothing else to install.

### In context

The tile stays light in a dark theme, like a printed sticker, because many scanners cannot read a light code on a dark background.

### Copy and download

`copyable` adds a Copy button that writes the image as PNG and the value as text in one clipboard item, so an image editor pastes the picture and a text field pastes the value. `downloadable` adds a menu with PNG, SVG and JPG. Files are named after `filename` and exported at `export-size` pixels, 1024 by default.

<Preview
  title="Copy and download"
  code={`<tp-qr-code
  value="https://northwind.co/invite/team-42"
  label="Invite link for the design team"
  copyable
  downloadable
  filename="design-team-invite"
  export-size="2048"
></tp-qr-code>`}
/>

Both actions are disabled while there is no code. The `copy()`, `download()`, `toBlob()` and `toSVG()` methods do the same work without the actions row, for a button or flow of your own.

When the browser refuses images, the text alone is copied.

<Code code={`const code = document.querySelector('tp-qr-code');
await code.download('svg', { size: 512, filename: 'poster-code' });
const png = await code.toBlob('png', { size: 300 });`} language="js" />

PNG and JPEG files are exactly the requested size. Every module is the same whole number of
pixels, so the code never blurs; the pixels left over widen the quiet zone. JPEG has no
transparency and is painted on white. Sizes are clamped between the module count and 4096
pixels.

### Live value

Assign `value` as the source changes and the code re-encodes. `status` is `empty`, `encoded` or `error`, reflected as `data-status`, and the tile keeps its size while empty. The button here calls `download()` with a larger size of its own for printing.

<Preview
  title="Live value"
  code={`<div id="qr-code-live" style="display:grid;gap:var(--tp-space-4);justify-items:center;inline-size:18rem;max-inline-size:100%">
  <tp-field label="Wi-Fi network" style="inline-size:100%">
    <tp-input default-value="Northwind Guest"></tp-input>
  </tp-field>
  <tp-qr-code size="lg" error-correction="Q" label="Scan to join the guest Wi-Fi"></tp-qr-code>
  <tp-button variant="outline" size="sm" data-download>Download print-ready PNG</tp-button>
</div>`}
  script={`const root = document.getElementById('qr-code-live');
const input = root.querySelector('tp-input');
const code = root.querySelector('tp-qr-code');
const encode = (name) => \`WIFI:T:WPA;S:\${name};P:welcome-2026;;\`;
await customElements.whenDefined('tp-input');
code.value = encode(input.value);
input.addEventListener('tp-value-change', (event) => {
  code.value = String(event.detail.value ?? '').trim() ? encode(event.detail.value) : '';
});
root.querySelector('[data-download]').addEventListener('click', () => {
  code.download('png', { size: 2048, filename: 'guest-wifi' });
});`}
/>

### Error correction

`error-correction` restores about 7% (`L`), 15% (`M`, the default), 25% (`Q`) or 30% (`H`) of a damaged code. Higher levels need more modules for the same value, so the code gets denser at the same size. Use `H` when a logo or sticker may cover part of the code.

<Preview
  title="Error correction"
  code={`<div style="display:flex;flex-wrap:wrap;justify-content:center;gap:var(--tp-space-5)">

  <tp-qr-code size="sm" error-correction="M" value="https://northwind.co/menu/table-12" label="Table 12 menu, level M"></tp-qr-code>
  <tp-qr-code size="sm" error-correction="Q" value="https://northwind.co/menu/table-12" label="Table 12 menu, level Q"></tp-qr-code>
  <tp-qr-code size="sm" error-correction="H" value="https://northwind.co/menu/table-12" label="Table 12 menu, level H"></tp-qr-code>
</div>`}
/>

`quiet-zone` is the light border scanners need around the modules, 4 modules by default. Keep it unless the code sits on a light surface that already provides the margin.

It is drawn inside the tile and included in every export.

The value is encoded in the most compact mode: digits only, upper-case letters with digits and
`$%*+-./:` and spaces, or any text as UTF-8 bytes. The largest code holds:

| Level | Digits | Upper-case letters | UTF-8 bytes |
| ----- | ------ | ------------------ | ----------- |
| L     | 7089   | 4296               | 2953        |
| M     | 5596   | 3391               | 2331        |
| Q     | 3993   | 2420               | 1663        |
| H     | 3057   | 1852               | 1273        |

### Sizes and colors

`size` is `sm` (128 px), `default` (192 px) or `lg` (256 px), and `--tp-qr-code-size` sets any other size. `--tp-qr-code-foreground` and `--tp-qr-code-background` change the colors on screen and in every export; keep dark modules on a light background with enough contrast, or the element raises a diagnostic.

The tile is square. `size` picks one of three sizes, and `--tp-qr-code-size` sets any other
size; it can be set on the element or any ancestor. The tile never grows wider than the space
around it. A diagnostic warns when the modules are lighter than the background or the
contrast is below 3:1.

### Accessibility

The code is an image named by `label`, or by the `qrCode` message when `label` is empty. It is
hidden from assistive technology while there is no code. The actions are a group named by the
`actions` message; the Copy button and the Download menu keep their own keyboard behavior and
announcements. The image never mirrors in right-to-left layouts, and in forced-colors mode it
keeps its own colors so it stays scannable.

### Encoding without the element

`@tweakpad/ui/qr` encodes without a browser, for servers, workers and build scripts:

<Code code={`import { encodeQr, qrPathData } from '@tweakpad/ui/qr';

const code = encodeQr('https://tweakpad.github.io', { errorCorrection: 'Q' });
const quietZone = 4;
const extent = code.size + quietZone * 2;
const svg = \`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 \${extent} \${extent}"><path d="\${qrPathData(code, quietZone)}"/></svg>\`;`} language="js" />

`encodeQr(text, { errorCorrection, minVersion, maxVersion, mask })` returns the version, size,
mask, mode and modules (row by row, 1 for dark). It throws `QrCapacityError`, carrying the
limit, when the value does not fit. `qrCapacity(mode, level, version)` gives the limits above.
