## Usage

Use a QR code to move something from a screen to a phone: a sign-in link, an invite, Wi-Fi details. `value` is the text to encode and `label` says what scanning does; the label names the image for assistive technology and titles SVG exports, while the value itself is never announced, because it may be private. Show the link or the text beside the code for people who cannot scan it. The tile stays light in a dark theme, like a printed sticker, because many scanners cannot read a light code on a dark background.

### Pairing a device

<Preview
  code={`<tp-card style="max-inline-size:20rem">
  <h3 slot="header">Connect your phone</h3>
  <p slot="description">Open the app on your phone and scan the code to sign in to this workspace.</p>
  <tp-qr-code value="https://app.northwind.co/pair/7KD-2Q9" label="Scan to sign in on your phone"></tp-qr-code>
  <tp-button slot="footer" variant="secondary">Done</tp-button>
</tp-card>`}
/>

The label describes the outcome, signing in, rather than the code, so a screen reader user knows what the image is for.

### Sharing an invite

<Preview
  code={`<tp-qr-code
  value="https://northwind.co/invite/team-42"
  label="Invite link for the design team"
  copyable
  downloadable
  filename="design-team-invite"
  export-size="2048"
></tp-qr-code>`}
/>

Copy writes the image and the value in one clipboard item, so an image editor pastes the picture and a text field pastes the link. Download offers PNG, SVG and JPG, named after `filename` and exported at `export-size` pixels. Both actions stay disabled while there is no code to export.

### Codes that follow a form

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-4);justify-items:start;inline-size:18rem;max-inline-size:100%">
  <tp-field label="Wi-Fi network" style="inline-size:100%">
    <tp-input id="qr-code-network" default-value="Northwind Guest"></tp-input>
  </tp-field>
  <tp-qr-code id="qr-code-wifi" size="lg" error-correction="Q" label="Scan to join the guest Wi-Fi"></tp-qr-code>
  <tp-button id="qr-code-print" variant="outline" size="sm">Download print-ready PNG</tp-button>
</div>`}
  script={`const input = document.getElementById('qr-code-network');
const code = document.getElementById('qr-code-wifi');
const encode = (name) => \`WIFI:T:WPA;S:\${name};P:welcome-2026;;\`;
await customElements.whenDefined('tp-input');
code.value = encode(input.value);
input.addEventListener('tp-value-change', (event) => {
  code.value = String(event.detail.value ?? '').trim() ? encode(event.detail.value) : '';
});
document.getElementById('qr-code-print').addEventListener('click', () => {
  code.download('png', { size: 2048, filename: 'guest-wifi' });
});`}
/>

Assigning `value` as the source changes re-encodes the code, and the tile keeps its size while it is empty. The export methods do the work of the built-in actions for a flow of your own, here a larger download for printing.

### Stickers and printed menus

<Preview
  code={`<div style="display:flex;flex-wrap:wrap;gap:var(--tp-space-5)">
  <tp-qr-code size="sm" error-correction="L" value="https://northwind.co/menu/table-12" label="Table 12 menu, level L"></tp-qr-code>
  <tp-qr-code size="sm" error-correction="M" value="https://northwind.co/menu/table-12" label="Table 12 menu, level M"></tp-qr-code>
  <tp-qr-code size="sm" error-correction="Q" value="https://northwind.co/menu/table-12" label="Table 12 menu, level Q"></tp-qr-code>
  <tp-qr-code size="sm" error-correction="H" value="https://northwind.co/menu/table-12" label="Table 12 menu, level H"></tp-qr-code>
</div>`}
/>

A code on a table or a poster gets scratched, folded or partly covered by a logo. Error correction restores about 7% (`L`), 15% (`M`), 25% (`Q`) or 30% (`H`) of a damaged code, at the cost of more, smaller modules at the same size. Keep the quiet zone, the light border scanners need around the modules, unless the surface around the code already provides it.

### Brand colors

<Preview
  code={`<div style="display:flex;flex-wrap:wrap;align-items:end;gap:var(--tp-space-5)">
  <tp-qr-code value="https://tweakpad.github.io" label="Open Tweakpad"></tp-qr-code>
  <tp-qr-code value="https://tweakpad.github.io" label="Open Tweakpad" error-correction="H" style="--tp-qr-code-size:12rem;--tp-qr-code-foreground:#1e3a8a;--tp-qr-code-background:#eff6ff"></tp-qr-code>
</div>`}
/>

The color properties apply on screen and in every export. Keep dark modules on a light background with enough contrast; a pair scanners may not read raises a diagnostic.
