## Usage

An Overflow list keeps a set of tags, labels or people to a budget and replaces what does not fit with one count, `+3`, which assistive technology reads as "3 more". Its items are its element children, in document order. It adds no role or focus behavior, so interactive items keep their own; the items left out stay in the page but are not shown, focusable or announced. Items should keep their own width, since an item that grows to fill its row cannot be measured.

A `limit` shows at most that many items, for when the number matters more than the space they take, such as the first few people on a card.

`max-rows` fits as many items as the width allows within that many wrapped rows, with the count beside them, and refits whenever the container resizes. Its height changes only when its fitted rows do, so the content below stays in place. With a `limit` as well, the fit never shows more than that many items.

In a table cell, a flex row or a grid track, the list asks for the width of its items on one row and can shrink down to the count, so the column sizes as if nothing were left out. In a flex row, give the list room to grow.

### Count that opens the rest

<Preview
  code={`<tp-overflow-list id="overflow-list-skills" max-rows="1" style="max-inline-size:22rem">
  <tp-badge variant="outline">Design systems</tp-badge>
  <tp-badge variant="outline">Accessibility</tp-badge>
  <tp-badge variant="outline">TypeScript</tp-badge>
  <tp-badge variant="outline">Figma</tp-badge>
  <tp-badge variant="outline">Motion</tp-badge>
  <tp-badge variant="outline">User research</tp-badge>
  <tp-badge variant="outline">Prototyping</tp-badge>
  <span slot="count">
    <tp-popover label="More skills">
      <tp-button slot="trigger" id="overflow-list-skills-button" variant="outline" size="xs"></tp-button>
      <tp-list id="overflow-list-skills-more" aria-label="More skills"></tp-list>
    </tp-popover>
  </span>
</tp-overflow-list>`}
  script={`await customElements.whenDefined('tp-overflow-list');
const list = document.getElementById('overflow-list-skills');
const button = document.getElementById('overflow-list-skills-button');
const more = document.getElementById('overflow-list-skills-more');
const update = () => {
  const labels = list.hiddenItems.map((item) => item.textContent.trim());
  button.textContent = '+' + labels.length;
  button.setAttribute('aria-label', labels.length + ' more skills');
  more.replaceChildren(
    ...labels.map((label) => Object.assign(document.createElement('tp-list-item'), { textContent: label, size: 'xs' })),
  );
};
list.addEventListener('tp-overflow-change', update);
update();`}
/>

An element in the `count` slot replaces the default count while items are left out, here a Button that opens a Popover with the omitted skills. It gets no generated content: fill it on `tp-overflow-change` from `hiddenCount` or `hiddenItems`, and state the number in its text or name. The count needs a box of its own, so the Popover sits in a wrapper. To change only the words of the default count, set its visible and spoken texts in `messages`.
