## Usage

A Menu holds commands, not navigation; use Navigation Menu for site links. Put a Button in the `trigger` slot and the command tree in the default slot. Arrow keys, Home/End and typeahead move through enabled items, and Tab closes the menu rather than trapping focus.

Trigger Enter/Space or pointer press opens. ArrowDown/ArrowUp opens at the first/last enabled item. Escape closes the top applicable branch; Tab closes and continues outside rather than trapping command focus. Disabled entries are excluded. Pointer highlighting never selects a check or radio by itself.

### Commands

Activating an item fires a cancelable `tp-action` with the item's `value`, then closes the menu. Listen on the Menu instead of wiring each item.

`tp-action` is a separate cancelable Menu event with `{value, item, sourceEvent}` emitted before selection commit. Canceling it prevents the command and close.

    <tp-menu-item value="Download PDF">Download PDF</tp-menu-item>

});`}

### Inset items

`inset` indents an item's label to line up with the text of items that have a leading icon, so a menu that mixes both keeps one text column.

<Preview
  title="Inset"
  code={`<tp-menu id="menu-inset" label="Document">
  <tp-button slot="trigger" variant="outline">Document</tp-button>
  <tp-menu-item value="duplicate"><tp-icon data-icon="copy"></tp-icon>Duplicate</tp-menu-item>
  <tp-menu-item value="share"><tp-icon data-icon="share"></tp-icon>Share</tp-menu-item>
  <tp-menu-item value="rename" inset>Rename</tp-menu-item>
  <tp-menu-item value="move" inset>Move to…</tp-menu-item>
</tp-menu>`}
  script={`const icons = {
  copy: { viewBox: '0 0 24 24', paths: [{ d: 'M8 8h13v13H8zM16 8V3H3v13h5', strokeWidth: 2 }] },
  share: { viewBox: '0 0 24 24', paths: [{ d: 'M4 12v8h16v-8M12 3v13M7 8l5-5 5 5', strokeWidth: 2 }] },
};
for (const icon of document.querySelectorAll('#menu-inset tp-icon')) icon.icon = icons[icon.dataset.icon];`}
/>

### Checks and radio choices

Checkbox items toggle independently; a radio group keeps exactly one choice. Both stay open on activation so several settings can change in one visit. A child with `data-menu-label` labels the group.

No checkbox/radio here is a standalone form field.

### Submenus

Nest a `tp-menu` with its own trigger to create a submenu at any depth. The inline-forward arrow opens it and the backward arrow returns to the parent item.

Moving to a different item in any parent menu closes that parent's open child branch, including deeper descendants. The parent and its ancestors stay open, and the new item keeps the highlight.

<Preview
  title="Nested menus"
  code={`<tp-menu label="Project">

### Context menu

`invocation="context"` turns the trigger slot into a context target: right-click, Shift+F10 or a long touch opens the menu at the pointer, and ordinary clicks keep the target's own behavior. Make the target focusable so keyboard users can reach it.

An external target can be associated with `for="target-id"`. A single-touch hold opens after 500 ms; movement beyond 10 coordinate units, a second touch, release, or cancellation cancels the hold. Another context invocation moves the anchor without closing and reopening. A context menu supports the same commands, groups, shortcuts, separators, checks, radio choices and any number of nested Menu levels.

### Hover opening

`open-on-hover` opens a top-level Menu on pointer hover after `open-delay`. Submenus already open on hover; keyboard and press activation keep working either way.
