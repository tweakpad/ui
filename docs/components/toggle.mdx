## Usage

A Toggle is an action with a remembered state, announced as a pressed or unpressed button. It does not submit a form value: use a Checkbox for a yes-or-no field and a Radio group for a single choice. To coordinate several Toggles, such as alignment options where only one applies, put them in a Toggle group. An Icon alone is decorative, so a Toggle without visible text needs an `aria-label`.

### Save for later

<Preview
  code={`<tp-toggle id="toggle-save" variant="outline"></tp-toggle>
<tp-toggle id="toggle-saved" variant="outline" default-pressed></tp-toggle>`}
  script={`import { html } from 'lit';
import { bookmarkIcon, filledBookmarkIcon } from '@tweakpad/ui/icons/text-formatting';

await customElements.whenDefined('tp-toggle');
for (const id of ['toggle-save', 'toggle-saved']) {
  document.getElementById(id).partContracts = {
    'toggle-content': {
      content: (state) =>
        html\`<tp-icon data-icon="inline-start" .icon=\${state.pressed ? filledBookmarkIcon : bookmarkIcon}></tp-icon>
          \${state.pressed ? 'Saved' : 'Save'}\`,
    },
  };
}`}
/>

When the artwork or the text should follow the state, such as an outlined bookmark that fills in, render the content from the state through the `toggle-content` part contract: its `content` receives the committed state, so the label never lags behind the pressed state it describes.

### Editor toolbar

<Preview
  code={`<div style="display:flex;flex-wrap:wrap;align-items:center;gap:var(--tp-space-2)">
  <tp-button variant="outline" size="sm">Insert link</tp-button>
  <tp-toggle variant="outline" size="sm">Spell check</tp-toggle>
  <tp-toggle variant="outline" size="icon-sm" aria-label="Pin toolbar" default-pressed><tp-icon id="toggle-toolbar-pin"></tp-icon></tp-toggle>
</div>`}
  script={`import { pinIcon } from '@tweakpad/ui/icons/pin';

document.getElementById('toggle-toolbar-pin').icon = pinIcon;`}
/>

Toggles share the Button's sizes, so a Toggle and a Button of one size line up in a toolbar, and the `icon-*` sizes make square Toggles at the same heights. Use a Button for a one-off action and a Toggle for a state that stays on.

### Mute notifications

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-3);justify-items:start">
  <tp-toggle id="toggle-mute" variant="outline">Mute notifications</tp-toggle>
  <output id="toggle-mute-output" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Notifications are on</output>
</div>`}
  script={`const toggle = document.getElementById('toggle-mute');
const output = document.getElementById('toggle-mute-output');
toggle.addEventListener('tp-value-change', (event) => {
  output.textContent = event.detail.value ? 'Notifications are muted' : 'Notifications are on';
});`}
/>

Each press proposes the inverse state through a cancelable `tp-value-change`: read `event.detail.value` to react, or cancel the event to keep the current state, for example until a confirmation succeeds. A disabled Toggle leaves the tab order but still shows whether it is pressed.

### Variants

<Preview
  code={`<tp-toggle default-pressed>Ghost</tp-toggle>
<tp-toggle variant="outline" default-pressed>Outline</tp-toggle>`}
/>

`ghost` suits a Toggle among others in a toolbar, where the fill alone marks the pressed state; `outline` gives a Toggle that stands alone a visible edge while unpressed.
