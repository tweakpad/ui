## Usage

A Navigation menu moves people between pages. Its links stay links: they keep native activation, modifier keys, targets and the tab order, and nothing takes on command-menu roles. Name the landmark with `aria-label`. For application commands, use a Menu or a Menubar.

### Documentation header

<Preview
  code={`<tp-navigation-menu aria-label="Documentation">
  <tp-navigation-menu-item value="guides">
    <tp-button slot="trigger" variant="ghost">Guides</tp-button>
    <div slot="content" style="display:grid;min-inline-size:12rem">
      <a href="#quick-start">Quick start</a>
      <a href="#theming">Theming</a>
      <a href="#accessibility">Accessibility</a>
    </div>
  </tp-navigation-menu-item>
  <tp-navigation-menu-item><a href="#components">Components</a></tp-navigation-menu-item>
  <tp-navigation-menu-item><a href="#blog">Blog</a></tp-navigation-menu-item>
</tp-navigation-menu>`}
/>

An item with a `trigger` and a `content` panel opens on hover or press; an item holding only a link is a plain destination. The panels share one measured viewport, so moving between items resizes it instead of closing and reopening.

### Account settings

<Preview
  code={`<tp-navigation-menu aria-label="Account">
  <tp-navigation-menu-item value="settings">
    <tp-button slot="trigger" variant="ghost">Settings</tp-button>
    <div slot="content" style="display:grid;min-inline-size:12rem">
      <a href="#profile" active>Profile</a>
      <a href="#billing" close-on-click>Billing</a>
      <a href="#notifications" close-on-click>Notifications</a>
    </div>
  </tp-navigation-menu-item>
  <tp-navigation-menu-item><a href="#support">Support</a></tp-navigation-menu-item>
</tp-navigation-menu>`}
/>

`active` on a link marks the page the reader is on, for assistive technology too. `close-on-click` closes the panel when a link is followed, for destinations on the same page whose panel would otherwise stay open.

## Keyboard

| Key | Action |
| --- | --- |
| <Keys keys="right" /> <Keys keys="left" /> | Moves focus to the next or previous trigger or link of a horizontal list, following the writing direction; a vertical list uses the up and down arrows. |
| <Keys keys="home" /> <Keys keys="end" /> | Moves focus to the first or the last trigger or link. |
| <Keys keys="down" /> | On a trigger of a horizontal list, opens its panel and moves focus into it; a vertical list uses the arrow toward the end of the line. |
| <Keys keys="esc" /> | Closes the open panel. |
