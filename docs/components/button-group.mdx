## Usage

A Button group only arranges and joins its members: each Button keeps its own name, disabled state and activation, and the group adds no focus management of its own. Give the group a `label` so assistive technology announces the set. The group sets no size on its members, so give every Button the same `size` when the set should share one height. A Button group implies no selection; when its members choose one shared value, such as text alignment, use a Toggle group instead.

### Canvas toolbar

<Preview
  code={`<tp-button-group orientation="vertical" label="Canvas tools">
  <tp-button-group orientation="vertical" label="Navigation">
    <tp-button id="button-group-select" variant="outline" size="icon">Select</tp-button>
    <tp-button id="button-group-hand" variant="outline" size="icon">Pan</tp-button>
  </tp-button-group>
  <tp-button-group orientation="vertical" label="Insert">
    <tp-button id="button-group-shape" variant="outline" size="icon">Rectangle</tp-button>
    <tp-button id="button-group-image" variant="outline" size="icon">Image</tp-button>
  </tp-button-group>
</tp-button-group>`}
  script={`import { mousePointerIcon } from '@tweakpad/ui/icons/mouse-pointer';
import { handIcon } from '@tweakpad/ui/icons/hand';
import { squareIcon } from '@tweakpad/ui/icons/square';
import { imageIcon } from '@tweakpad/ui/icons/image';

document.getElementById('button-group-select').icon = mousePointerIcon;
document.getElementById('button-group-hand').icon = handIcon;
document.getElementById('button-group-shape').icon = squareIcon;
document.getElementById('button-group-image').icon = imageIcon;`}
/>

A vertical group stacks its members and moves the seams to the block axis; members stretch to the widest one, and their order and keyboard behavior stay as written. Groups nest, each with its own seams and a gap between them, so related tools read as sets inside one toolbar.

### Fields with a prefix or an action

<Preview
  code={`<div id="button-group-fields" style="display:grid;justify-items:start;gap:var(--tp-space-4)">
  <tp-button-group label="Workspace address">
    <tp-button-group-text>tweakpad.app/</tp-button-group-text>
    <tp-input label="Workspace slug" placeholder="acme"></tp-input>
  </tp-button-group>
  <tp-button-group label="Invite a teammate">
    <tp-input label="Email" type="email" placeholder="name@company.com"></tp-input>
    <tp-button variant="outline">Send invite</tp-button>
  </tp-button-group>
  <tp-button-group label="Star this repository">
    <tp-toggle variant="outline" data-star>Star</tp-toggle>
    <tp-button-group-text data-star-count>2,418</tp-button-group-text>
  </tp-button-group>
</div>`}
  script={`const root = document.querySelector('#button-group-fields');
root.querySelector('[data-star]').addEventListener('tp-value-change', (event) => {
  root.querySelector('[data-star-count]').textContent = event.detail.value ? '2,419' : '2,418';
});`}
/>

Inputs, selects, Input groups and Toggles join the set like a Button and keep their value, validation and form behavior. A Button group text holds what is read but never pressed: a fixed prefix, a unit or a count that follows another member.

### Split button

<Preview
  code={`<tp-button-group label="Publish">
  <tp-button variant="secondary">Publish</tp-button>
  <tp-separator></tp-separator>
  <tp-menu label="Publish options">
    <tp-button id="button-group-options" slot="trigger" variant="secondary" size="icon">Publish options</tp-button>
    <tp-menu-item value="schedule">Schedule for later</tp-menu-item>
    <tp-menu-item value="draft">Save as draft</tp-menu-item>
    <tp-menu-item value="preview">Share preview link</tp-menu-item>
  </tp-menu>
</tp-button-group>`}
  script={`import { chevronDownIcon } from '@tweakpad/ui/icons/chevron-down';

document.getElementById('button-group-options').icon = chevronDownIcon;`}
/>

The main action sits on one side and a Menu of alternatives on the other. A Separator keeps a visible divide between filled members, and the group turns it across the row. The Menu joins through its trigger and keeps its own focus and dismissal; a Popover joins the same way.

### Dialog footer

<Preview
  code={`<tp-button-group id="button-group-footer" label="Dialog actions">
  <tp-button variant="outline">Cancel</tp-button>
  <tp-button>Save changes</tp-button>
</tp-button-group>`}
  script={`document.getElementById('button-group-footer').joined = false;`}
/>

With `joined` turned off, each Button keeps its own corners and the members sit a standard gap apart, while the set is still announced as one group.
