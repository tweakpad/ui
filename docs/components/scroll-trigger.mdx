## Usage

A Scroll trigger turns the Text motions, Images, Image groups and nested triggers inside it into one sequence. As it nears the view it asks every member to prepare, so images start loading; once it is in view and everything is ready, it reveals the members in document order, `stagger` milliseconds apart. So a heading waits for its font, and a caption for the images before it. The trigger is an unstyled block that never changes its own box, so lay out its content as you like. `reveal-repeat` plays the sequence again each time the section comes back into view; keep it for sections people return to.

`scrub` maps the scroll position onto the sequence a timed reveal would play, in both directions, and smoothing lets it trail the scroll slightly. `scrub-range` picks the stretch of scroll that drives it, with offsets that work like a CSS animation range: `entry 25% contain 40%` starts once a quarter of the section has entered and finishes well before the middle of the view, so the content sits still while people read it. `scrub-once` leaves revealed content at rest when scrolling back.

`pin` holds the content in a sticky stage while the scroll advances through an extra length; with `scrub`, the reveal plays across that length. The stage fills the nearest scroll container that sets `container-type: size`, and the viewport without one.

### Reacting to the reveal

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-3)">
  <tp-scroll-trigger id="scroll-trigger-welcome" stagger="200" reveal="fade up">
    <p style="margin:0;font-size:var(--tp-text-xl);font-weight:var(--tp-font-semibold)"><tp-text-motion split="words">Welcome to your workspace</tp-text-motion></p>
    <p style="margin:var(--tp-space-1) 0 0;color:var(--tp-muted-foreground)"><tp-text-motion>Your projects, people and files in one place.</tp-text-motion></p>
  </tp-scroll-trigger>
  <output id="scroll-trigger-welcome-status" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Waiting</output>
</div>`}
  script={`const trigger = document.getElementById('scroll-trigger-welcome');
const status = document.getElementById('scroll-trigger-welcome-status');
trigger.addEventListener('tp-reveal-change', (event) => {
  if (event.target === trigger && event.detail.revealed) status.textContent = 'Revealing…';
});
trigger.addEventListener('tp-reveal-change-complete', (event) => {
  if (event.target === trigger && event.detail.revealed) status.textContent = 'Revealed';
});`}
/>

The trigger announces when its sequence starts and when the last member settles, for work that should follow the reveal; while scrubbing, it reports the progress each frame for an animation of your own. The members' events bubble under the same names, so check that the event comes from the trigger.
