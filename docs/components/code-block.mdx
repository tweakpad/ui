## Usage

Use a Code block for source a reader studies or copies: setup steps in a guide, an API example, a change under review. The source is the element's text content, dedented and trimmed, so it can be indented with the surrounding markup; escape `<` and `&` as `&lt;` and `&amp;`, or set `code` from script. `label` adds a header with the title, the language and the copy action. The built-in highlighter covers TypeScript, JavaScript, HTML, CSS, JSON, Bash and diffs; other languages render as plain text, and an adapter from `@tweakpad/ui/code` assigned to `highlighter` covers every grammar, swapping in colors without shifting the layout.

### Install commands

<Preview
  align="stretch"
  code={`<tp-code-block language="bash" style="max-inline-size:44rem">
  # Install the library and its peer dependency
  npm install @tweakpad/ui lit
</tp-code-block>`}
/>

A short command needs no header: the copy action floats in the corner. `wrap` wraps a long line instead of scrolling it, and `copyable="false"` removes the action from code that should not be pasted as is.

### Steps that need approval

<Preview
  align="stretch"
  code={`<tp-code-block language="bash" style="max-inline-size:44rem">
  <span slot="title" style="display:inline-flex;align-items:center;gap:var(--tp-space-2)">
    Deploy to production
    <tp-badge variant="warning">Requires approval</tp-badge>
  </span>
  npx tweakpad deploy --env production --confirm
</tp-code-block>`}
/>

The `title` slot replaces the `label` text with content of your own, here with a Badge. Slotted elements are not part of the source, so the copied text is exactly the command.

When the prose around the block refers to lines, number them; the gutter stays put while long lines scroll. Highlighted lines draw the eye to the part the text is about.

### Showing a change

<Preview
  align="stretch"
  code={`<tp-code-block language="javascript" label="cart.js" line-numbers removed-lines="2-4" added-lines="5" style="max-inline-size:44rem">
  export function subtotal(items) {
    let sum = 0;
    for (const item of items) sum += item.total;
    return sum;
    return items.reduce((sum, item) => sum + item.total, 0);
  }
</tp-code-block>`}
/>

Added and removed lines get a gutter marker, a tint and visually hidden text, so the change reads without relying on color, while the code itself keeps its syntax colors. To show a patch exactly as a tool printed it, use `language="diff"` instead.
