## Usage

Use a Toggle group for a set of related actions that stay pressed, such as a view switcher or a formatting toolbar. Put Toggles with unique `value`s inside it and give the group a `label`. The selection is an ordered list of values in both modes, so `default-value` takes a JSON array. The group is one tab stop, and the arrow keys move between Toggles without pressing them. It submits no form value: for one choice from a form, use a Radio group.

### Text formatting

<Preview
  code={`<tp-toggle-group label="Text formatting" size="icon" multiple default-value='["bold"]'>
  <tp-toggle value="bold" aria-label="Bold"><tp-icon id="toggle-group-bold"></tp-icon></tp-toggle>
  <tp-toggle value="italic" aria-label="Italic"><tp-icon id="toggle-group-italic"></tp-icon></tp-toggle>
  <tp-toggle value="underline" aria-label="Underline"><tp-icon id="toggle-group-underline"></tp-icon></tp-toggle>
</tp-toggle-group>`}
  script={`import { boldIcon, italicIcon, underlineIcon } from '@tweakpad/ui/icons/text-formatting';

document.getElementById('toggle-group-bold').icon = boldIcon;
document.getElementById('toggle-group-italic').icon = italicIcon;
document.getElementById('toggle-group-underline').icon = underlineIcon;`}
/>

`multiple` lets each Toggle be pressed on its own, as formatting marks combine. The group's `size` applies to every Toggle; an `icon-*` size makes them square, and each Icon-only Toggle needs an `aria-label`.

### Date range

<Preview
  code={`<tp-toggle-group label="Date range" variant="outline" spacing="0" default-value='["30d"]'>
  <tp-toggle value="7d">7 days</tp-toggle>
  <tp-toggle value="30d">30 days</tp-toggle>
  <tp-toggle value="90d">90 days</tp-toggle>
  <tp-toggle value="12m" disabled>12 months</tp-toggle>
</tp-toggle-group>`}
/>

`spacing="0"` joins the Toggles into one segmented control with shared seams, which reads as a single setting with several positions. A disabled Toggle, here a range the plan does not include, is skipped by the arrow keys.

### Billing period

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-3);justify-items:start">
  <tp-toggle-group id="toggle-group-period" label="Billing period" variant="outline" spacing="0" default-value='["yearly"]'>
    <tp-toggle value="monthly">Monthly</tp-toggle>
    <tp-toggle value="yearly">Yearly</tp-toggle>
  </tp-toggle-group>
  <output id="toggle-group-period-output" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">$96 per seat, billed yearly</output>
</div>`}
  script={`const group = document.getElementById('toggle-group-period');
const output = document.getElementById('toggle-group-period-output');
group.addEventListener('tp-value-change', (event) => {
  if (event.target !== group) return;
  const [period] = event.detail.value;
  if (!period) {
    event.preventDefault();
    return;
  }
  output.textContent = period === 'yearly' ? '$96 per seat, billed yearly' : '$10 per seat, billed monthly';
});`}
/>

In single mode a press on the pressed Toggle clears the selection. When an empty selection makes no sense, as for a price that needs a period, cancel that proposal in `tp-value-change`.

### Heading weight

<Preview
  code={`<tp-field label="Heading weight">
  <tp-toggle-group id="toggle-group-weight" variant="outline" size="lg" default-value='["medium"]'>
    <tp-toggle value="light" data-weight="300" aria-label="Light"><span aria-hidden="true">Aa</span><span>Light</span></tp-toggle>
    <tp-toggle value="regular" data-weight="400" aria-label="Regular"><span aria-hidden="true">Aa</span><span>Regular</span></tp-toggle>
    <tp-toggle value="medium" data-weight="500" aria-label="Medium"><span aria-hidden="true">Aa</span><span>Medium</span></tp-toggle>
    <tp-toggle value="bold" data-weight="700" aria-label="Bold"><span aria-hidden="true">Aa</span><span>Bold</span></tp-toggle>
  </tp-toggle-group>
</tp-field>`}
  script={`await customElements.whenDefined('tp-toggle');
for (const item of document.querySelectorAll('#toggle-group-weight tp-toggle')) {
  item.partContracts = {
    toggle: { styleHook: { 'block-size': 'auto', 'padding-block': 'var(--tp-space-2)' } },
    'toggle-content': { styleHook: { 'flex-direction': 'column', 'font-weight': item.dataset.weight } },
  };
}`}
/>

A Toggle can hold more than a word, such as a sample above its name. Reshape each Toggle through its part contracts, here stacking the content and giving each sample its weight, and let a Field name the group.

### Variants

<Preview
  code={`<tp-toggle-group label="Ghost alignment" default-value='["left"]'>
  <tp-toggle value="left">Left</tp-toggle>
  <tp-toggle value="center">Center</tp-toggle>
  <tp-toggle value="right">Right</tp-toggle>
</tp-toggle-group>
<tp-toggle-group label="Outline alignment" variant="outline" default-value='["left"]'>
  <tp-toggle value="left">Left</tp-toggle>
  <tp-toggle value="center">Center</tp-toggle>
  <tp-toggle value="right">Right</tp-toggle>
</tp-toggle-group>`}
/>

The group's `variant` paints every Toggle in it. `ghost` keeps a toolbar quiet until something is pressed; `outline` draws each Toggle's edge, which suits a group that stands on its own in a form or a header.

## Keyboard

| Key                                         | Action                                                                          |
| ------------------------------------------- | ------------------------------------------------------------------------------- |
| <Keys keys="right" /> <Keys keys="left" />  | Moves focus to the next or previous Toggle of a horizontal group, wrapping around. |
| <Keys keys="down" /> <Keys keys="up" />     | Moves focus to the next or previous Toggle of a vertical group, wrapping around.   |
| <Keys keys="home" /> <Keys keys="end" />    | Moves focus to the first or the last Toggle.                                    |
| <Keys keys="space" /> <Keys keys="enter" /> | Presses or releases the focused Toggle.                                         |
