## Usage

A Description list shows the details of one record as names and values: an order, an API key, a subscription. It renders one native description list, so assistive technology reads each label with its value. Place the items directly inside the list, in reading order; other children are not shown. In a vertical list the labels share one column, as wide as the widest label up to 40% of the list, so the values line up.

A value can be any content: text, a link, or components such as a Badge, a Time or a Copy button. A long value runs under its label when its item is stacked, while the other pairs keep their columns.

  script={`await customElements.whenDefined('tp-description-list');
document.getElementById('description-list-billing').messages = {
  showMore: ({ hidden }) => 'Show ' + hidden + ' more billing details',
  showLess: 'Show fewer billing details',
};`}
/>

With a `limit`, the first items show and a Show more button below the list reveals the rest, which expand into place; the button then reads Show less. Hidden items are not shown, focusable or announced. Name the button for its list when a page has several, as the messages do here with the count of hidden items.
