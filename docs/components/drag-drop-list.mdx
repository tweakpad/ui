## Usage

Use a Drag Drop List when the order of a short collection is the point: priorities, a checklist, the columns of a table, the stages of a pipeline. Items are plain data with a stable `id` and a `label`, so the list is fed from script before it first renders, through `defaultValue` when it owns the order or `value` when your application does. While a row is dragged, the others make room in a preview order; a drop commits a new array, and Escape, a drop outside the list or a rejected proposal restores the committed order. Every row has a named handle Button, so the whole interaction also works from the keyboard and is announced as it happens.

### Saving the order

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-3);max-inline-size:26rem">
  <tp-drag-drop-list id="drag-drop-list-priorities" label="Sprint priorities" variant="outline" size="sm"></tp-drag-drop-list>
  <span id="drag-drop-list-priorities-status" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Drag a row to reprioritize.</span>
</div>`}
  script={`const authored = document.getElementById('drag-drop-list-priorities');
const list = authored.cloneNode();
list.defaultValue = [
  { id: 'sso', label: 'SAML single sign-on' },
  { id: 'export', label: 'CSV export for reports' },
  { id: 'mobile', label: 'Mobile push notifications' },
];
list.addEventListener('tp-value-commit', () => {
  document.getElementById('drag-drop-list-priorities-status').textContent =
    'Saved order: ' + list.value.map((item) => item.label).join(' → ');
});
authored.replaceWith(list);`}
/>

`tp-value-commit` fires once a drop has settled, the moment to save the new order; hovering never commits. While a save is pending, `readonly` keeps the order visible but locked.

### Rows with status and actions

const list = document.createElement('tp-drag-drop-list');

const tone = { Ready: 'success', 'In review': 'secondary', Blocked: 'destructive' };

  <tp-badge slot="actions" variant="outline">Moving</tp-badge></tp-list-item>\`;
list.defaultValue = [
  { id: 'v2-4', label: 'v2.4 Billing', status: 'Ready' },
  { id: 'v2-5', label: 'v2.5 Audit log', status: 'In review' },
  { id: 'v2-6', label: 'v2.6 SSO groups', status: 'Blocked' },

/>

`renderItem` draws each row from its item and a context, so rows can carry Badges and their own actions; a Button in the `actions` slot stays separately operable, and the context marks the copy shown while dragging so its controls can be disabled there. `renderOverlay` draws what follows the pointer, here a compact row marked as moving.

<Preview
  code={`<tp-drag-drop-list id="drag-drop-list-widgets" label="Dashboard widgets" variant="subdued" activation="item" reorder-mode="swap" style="max-inline-size:26rem"></tp-drag-drop-list>`}

By default only the handle starts a pointer drag, which keeps the text of a row selectable. When rows are tiles to rearrange rather than text to read, `activation="item"` lets the whole row start a drag, after a short delay or movement so clicks still work. `reorder-mode="swap"` exchanges two widgets instead of shifting everything between them, so the rest of the layout stays where people left it.

### Moving between lists

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-4);max-inline-size:40rem">
  <div id="drag-drop-list-lanes" style="display:grid;grid-template-columns:repeat(auto-fit,minmax(min(100%,16rem),1fr));gap:var(--tp-space-4)"></div>
  <tp-button id="drag-drop-list-promote" variant="outline" style="justify-self:start">Move first item to Ready</tp-button>
  <span id="drag-drop-list-lanes-status" role="status" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Drag a card between lanes.</span>
</div>`}
  script={`import { DragDropManager } from '@tweakpad/ui/drag-drop';

const lanes = document.getElementById('drag-drop-list-lanes');
const status = document.getElementById('drag-drop-list-lanes-status');
const manager = new DragDropManager();
const lane = (group, label, items) => {
  const list = document.createElement('tp-drag-drop-list');
  Object.assign(list, { manager, group, label, variant: 'outline', defaultValue: items });
  list.addEventListener('tp-value-commit', () => {
    status.textContent = backlog.label + ': ' + backlog.value.length + ' · ' + ready.label + ': ' + ready.value.length;
  });
  lanes.append(list);
  return list;
};
const backlog = lane('backlog', 'Backlog', [
  { id: 'invoices', label: 'PDF invoices' },
  { id: 'sso', label: 'SAML single sign-on' },
  { id: 'audit', label: 'Audit log export' },
]);
const ready = lane('ready', 'Ready', []);
document.getElementById('drag-drop-list-promote').addEventListener('click', () => {
  const first = backlog.value[0];
  if (first) backlog.moveItem(first.id, { list: ready, index: ready.value.length });
});`}
/>

Lists that share one `DragDropManager` from `@tweakpad/ui/drag-drop`, each with a unique `group`, pass items between them, like the lanes of a board; an empty lane still accepts drops. `moveItem` performs the same move from code, for a menu action such as "Move to Ready" or for people who prefer not to drag across lanes. `type` and `accept` limit which items a list takes.

### State owned by the application

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-4);max-inline-size:40rem">
  <div id="drag-drop-list-owned" style="display:grid;grid-template-columns:repeat(auto-fit,minmax(min(100%,16rem),1fr));gap:var(--tp-space-4)"></div>
  <span id="drag-drop-list-owned-state" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm);font-family:var(--tp-font-mono)"></span>
</div>`}
  script={`import { DragDropManager } from '@tweakpad/ui/drag-drop';

const lanes = document.getElementById('drag-drop-list-owned');
const output = document.getElementById('drag-drop-list-owned-state');
const manager = new DragDropManager();
// The application's state; the lists only render it.
let state = {
  todo: [{ id: 'copy', label: 'Write launch copy' }, { id: 'qa', label: 'Regression pass' }],
  done: [{ id: 'pricing', label: 'Pricing page' }],
};
const show = () => {
  output.textContent = JSON.stringify({ todo: state.todo.map((i) => i.id), done: state.done.map((i) => i.id) });
};
const staged = new Map();
const lists = Object.keys(state).map((group) => {
  const list = document.createElement('tp-drag-drop-list');
  Object.assign(list, { manager, group, label: group === 'todo' ? 'To do' : 'Done', variant: 'outline', value: state[group] });
  list.addEventListener('tp-value-change', (event) => {
    if (event.defaultPrevented) return;
    const { operationId, sourceGroup, destinationGroup } = event.detail.metadata;
    const proposal = staged.get(operationId) ?? new Map();
    staged.set(operationId, proposal.set(group, event.detail.value));
    if ([sourceGroup, destinationGroup].every((lane) => proposal.has(lane))) {
      for (const member of lists) if (proposal.has(member.group)) member.value = proposal.get(member.group);
      staged.delete(operationId);
    }
  });
  list.addEventListener('tp-value-commit', () => {
    state = Object.fromEntries(lists.map((member) => [member.group, member.value]));
    show();
  });
  lanes.append(list);
  return list;
});
show();`}
/>

With `value` instead of `defaultValue`, the lists propose and your code decides. A move between lanes proposes one `tp-value-change` per lane with a shared operation id; stage both and publish both values synchronously to accept the move. Leaving them unpublished, or cancelling either event, rejects the whole move, so the lanes never disagree.

### Approving a drop

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-4);max-inline-size:40rem">
  <div id="drag-drop-list-teams" style="display:grid;grid-template-columns:repeat(auto-fit,minmax(min(100%,16rem),1fr));gap:var(--tp-space-4)"></div>
  <div id="drag-drop-list-decision" hidden>
    <div style="display:flex;flex-wrap:wrap;gap:var(--tp-space-2)">
      <tp-button id="drag-drop-list-approve" size="sm">Approve move</tp-button>
      <tp-button id="drag-drop-list-reject" size="sm" variant="outline">Reject</tp-button>
    </div>
  </div>
  <span id="drag-drop-list-teams-status" role="status" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Moving a teammate between teams needs approval.</span>
</div>`}
  script={`import { DragDropManager } from '@tweakpad/ui/drag-drop';

const status = document.getElementById('drag-drop-list-teams-status');
const decisionControls = document.getElementById('drag-drop-list-decision');
const manager = new DragDropManager();
for (const [group, label, items] of [
  ['design', 'Design team', [{ id: 'maya', label: 'Maya Chen' }, { id: 'omar', label: 'Omar Haddad' }]],
  ['platform', 'Platform team', [{ id: 'grace', label: 'Grace Kim' }]],
]) {
  const list = document.createElement('tp-drag-drop-list');
  Object.assign(list, { manager, group, label, variant: 'outline', defaultValue: items });
  document.getElementById('drag-drop-list-teams').append(list);
}
let decision;
manager.monitor.addEventListener('dragend', (event) => {
  if (event.canceled) return;
  decision = event.suspend();
  decisionControls.hidden = false;
  status.textContent = 'Waiting for approval…';
});
manager.monitor.addEventListener('settled', (event) => {
  decision = undefined;
  decisionControls.hidden = true;
  status.textContent = 'Drop ' + event.outcome + '.';
});
document.getElementById('drag-drop-list-approve').addEventListener('click', () => decision?.resume());
document.getElementById('drag-drop-list-reject').addEventListener('click', () => decision?.abort());`}
/>

When a drop needs a server check or a person's approval, suspend it in `dragend`: the dragged row stays where it was dropped and nothing commits until you resume or abort the returned decision. The drop then settles as committed or rejected, and a rejected drop returns the row to its place.

### Variants

<Preview
  code={`<div style="display:grid;grid-template-columns:repeat(auto-fit,minmax(14rem,1fr));gap:var(--tp-space-6);max-inline-size:48rem">
  <tp-drag-drop-list id="drag-drop-list-ghost" label="Table columns"></tp-drag-drop-list>
  <tp-drag-drop-list id="drag-drop-list-outline" label="Table columns" variant="outline"></tp-drag-drop-list>
  <tp-drag-drop-list id="drag-drop-list-subdued" label="Table columns" variant="subdued"></tp-drag-drop-list>
</div>`}
  script={`for (const id of ['drag-drop-list-ghost', 'drag-drop-list-outline', 'drag-drop-list-subdued']) {
  const authored = document.getElementById(id);
  const list = authored.cloneNode();
  list.defaultValue = [
    { id: 'customer', label: 'Customer' },
    { id: 'status', label: 'Status' },
    { id: 'amount', label: 'Amount' },
  ];
  authored.replaceWith(list);
}`}
/>

The default rows have no boundary and suit a list inside a card or a panel; `outline` draws each row as its own block, for a list standing alone on a page; `subdued` fills the rows quietly, for side panels and settings. `size` steps the rows down for dense surfaces.

## Keyboard

| Key | Action |
| --- | --- |
| <Keys keys="space" /> <Keys keys="enter" /> | On a handle, pick the item up; while moving, drop it |
| <Keys keys="up" /> <Keys keys="down" /> | Move the picked-up item in a vertical list |
| <Keys keys="left" /> <Keys keys="right" /> | Move the picked-up item in a horizontal list, following the writing direction |
| <Keys keys="escape" /> | Cancel the move and restore the order |
| <Keys keys="tab" /> | Drop the item and continue to the next focusable element |
