## Usage

A Key hint describes a shortcut; the application implements it. Draw one Key hint per key inside a Key hint group, which spaces the keys and puts separators between them. A generated key such as `mod` draws the notation of the reader's platform, Command on macOS and Ctrl elsewhere, and gives assistive technology a readable name for it; `platform` pins one platform instead. A shortcut that matters belongs in the owning control's description or in prose as well, since a hint is easy to miss.

### Shortcuts in controls

<Preview
  code={`<tp-button variant="outline">
  Accept invite
  <tp-key-hint slot="icon-end" key="enter"></tp-key-hint>
</tp-button>
<tp-tooltip>
  <tp-button slot="trigger" variant="outline">Save</tp-button>
  Save changes
  <tp-key-hint-group separator="none">
    <tp-key-hint key="mod"></tp-key-hint>
    <tp-key-hint>S</tp-key-hint>
  </tp-key-hint-group>
</tp-tooltip>`}
/>

A hint inside a Button or a Tooltip stays informative: the control keeps focus and activation, and the keys take the colors of the surface they sit on.

### Search field shortcut

<Preview
  code={`<tp-input-group style="max-inline-size:22rem">
  <tp-input label="Search" type="search" placeholder="Jump to a project"></tp-input>
  <tp-key-hint-group slot="inline-end" separator="none">
    <tp-key-hint key="mod"></tp-key-hint>
    <tp-key-hint>P</tp-key-hint>
  </tp-key-hint-group>
</tp-input-group>`}
/>

In an Input group the shortcut goes in an addon slot; the group lays out the addon, and the Key hint group spaces the keys.

### Two-step shortcut

<Preview
  code={`<tp-key-hint-group separator="then" label="Comment on selection">
  <tp-key-hint-group separator="none">
    <tp-key-hint key="mod"></tp-key-hint>
    <tp-key-hint>K</tp-key-hint>
  </tp-key-hint-group>
  <tp-key-hint-group separator="none">
    <tp-key-hint key="mod"></tp-key-hint>
    <tp-key-hint>C</tp-key-hint>
  </tp-key-hint-group>
</tp-key-hint-group>`}
/>

Groups nest: a sequence group says "then" between two chords, and each chord sets its own separator. A `label` on the outer group names the shortcut for assistive technology.

### Moving through results

<Preview
  code={`<p id="key-hint-arrows" style="margin:0;display:flex;flex-wrap:wrap;align-items:center;gap:var(--tp-space-2)">
  Move between results with
  <tp-key-hint-group separator="none">
    <tp-key-hint label="Up arrow"><tp-icon data-icon="up"></tp-icon></tp-key-hint>
    <tp-key-hint label="Down arrow"><tp-icon data-icon="down"></tp-icon></tp-key-hint>
  </tp-key-hint-group>
  and open with
  <tp-key-hint label="Return"><tp-icon data-icon="return"></tp-icon></tp-key-hint>
</p>`}
  script={`import { arrowUpIcon, arrowDownIcon } from '@tweakpad/ui/icons/arrows';
import { cornerDownLeftIcon } from '@tweakpad/ui/icons/link';

const icons = { up: arrowUpIcon, down: arrowDownIcon, return: cornerDownLeftIcon };
for (const icon of document.querySelectorAll('#key-hint-arrows tp-icon')) icon.icon = icons[icon.dataset.icon];`}
/>

The content of a key replaces the generated notation, so it can hold an Icon, which takes the key's icon size. An icon key needs a `label` to be named.

### Localized shortcut

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-4);justify-items:start">
  <p style="margin:0">
    Commenter :
    <tp-key-hint-group id="key-hint-french" separator="then" platform="windows" label="Commenter la sélection">
      <tp-key-hint-group separator="none"><tp-key-hint key="control"></tp-key-hint><tp-key-hint>K</tp-key-hint></tp-key-hint-group>
      <tp-key-hint-group separator="none"><tp-key-hint key="control"></tp-key-hint><tp-key-hint>C</tp-key-hint></tp-key-hint-group>
    </tp-key-hint-group>
  </p>
  <div dir="rtl" lang="ar" style="display:flex;align-items:center;gap:var(--tp-space-3)">
    <span>اضغط
      <tp-key-hint-group separator="none"><tp-key-hint key="mod"></tp-key-hint><tp-key-hint>K</tp-key-hint></tp-key-hint-group>
      للبحث</span>
    <tp-button variant="outline">إرسال<tp-key-hint slot="icon-end" key="enter" label="إدخال"></tp-key-hint></tp-button>
  </div>
</div>`}
  script={`await customElements.whenDefined('tp-key-hint-group');
document.getElementById('key-hint-french').keyLabels = {
  control: { text: 'Ctrl', label: 'Contrôle' },
  then: 'puis',
};`}
/>

Key labels on a group replace the visible text and the spoken name of the generated keys inside it, and translate the word between the steps of a sequence. Spacing is logical, so hints follow right-to-left text; set `dir="ltr"` on a group when the notation must keep its left-to-right order.
