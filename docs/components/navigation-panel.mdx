## Usage

Use a Navigation panel for the persistent navigation of an application: the destinations people move between all day, beside the page they are working on. The panel owns layout and state: the navigation in a sticky column, your page in the inset, and a trigger that toggles between them. Links are real anchors, so mark the current page with `active`; groups, menus and items give the list its structure, and a screen reader hears it as one navigation landmark.

The panel has no built-in breakpoint. `compact="false"` states that a panel is in wide mode; set `compact` from your own layout logic, or give the panel a `responsiveAdapter` that observes the viewport and reports when to switch. Here the panel collapses to an icon rail, and each link's `tooltip` names it while only its icon shows.
