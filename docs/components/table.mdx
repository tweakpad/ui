## Usage

Use a Table to read and compare records across columns. Each part renders its native table element, so column layout, `colspan`, `rowspan` and header relationships work as in plain HTML: a `tp-table-head` with `scope="row"` names its row, and the caption names the table. A Table has no grid keyboard model; people tab between the controls placed in its cells, and when the data needs cell-by-cell navigation or sorting state, build that around it.
