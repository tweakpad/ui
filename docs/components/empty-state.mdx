## Usage

Use an Empty state where a list, table or search would otherwise render nothing. Say what is missing in `title`, why or what to do next in `description`, and offer the action that fills the view. Group several actions in one element in the `actions` slot. The component is presentational: it owns no value, events or form state. Empty media, descriptions and action regions collapse.

### Media

Put an icon, illustration or avatar group in the `media` slot. `media-treatment="icon"` sizes a single glyph for the icon role; the default `plain` shows the media as authored, which suits illustrations or avatars. Mark decorative media `aria-hidden`. Decorate repeated illustrations with `aria-hidden`; give meaningful images alt text.

### Search recovery

Default content sits between the description and the actions. Use it for recovery that is more than a button, such as a new search, so people stay on the page instead of starting over.

### Inside a surface

Empty states inherit their container's background, so they sit naturally inside a Card or a table body. Omit actions when the state is terminal and nothing can change it.

### Surface styles

The component paints no surface of its own. Style its `empty-state` part for a border, a dashed drop-zone outline or a muted fill. Use the `description` slot when the description needs a link.
