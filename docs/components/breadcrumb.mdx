## Usage

Put each step in as a direct child: native links for the ancestors and a plain element for the current page, which is marked as the current page for assistive technology. Links keep their destinations, modified clicks and listeners, so the trail works with or without a router. Give the landmark its own `label` when the page has more than one navigation.

### File path

<Preview
  code={`<tp-breadcrumb label="File path" separator="/">
  <a href="#breadcrumb-workspace">northwind</a>
  <a href="#breadcrumb-repo">web-app</a>
  <a href="#breadcrumb-src">src</a>
  <span>README.md</span>
</tp-breadcrumb>`}
/>

The chevron between steps mirrors in right-to-left layouts; `separator` swaps it for text, such as the slash readers expect in a path. Separators are hidden from assistive technology either way.

Collapsing a long trail is the application's choice. When the hidden pages must stay reachable, a named Button opens a Menu of their links. When they are reachable another way, such as from the account menu, a decorative mark stands in for them: it gets separators like any step, but screen readers skip it and it never takes focus.

### Ancestor menu

<Preview
  code={`<tp-breadcrumb label="Settings" separator="/">
  <a href="#breadcrumb-acme">Acme</a>
  <tp-menu label="Settings sections" placement="block-end start">
    <tp-button slot="trigger" variant="ghost" size="sm">
      Settings
      <tp-icon slot="icon-end" id="breadcrumb-sections-icon"></tp-icon>
    </tp-button>
    <a href="#breadcrumb-general" close-on-click>General</a>
    <a href="#breadcrumb-members" close-on-click>Members</a>
    <a href="#breadcrumb-billing-menu" close-on-click>Billing</a>
  </tp-menu>
  <span>Security</span>

  script={`import { chevronDownIcon } from '@tweakpad/ui/icons/chevron-down';

An ancestor can open a menu of its sibling sections, so readers move sideways without going up a level first. The trigger keeps the ancestor's own name, and the chevron says it opens a list.

### Responsive collapse

<Preview
  code={`<tp-breadcrumb label="Documentation">
  <a href="#breadcrumb-docs-home">Docs</a>
  <span id="breadcrumb-responsive">
    <tp-menu label="Hidden pages" placement="block-end start">
      <tp-button slot="trigger" variant="ghost" size="icon-sm">
        <tp-icon slot="icon-start" id="breadcrumb-menu-icon"></tp-icon>
        Show 3 hidden pages
      </tp-button>
      <a href="#breadcrumb-r-guides" close-on-click>Guides</a>
      <a href="#breadcrumb-r-data" close-on-click>Data</a>
      <a href="#breadcrumb-r-fetching" close-on-click>Fetching</a>
    </tp-menu>
    <tp-drawer label="Go to" description="Pages above Caching in the docs." hidden>
      <tp-button slot="trigger" variant="ghost" size="icon-sm">
        <tp-icon slot="icon-start" id="breadcrumb-drawer-icon"></tp-icon>
        Show 3 hidden pages
      </tp-button>
      <nav style="display:grid;gap:var(--tp-space-2)">
        <a href="#breadcrumb-r-guides">Guides</a>
        <a href="#breadcrumb-r-data">Data</a>
        <a href="#breadcrumb-r-fetching">Fetching</a>
      </nav>
      <tp-button slot="close" variant="outline">Close</tp-button>
    </tp-drawer>
  </span>
  <a href="#breadcrumb-r-caching">Caching</a>
  <span>Revalidating</span>
</tp-breadcrumb>`}
  script={`import { navigationIcons } from '@tweakpad/ui/icons/navigation';

document.getElementById('breadcrumb-menu-icon').icon = navigationIcons.more;
document.getElementById('breadcrumb-drawer-icon').icon = navigationIcons.more;
await customElements.whenDefined('tp-drawer');
const host = document.getElementById('breadcrumb-responsive');
const menu = host.querySelector('tp-menu');
const drawer = host.querySelector('tp-drawer');
const wide = matchMedia('(min-width: 48rem)');
const update = () => {
  if (!host.isConnected) return wide.removeEventListener('change', update);
  const [active, inactive] = wide.matches ? [menu, drawer] : [drawer, menu];
  inactive.setOpen(false);
  inactive.hidden = true;
  active.hidden = false;
};
wide.addEventListener('change', update);
update();
drawer.addEventListener('click', (event) => {
  if (event.target.closest?.('nav a')) drawer.setOpen(false);
});`}
/>

On a phone, a drawer of hidden pages is easier to tap than a menu. The trail stays the same; the application picks the surface for the viewport, here at 48rem, and each surface keeps its own focus and dismissal.

### Long trail

<Preview
  code={`<tp-breadcrumb label="Product category" style="max-inline-size:20rem">

In a narrow column the trail wraps instead of overflowing. Collapse ancestors when a wrapped trail would push the page content too far down.
