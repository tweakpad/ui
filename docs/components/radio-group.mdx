## Usage

Use a Radio Group when every option should stay visible and exactly one applies. For long lists, use Select; for an on/off setting, use Switch. The group owns the value and the single tab stop; each `tp-radio-group-item` supplies a `value` and its label as content.

Press/Space selects; pressing the selected item does not clear it. Enter does not select. Arrow keys follow orientation and writing direction, wrap and skip disabled items, and select the focused Radio; consumed keys and arrows carrying Alt, Ctrl or Meta are left to the browser. Home/End choose the first/last eligible Radio. One selected enabled Radio is the tab stop, otherwise the first enabled Radio is; Tab leaves the group.

### Labelling

A Field provides the visible label, description and error. Without one, give the group a `label` so it still has an accessible name.

### Orientation

`orientation="horizontal"` lays items in a row and switches the arrow keys to Left and Right. Keep horizontal groups to a few short labels.

<Preview
  title="Horizontal"

    <tp-radio-group-item value="yearly">Yearly</tp-radio-group-item>

### Disabled and read-only

Disable one item when its option is temporarily unavailable, or the whole group when the choice does not apply. Arrow keys skip disabled items.

### Controlled

Set `value` to own the selection and accept each proposal in `onValueChange`; an empty value starts with nothing selected. Because your code holds the value, it can also change it from elsewhere, such as a recommendation.

The first update fixes controlled versus uncontrolled ownership. Cancel with `event.preventDefault()` or `event.detail.cancelled = true`.

<Preview
  title="Controlled value"
  code={`<div id="radio-group-controlled" style="display:grid;gap:var(--tp-space-4);justify-items:start">
  <tp-field label="Delivery">
    <tp-radio-group value="">
      <tp-radio-group-item value="standard">Standard · 3–5 days · Free</tp-radio-group-item>
      <tp-radio-group-item value="express">Express · Next day · $9</tp-radio-group-item>
      <tp-radio-group-item value="pickup">Pick up in store · Today</tp-radio-group-item>
    </tp-radio-group>
  </tp-field>
  <tp-button variant="outline" size="sm" data-recommend>Choose the fastest for my address</tp-button>
</div>`}
  script={`const root = document.querySelector('#radio-group-controlled');
const group = root.querySelector('tp-radio-group');
group.onValueChange = (event) => {
  if (event.defaultPrevented || event.detail.cancelled) return;
  group.value = event.detail.value;
};
root.querySelector('[data-recommend]').addEventListener('click', () => {
  group.value = 'pickup';
});`}
/>

### Forms

The group submits once under its `name`, or the Field's. `required` blocks submission while nothing is chosen, and reset restores `default-value`.

The group submits once only while a matching eligible Radio is mounted. String/number/Boolean values stringify; object values use JSON serialization while selection uses identity. Unmatched values remain stored, render no selection and fail required validity; matching remounts restore the checked presentation. Read-only retains submission; disabled omits it.

### Value changes

`tp-value-change` reports each selection with its `reason`. Arrow keys select as they move, so listen to this event rather than to clicks.

<Preview
  title="Value change"
  code={`<div style="display:grid;gap:var(--tp-space-3);justify-items:start">
  <tp-radio-group id="radio-group-size" label="Team size" default-value="small" orientation="horizontal">
    <tp-radio-group-item value="solo">Just me</tp-radio-group-item>
    <tp-radio-group-item value="small">2–10</tp-radio-group-item>
    <tp-radio-group-item value="large">11+</tp-radio-group-item>
  </tp-radio-group>
  <output id="radio-group-size-output" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Selected: small</output>
</div>`}
  script={`const group = document.querySelector('#radio-group-size');
const output = document.querySelector('#radio-group-size-output');
group.addEventListener('tp-value-change', (event) => {
  if (event.target !== group || event.detail.cancelled) return;
  output.textContent = 'Selected: ' + event.detail.value;
});`}
/>
