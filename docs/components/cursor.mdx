## Usage

Use a Cursor on portfolios, galleries and landing pages, not on dense application screens. Place one anywhere: it takes no space and draws in the top layer, so dialogs and menus never cover it. By default it replaces the pointer on the whole page; every example here limits it to its parent element with `scope="region"`, so the rest of the page keeps the system pointer.

The cursor is decorative: it is hidden from assistive technology and never a hit target, so focus order and activation are unchanged. Touch and other coarse pointers never engage it. Under reduced motion it stays but follows the pointer instantly, and its changes between zones are immediate.

### Media and drag targets

/>

A Cursor zone around content changes the cursor while the pointer is inside it, without changing the content's own box. Its state is reported with `tp-cursor-state-change`, the cursor's custom properties set on the zone are adopted while it is active, and a `<template>` child replaces the cursor's content with a label, a Badge or an icon; keep that content non-interactive. `--tp-cursor-blend: difference` inverts the cursor over what is beneath it, so a white cursor stays visible on light and dark areas alike. `for` names the one cursor a zone addresses; without it, a zone addresses every cursor. Nested zones work, and the innermost wins.

### Navigation that pulls the cursor

  align="stretch"
  code={`<div style="display:flex;flex-wrap:wrap;gap:var(--tp-space-4);padding:var(--tp-space-8) var(--tp-space-6);border:var(--tp-border-width) dashed var(--tp-border);border-radius:var(--tp-radius-xl)">

  <tp-cursor-zone for="cursor-stick" stick="bounds"><tp-button variant="ghost">Pricing</tp-button></tp-cursor-zone>
  <tp-cursor-zone for="cursor-stick" stick="bounds"><tp-button variant="ghost">Customers</tp-button></tp-cursor-zone>
  <tp-cursor-zone for="cursor-stick" stick="center" damping="40" style="--tp-cursor-size:var(--tp-space-12)"><tp-button>Start free trial</tp-button></tp-cursor-zone>
</div>`}
/>

A sticky zone pulls the cursor toward its target through the same spring: to its center, or around its bounds, where the default ring morphs into the target's rectangle. A zone can carry its own physics while it is active. The bounds come from the zone's element children, so a zone around bare text sticks to nothing.

### A dot and a trailing ring

<Preview
  align="stretch"
  code={`<div style="display:grid;place-items:center;min-block-size:12rem;padding:var(--tp-space-6);border:var(--tp-border-width) dashed var(--tp-border);border-radius:var(--tp-radius-xl)">
  <tp-cursor id="cursor-dot" scope="region" stiffness="900" damping="50">
    <span style="display:block;inline-size:var(--tp-space-2);block-size:var(--tp-space-2);border-radius:var(--tp-radius-full);background:currentcolor"></span>
  </tp-cursor>
  <tp-cursor id="cursor-ring" scope="region" stiffness="120" damping="16" style="--tp-cursor-size:var(--tp-space-10)"></tp-cursor>
  <tp-cursor-zone for="cursor-ring" state="grow" style="--tp-cursor-size:var(--tp-space-16);--tp-cursor-opacity:0.5">
    <tp-button variant="outline">Only the ring reacts</tp-button>
  </tp-cursor-zone>
</div>`}
/>

Content in the cursor replaces the default ring. Several cursors can share a region with their own physics: a stiff, well-damped spring keeps the dot on the pointer, while a softer, lighter-damped one makes the ring lag and overshoot. A zone that names one of them changes only that one. The frame loop stops once a cursor rests and starts again when the pointer moves.

A `native` zone gives the system pointer back and hides the cursor. Put one around text entry, embedded documents, players and anything else where people need to see exactly where they point.

### A busy page

<Preview
  align="stretch"
  code={`<div id="cursor-state" style="display:grid;justify-items:start;gap:var(--tp-space-4);padding:var(--tp-space-8) var(--tp-space-6);border:var(--tp-border-width) dashed var(--tp-border);border-radius:var(--tp-radius-xl)">
  <style>
    #cursor-state tp-cursor[data-cursor-state="loading"] { --tp-cursor-size: var(--tp-space-12); --tp-cursor-opacity: 0.4; }
    #cursor-state tp-cursor[data-cursor-state="blocked"] { --tp-cursor-color: var(--tp-destructive); --tp-cursor-radius: var(--tp-radius-sm); }
  </style>
  <tp-cursor id="cursor-busy" scope="region"></tp-cursor>
  <tp-toggle-group id="cursor-states" label="Cursor state" variant="outline">
    <tp-toggle value="loading">Loading</tp-toggle>
    <tp-toggle value="blocked">Blocked</tp-toggle>
  </tp-toggle-group>
</div>`}
  script={`const cursor = document.getElementById('cursor-busy');
document.getElementById('cursor-states').addEventListener('tp-value-change', (event) => {
  cursor.setState(event.detail.value[0] ?? null);
});`}
/>

`setState()` gives the cursor a state of the application's own, such as loading, that lasts until it is cleared with `null` or a zone takes over; style each state through the cursor's state attribute. `tp-cursor-state-change` fires before every change, from a zone or from script, and can be canceled to keep the current state.
