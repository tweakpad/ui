## Usage

Set the timeline's `value` to the current item's `value`: earlier items become complete, later ones upcoming, and the connectors fill up to the current step. Status is also given as visually hidden text, never by color alone. Timeline is display-only; links and buttons inside items keep their own behavior.

Duplicate non-empty values dispatch one `tp-diagnostic` warning; the first matching item is current. Timeline is display-only: it adds no focus stop, keyboard handling or selection, and dispatches no change events.

The host has the `list` role (set as an attribute unless you supply one), so `aria-label` and `aria-labelledby` name it directly. The timeline sets `role="listitem"` on each item, and `aria-current="step"` on the first current item. The dot and connectors are hidden from assistive technology.

### Horizontal

`orientation="horizontal"` lays items along the inline axis, sharing the width equally. `responsive` switches from vertical to horizontal above a 40rem container.

### Markers

The `marker` slot replaces the dot with a number, an Icon or an Avatar. Hide a visible step number from assistive technology, since the list already conveys position. The marker box is at least one line tall and centers its content, so a dot, an icon or a number sits on the first line of the item's content. Larger markers, such as an Avatar, align with the start of the content. When the first line of content is inset, add the inset to `--tp-timeline-marker-offset`.

### Sides

`align` puts content on the `end` side (default), the `start` side, or alternating sides. An item's own `align` overrides its position, so a conversation keeps each author on one side. For per-item sides, use `align="alternate"` on the timeline so that both sides get equal space.

Sides are logical. In a vertical timeline, start and end are the inline start and end and mirror in right-to-left text. In a horizontal timeline, start is above the axis and end below, and items run in the inline direction, so a right-to-left timeline runs right to left. A vertical alternating timeline puts every item on the end side below 40rem.

### Logs and changelogs

Without a `value`, items have no status and stay neutral. The `opposite` slot holds content on the other side of the axis, such as a version or a date.

### Item status

An item's `status` overrides only its own derived status, for statuses set item by item or a step that was skipped.
