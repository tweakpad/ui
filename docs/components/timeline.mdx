## Usage

A Timeline shows where something stands in a sequence: an order, a release, a setup, a project. Set its `value` to the current item's `value`, and the items before it read as complete, the ones after it as upcoming, with the line filled up to the current step. Each status is also spoken as text, never carried by color alone. The Timeline is display-only: it adds no focus stop, and links, buttons and Collapsibles inside items keep their own behavior. Name it with `aria-label`, since it is announced as a list.

A horizontal Timeline lays a few short steps along the width, sharing it equally. The responsive orientation is vertical in a narrow container and horizontal from 40rem up, for a tracker that has to work in a sidebar and in a page.

Alternating items take turns above and below the axis, so longer entries get twice the room, and every marker stays on the axis however tall its content is. Items keep a minimum width; when they no longer fit, the Timeline overflows, so a long one sits in a horizontal Scroll area.

The `marker` slot replaces the dot with a number, an Icon or an Avatar, centered on the first line of the content. Hide a visible step number from assistive technology: the list already says which item this is.

A log has no current step, so it takes no `value` and its items stay neutral. The `opposite` slot puts a version or a date across the axis from the entry.

### Incident response

<Preview
  code={`<tp-timeline aria-label="Incident response" style="max-inline-size:22rem">
  <tp-timeline-item status="complete"><strong>Alert acknowledged</strong><div style="color:var(--tp-muted-foreground)">09:12</div></tp-timeline-item>
  <tp-timeline-item status="complete"><strong>Rollback deployed</strong><div style="color:var(--tp-muted-foreground)">09:31</div></tp-timeline-item>
  <tp-timeline-item status="current"><strong>Monitoring</strong><div style="color:var(--tp-muted-foreground)">Error rate back to baseline</div></tp-timeline-item>
  <tp-timeline-item status="upcoming"><strong>Postmortem</strong><div style="color:var(--tp-muted-foreground)">Due Friday</div></tp-timeline-item>
</tp-timeline>`}
/>

When the statuses come from the data item by item, set each item's `status` instead of a `value` on the Timeline. An item's own status also overrides the one its position gives it, for a step that was skipped.
