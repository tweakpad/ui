## Usage

Use the Media player where the browser's own controls fall short: one look in every browser and theme, captions and chapters, shortcuts and live streams. Put a native `<video>` or `<audio>` element and one layout inside the player. The player owns a single media store: every control reads its state from it and changes playback through the same requests, so buttons, keys and gestures always agree. Controls the media or the browser cannot support, such as picture-in-picture in some browsers, hide themselves.

### Live events

<Preview
  align="stretch"
  code={`<tp-media-player id="media-player-live" content-title="Launch keynote" style="max-inline-size:44rem">
  <tp-media-video-layout></tp-media-video-layout>
</tp-media-player>`}
  script={`const player = document.getElementById('media-player-live');
const video = Object.assign(document.createElement('video'), {
  src: 'https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4',
  loop: true,
  playsInline: true,
  preload: 'auto',
  width: 1280,
  height: 720,
});
// Simulation only: real live media reports these members itself.
const seekableEnd = () => (video.seekable.length ? video.seekable.end(video.seekable.length - 1) : 0);
Object.defineProperties(video, {
  streamType: { get: () => 'live' },
  targetLiveWindow: { get: () => 20 },
  liveEdgeStart: { get: () => Math.max(0, seekableEnd() - 3) },
});
player.prepend(video);`}
/>

A stream is live when the media reports a live stream type or an infinite duration, and it has a rewind window when it reports a target live window. The video layout then switches to its live form: a live button that jumps to the edge and a timeline that spans only the window. Streaming engines report these through their media element; this example adds them to a looping clip to simulate a 20-second window.

### Streams with quality levels

<Preview
  align="stretch"
  code={`<tp-media-player
  id="media-player-tracks"
  content-title="Product walkthrough"
  poster="https://images.unsplash.com/photo-1498050108023-c5249f4df085?w=1280&q=80"
  style="max-inline-size:44rem"
>
  <video
    src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4"
    width="1280"
    height="720"
    preload="metadata"
    playsinline
  ></video>
  <tp-media-video-layout></tp-media-video-layout>
</tp-media-player>`}
  script={`const list = (items) => Object.assign(new EventTarget(), items, { length: items.length });

let selected = -1;
let active = 1;
const renditions = list([
  { id: '1080p', width: 1920, height: 1080, bitrate: 6_000_000 },
  { id: '720p', width: 1280, height: 720, bitrate: 3_000_000 },
  { id: '360p', width: 640, height: 360, bitrate: 800_000 },
]);
for (let index = 0; index < renditions.length; index++) {
  Object.defineProperty(renditions[index], 'active', { get: () => index === active });
}
Object.defineProperty(renditions, 'selectedIndex', {
  get: () => selected,
  set(index) {
    selected = index; // the streaming engine switches levels here
    if (index >= 0) active = index;
    renditions.dispatchEvent(new Event('change'));
    renditions.dispatchEvent(new Event('activechange'));
  },
});

const audioTracks = list([
  { id: 'main', kind: 'main', label: 'English', language: 'en' },
  { id: 'commentary', kind: 'commentary', label: 'Director commentary', language: 'en' },
]);
for (let index = 0; index < audioTracks.length; index++) {
  let enabled = index === 0;
  Object.defineProperty(audioTracks[index], 'enabled', {
    get: () => enabled,
    set(value) {
      if (enabled === value) return;
      enabled = value;
      audioTracks.dispatchEvent(new Event('change'));
    },
  });
}

await customElements.whenDefined('tp-media-player');
document.getElementById('media-player-tracks').mediaAdapter = { videoRenditions: renditions, audioTracks };`}
/>

Media without native rendition or audio-track lists, such as an adaptive streaming engine, supplies them through `mediaAdapter`. Each list is array-like and an event target, and renditions add a `selectedIndex` where `-1` means adaptive; the settings menu then gains Quality and Audio submenus. This mock records the selection without changing the video.

## Keyboard

With focus anywhere in the player:

| Key | Action |
| --- | --- |
| <Keys keys="space" /> <Keys keys="k" /> | Plays or pauses. |
| <Keys keys="right" /> <Keys keys="l" /> | Seeks forward by `seek-step`. |
| <Keys keys="left" /> <Keys keys="j" /> | Seeks back by `seek-step`. |
| <Keys keys="up" /> <Keys keys="down" /> | Raises or lowers the volume by `volume-step`. |
| <Keys keys="0" /> to <Keys keys="9" /> | Seeks to that tenth of the media, 0 being the start. |
| <Keys keys="home" /> <Keys keys="end" /> | Seeks to the start or the end. |
| <Keys keys=">" /> <Keys keys="<" /> | Speeds up or slows down playback by one step. |
| <Keys keys="m" /> | Mutes or unmutes. |
| <Keys keys="f" /> | Enters or leaves fullscreen. |
| <Keys keys="c" /> | Shows or hides captions. |
| <Keys keys="i" /> | Enters or leaves picture-in-picture. |

The shortcuts are published to assistive technology on each control and shown in the layout's tooltips. A Media hotkey with the same keys replaces a default, and `hotkeys="none"` keeps only the authored ones. `hotkey-scope="document"` routes keys from anywhere on the page to the most recently used player.
