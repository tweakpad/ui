## Usage

A Separator fills its container along its axis: the full width when horizontal, the full height when vertical. It reserves no spacing of its own, so the surrounding layout sets the gap on either side. Most rules only organize what is already grouped, so a Separator is decorative and hidden from assistive technology by default.

### Row actions

  code={`<div style="display:flex;align-items:center;gap:var(--tp-space-3);block-size:var(--tp-space-6)">

  <tp-separator orientation="vertical"></tp-separator>
  <tp-button variant="ghost" size="sm">Duplicate</tp-button>
  <tp-separator orientation="vertical"></tp-separator>
  <tp-button variant="ghost" size="sm">Archive</tp-button>
</div>`}
/>

A vertical Separator takes the height of its container, so give the row a block size or let a flex row stretch it.

### Order summary

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-4);inline-size:24rem;max-inline-size:100%">
  <div style="display:flex;justify-content:space-between">

    <strong>Team, billed yearly</strong>
  </div>
  <div style="display:flex;justify-content:space-between">
    <span>Seats</span>
    <strong>12 of 15</strong>
  </div>
  <tp-separator id="separator-total"></tp-separator>
  <div style="display:flex;justify-content:space-between">
    <span>Next invoice</span>
    <strong>$1,440.00 on March 1</strong>
  </div>
</div>`}
  script={`document.getElementById('separator-total').decorative = false;`}
/>

Here the rule separates the plan from what it costs, a boundary a screen reader user should hear as well. Turning `decorative` off announces the Separator with its orientation.
