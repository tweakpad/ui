## Usage

Set `value` to the exact text to copy. After a click the icon turns into a check, the accessible name becomes `copied-label` for `duration` milliseconds, and the result is announced politely. The control composes a Button, so focus, disabled and keyboard behavior are the Button's.

### Labels

Icon-only is the default, with `label` as the accessible name; make it specific, such as "Copy invite link", so it makes sense out of context. `show-label` renders the label as text, and the copied message replaces it while confirmed.

  title="Visible label"

### Variants and sizes

`variant` and `size` follow Button. The default `ghost` at `sm` fits beside inline values; reach for `outline` or `secondary` when copying is the main action.

### Events

`tp-copy` fires before the write and can be canceled to skip it. `tp-copied` and `tp-copy-error` report the outcome; both are already announced, so use them for analytics or follow-up UI rather than duplicate messages.

<Preview
  title="Copy events"
  code={`<div style="display:grid;gap:var(--tp-space-2);justify-items:center">
  <tp-copy-button id="copy-button-events" variant="outline" size="default" show-label value="npm install @tweakpad/ui" label="Copy install command"></tp-copy-button>
  <output id="copy-button-events-output" style="font-size:var(--tp-text-sm);color:var(--tp-muted-foreground)">Not copied yet</output>
</div>`}
  script={`const button = document.getElementById('copy-button-events');
const output = document.getElementById('copy-button-events-output');
button.addEventListener('tp-copied', (event) => {
  output.textContent = 'Copied "' + event.detail.value + '"';
});
button.addEventListener('tp-copy-error', () => {
  output.textContent = 'The browser blocked clipboard access';
});`}
/>

The Clipboard API is used where available, with a selection-based fallback; success is reported only after the write succeeds. `copy()` runs the same sequence from code and resolves to whether it worked.

### Copying more than text

`data` is a function that receives `value` and returns further representations keyed by media type, each a string, a `Blob` or a promise of either. They are written with `value` as `text/plain` in one clipboard item, so a paste target picks the type it understands: an image editor takes the picture and a text field takes the text. The function runs during the click, so return pending work as promises instead of awaiting it; browsers that tie clipboard access to the click (Safari) reject a write that starts later.

<Code code={`const button = document.querySelector('tp-copy-button');
button.value = 'https://example.com/invite/42';
button.data = () => ({ 'image/png': renderInviteCard() }); // renderInviteCard(): Promise<Blob>`} language="js" />

Types the browser cannot write are left out. When the browser refuses the item, the text alone is copied and `tp-copied` reports `types: ['text/plain']`. [QR code](../qr-code/) uses this to copy its image together with its value.
