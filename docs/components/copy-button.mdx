## Usage

Use a Copy button wherever people need a value somewhere else: a key, a link, an identifier or a command. Set `value` to the exact text to copy. After a press the Icon turns into a check, the button's name becomes the copied message for a moment, and the result is announced politely, so nobody has to wonder whether it worked. It composes a Button, so focus, disabled and keyboard behavior are the Button's. Icon-only is the default, with `label` as its accessible name; make it specific, such as "Copy invite link", so it makes sense out of context.

### Invite link

<Preview
  code={`<tp-copy-button variant="outline" size="default" show-label value="https://tweakpad.app/invite/k7Qm2x" label="Copy invite link" copied-label="Link copied"></tp-copy-button>`}
/>

When copying is the main action, as in a share dialog, `show-label` puts the label beside the Icon, and the copied message replaces it while confirmed.

In a Field group, as in an Input group's `action` slot, the Copy button joins the border of the editors beside it, and its `value` can combine their values into the text people paste elsewhere.

### Install command

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-2);justify-items:start">
  <tp-copy-button id="copy-button-install" variant="outline" size="default" show-label value="npm install @tweakpad/ui" label="Copy install command"></tp-copy-button>
  <output id="copy-button-install-output" style="font-size:var(--tp-text-sm);color:var(--tp-muted-foreground)">Not copied yet</output>
</div>`}
  script={`const button = document.getElementById('copy-button-install');
const output = document.getElementById('copy-button-install-output');
button.addEventListener('tp-copied', (event) => {
  output.textContent = 'Copied "' + event.detail.value + '"';
});
button.addEventListener('tp-copy-error', () => {
  output.textContent = 'The browser blocked clipboard access';
});`}
/>

`tp-copy` fires before the write and can be cancelled to skip it; `tp-copied` and `tp-copy-error` report the outcome only once the browser has answered. Both outcomes are already announced, so use the events for analytics or follow-up interface rather than a second message. `copy()` runs the same sequence from code and resolves to whether it worked.

`variant` follows the Button's. `ghost` is the default because a Copy button usually sits beside the value it copies and should not compete with it; `outline` or `secondary` suit a copy that is the main action.
