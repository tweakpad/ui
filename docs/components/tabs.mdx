## Usage

Each tab is a native button in the `tab` slot and each panel an element in the `panel` slot, matched by `value`. Tabs gives them their roles, links each tab to its panel and keeps one tab in the page's tab order; `label` names the tab list. Keep tabs for peers of equal weight that readers switch between; content that should be read in order belongs in sections, and disclosures that can be open together in an Accordion.

An inactive panel leaves the document after its exit and comes back when its tab is selected, so heavy content costs nothing while hidden. `keep-mounted` keeps a panel in the document, hidden and inert, for one whose form fields must still submit or whose draft must survive.

By default the arrow keys only move focus, and Enter or Space selects. When a panel is cheap to show, as a figure for each range is, `automatic` activation selects as focus moves, so readers flip through ranges with the arrows alone.

### Jumping to a tab

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-3)">
  <tp-tabs id="tabs-report" default-value="revenue" label="Monthly report">
    <button slot="tab" value="revenue">Revenue</button>
    <button slot="tab" value="orders">Orders</button>
    <button slot="tab" value="refunds">Refunds</button>
    <p slot="panel" value="revenue">$84,210 in September, up 6% on August.</p>
    <p slot="panel" value="orders">1,932 orders, 214 from new customers.</p>
    <p slot="panel" value="refunds">37 refunds totalling $2,940; 9 still pending.</p>
  </tp-tabs>
  <div style="display:flex;align-items:center;justify-content:space-between;gap:var(--tp-space-3)">
    <output id="tabs-report-status" aria-live="polite" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Showing revenue</output>
    <tp-button id="tabs-report-jump" variant="outline" size="sm">Review pending refunds</tp-button>
  </div>
</div>`}
  script={`const tabs = document.getElementById('tabs-report');
const status = document.getElementById('tabs-report-status');
tabs.addEventListener('tp-value-change', (event) => {
  if (event.target !== tabs) return;
  status.textContent = \`Showing \${event.detail.value}\`;
});
document.getElementById('tabs-report-jump').addEventListener('click', () => {
  tabs.setValue('refunds');
});`}
/>

Every selection is first proposed with a cancelable `tp-value-change`. `setValue()` sends a tab's value through the same proposal from code, here from a call to action elsewhere on the page, and returns whether it was accepted. Panels can hold controls that send their own change events, so check the event's target.

### Guarding unsaved edits

<Preview
  code={`<tp-tabs id="tabs-guard" value="profile" label="Account settings">
  <button slot="tab" value="profile">Profile</button>
  <button slot="tab" value="notifications">Notifications</button>
  <section slot="panel" value="profile" keep-mounted>
    <tp-card>
      <span slot="header">Profile</span>
      <span slot="description">Shown on comments and assignments.</span>
      <tp-field label="Display name">
        <tp-input id="tabs-guard-name" name="display-name" default-value="Maya Chen"></tp-input>
      </tp-field>
      <p id="tabs-guard-status" role="status" style="margin:0;color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)"></p>
      <div slot="footer" style="display:flex;gap:var(--tp-space-2)">
        <tp-button id="tabs-guard-save">Save</tp-button>
        <tp-button id="tabs-guard-discard" variant="ghost">Discard</tp-button>
      </div>
    </tp-card>
  </section>
  <section slot="panel" value="notifications">
    <tp-card>
      <span slot="header">Notifications</span>
      <span slot="description">Email me when someone mentions me or assigns me a task.</span>
    </tp-card>
  </section>
</tp-tabs>`}
  script={`const tabs = document.getElementById('tabs-guard');
const name = document.getElementById('tabs-guard-name');
const status = document.getElementById('tabs-guard-status');
await customElements.whenDefined('tp-input');
await name.updateComplete;
let saved = name.value;
tabs.onValueChange = (event) => {
  if (name.value !== saved) {
    event.preventDefault();
    status.textContent = 'Save or discard your changes before leaving Profile.';
    return;
  }
  status.textContent = '';
  tabs.value = event.detail.value;
};
name.addEventListener('input', () => {
  status.textContent = '';
});
document.getElementById('tabs-guard-save').addEventListener('click', () => {
  saved = name.value;
  status.textContent = 'Saved.';
});
document.getElementById('tabs-guard-discard').addEventListener('click', () => {
  name.setValue(saved);
  status.textContent = '';
});`}
/>

A `value` set from the start makes the selection the application's: each accepted proposal is written back to `value`, and a proposal that is cancelled or not written back keeps the current tab. Edit the name, then try to leave the tab. The profile panel keeps its place in the document, so the draft survives while another tab shows.

### Unavailable sections

<Preview
  code={`<tp-tabs default-value="details" label="Order">
  <button slot="tab" value="details">Details</button>
  <button slot="tab" value="shipping">Shipping</button>
  <button slot="tab" value="returns" aria-disabled="true">Returns</button>
  <p slot="panel" value="details">Order #10482, placed March 3.</p>
  <p slot="panel" value="shipping">Delivered March 6 by UPS.</p>
  <p slot="panel" value="returns">Returns open after delivery.</p>
</tp-tabs>`}
/>

`aria-disabled="true"` keeps a tab reachable with the arrow keys, so readers still learn that returns exist; native `disabled` takes it out of focus. Neither can be selected. `disabled` on Tabs itself locks the whole list, for example while the content behind it loads.

## Keyboard

| Key | Action |
| --- | --- |
| <Keys keys="right" /> <Keys keys="left" /> | Moves focus to the next or previous tab of a horizontal list, following the writing direction and wrapping at the ends. |
| <Keys keys="down" /> <Keys keys="up" /> | Moves focus to the next or previous tab of a vertical list. |
| <Keys keys="home" /> <Keys keys="end" /> | Moves focus to the first or the last tab. |
| <Keys keys="enter" /> <Keys keys="space" /> | Selects the focused tab. |
| <Keys keys="tab" /> | Leaves the list for the selected panel. |
