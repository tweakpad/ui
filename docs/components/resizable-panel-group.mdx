## Usage

Use a Resizable panel group when people decide how much room each region of a workspace gets: a navigation column beside a document, an editor above its output. One group owns the sizes of its panels; panels and handles are its direct children in order, and every pointer, keyboard and programmatic change goes through the same constraints. Give the group a size along its axis, and nest another group inside a panel for the other axis, as the reading pane above does.

Each handle is a focusable separator whose `label` names what it resizes ("Resize navigation"), so a screen reader user hears which panel changes. When a layout only needs a divider that never moves, use Separator.

### Editor with a file tree

  align="stretch"
  code={`<tp-resizable-panel-group style="block-size:12rem;border:var(--tp-border-width) solid var(--tp-border);border-radius:var(--tp-radius-lg)">
  <tp-resizable-panel default-size="25%" min-size="15%" max-size="40%">
    <div style="padding:var(--tp-space-4);font-size:var(--tp-text-sm)">Files</div>
  </tp-resizable-panel>
  <tp-resizable-handle label="Resize files" with-handle></tp-resizable-handle>
  <tp-resizable-panel min-size="20rem">
    <div style="padding:var(--tp-space-4);font-family:var(--tp-font-mono);font-size:var(--tp-text-sm)">checkout.tsx</div>
  </tp-resizable-panel>
</tp-resizable-panel-group>`}
/>

Bounds keep each region usable: the file tree stays between 15% and 40% of the group, and the editor never drops below 20rem whatever the window size. Sizes take percentages, pixels or other lengths, and a unitless value is a percentage. Double-clicking a handle restores its panel's default size.

### Collapsible sidebar

<Preview
  align="stretch"
  code={`<div style="display:grid;gap:var(--tp-space-3);justify-items:start">
  <tp-button id="resizable-panel-group-toggle" variant="outline" size="sm">Toggle channels</tp-button>
  <tp-resizable-panel-group style="inline-size:100%;block-size:12rem;border:var(--tp-border-width) solid var(--tp-border);border-radius:var(--tp-radius-lg)">
    <tp-resizable-panel id="resizable-panel-group-channels" default-size="25%" min-size="18%" collapsible>
      <div style="padding:var(--tp-space-4);font-size:var(--tp-text-sm)">Channels</div>
    </tp-resizable-panel>
    <tp-resizable-handle label="Resize channels" with-handle></tp-resizable-handle>
    <tp-resizable-panel min-size="40%">
      <div style="padding:var(--tp-space-4);font-size:var(--tp-text-sm)">#design-reviews</div>
    </tp-resizable-panel>
  </tp-resizable-panel-group>
</div>`}
  script={`await customElements.whenDefined('tp-resizable-panel');
const channels = document.getElementById('resizable-panel-group-channels');
document.getElementById('resizable-panel-group-toggle').addEventListener('click', () => {
  if (channels.isCollapsed()) channels.expand();
  else channels.collapse();
});`}
/>

A `collapsible` panel snaps closed when dragged below its minimum, and Enter on its handle toggles it, so a sidebar can get out of the way without a separate control. When the page has its own toggle, the panel's `collapse()` and `expand()` drive the same state, and expanding returns to the size it had before.

### Layout presets

<Preview
  align="stretch"
  code={`<div style="display:grid;gap:var(--tp-space-3)">
  <div style="display:flex;gap:var(--tp-space-2)">
    <tp-button id="resizable-panel-group-split" variant="outline" size="sm">Side by side</tp-button>
    <tp-button id="resizable-panel-group-focus" variant="outline" size="sm">Focus on code</tp-button>
  </div>
  <tp-resizable-panel-group id="resizable-panel-group-controlled" style="block-size:10rem;border:var(--tp-border-width) solid var(--tp-border);border-radius:var(--tp-radius-lg)">
    <tp-resizable-panel min-size="20%">
      <div style="padding:var(--tp-space-4);font-family:var(--tp-font-mono);font-size:var(--tp-text-sm)">checkout.tsx</div>
    </tp-resizable-panel>
    <tp-resizable-handle label="Resize preview" with-handle></tp-resizable-handle>
    <tp-resizable-panel min-size="15%">
      <div style="padding:var(--tp-space-4);font-size:var(--tp-text-sm)">Preview</div>
    </tp-resizable-panel>
  </tp-resizable-panel-group>
</div>`}
  script={`// Controlled sizes are set before the group first connects, so the script connects a copy.
await customElements.whenDefined('tp-resizable-panel-group');
const authored = document.getElementById('resizable-panel-group-controlled');
const group = authored.cloneNode(true);
group.sizes = ['50%', '50%'];
group.onSizesChange = (event) => {
  if (!event.defaultPrevented) group.sizes = event.detail.value;
};
authored.replaceWith(group);
document.getElementById('resizable-panel-group-split').addEventListener('click', () => {
  group.sizes = ['50%', '50%'];
});
document.getElementById('resizable-panel-group-focus').addEventListener('click', () => {
  group.sizes = ['80%', '20%'];
});`}
/>

When the layout belongs to application state, such as presets or a layout synced across windows, set `sizes` and accept each proposal by assigning it back; a proposal you do not publish leaves the previous layout in place, so a drag never fights the state.

### Remembering the layout

<Preview
  align="stretch"
  code={`<div style="display:grid;gap:var(--tp-space-3)">
  <tp-resizable-panel-group id="resizable-panel-group-saved" persistence-key="mail-layout" style="block-size:10rem;border:var(--tp-border-width) solid var(--tp-border);border-radius:var(--tp-radius-lg)">
    <tp-resizable-panel id="resizable-panel-group-folders" default-size="25%" min-size="15%">
      <div style="padding:var(--tp-space-4);font-size:var(--tp-text-sm)">Folders</div>
    </tp-resizable-panel>
    <tp-resizable-handle label="Resize folders" with-handle></tp-resizable-handle>
    <tp-resizable-panel id="resizable-panel-group-messages" min-size="30%">
      <div style="padding:var(--tp-space-4);font-size:var(--tp-text-sm)">Messages</div>
    </tp-resizable-panel>
  </tp-resizable-panel-group>
  <span style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Drag the handle, then reload the page.</span>
</div>`}
  script={`// The adapter is set before the group first connects, so the script connects a copy.
await customElements.whenDefined('tp-resizable-panel-group');
const authored = document.getElementById('resizable-panel-group-saved');
const group = authored.cloneNode(true);
group.persistenceAdapter = {
  load: (key) => {
    try {
      return JSON.parse(localStorage.getItem(key) ?? 'null');
    } catch {
      return null;
    }
  },
  save: (key, layout) => {
    try {
      localStorage.setItem(key, JSON.stringify(layout));
    } catch {}
  },
};
authored.replaceWith(group);`}
/>

With a `persistence-key` and an adapter that loads and saves, the group restores the saved layout when it connects and saves each layout once a drag settles, rather than on every frame. The layout is keyed by panel id, so give panels stable ids. The storage is yours: local storage, a user profile or a URL.

## Keyboard

| Key | Action |
| --- | --- |
| <Keys keys="left" /> <Keys keys="right" /> | Move the focused handle along a horizontal group, following the writing direction |
| <Keys keys="up" /> <Keys keys="down" /> | Move the focused handle along a vertical group |
| <Keys keys="home" /> <Keys keys="end" /> | Shrink or grow the handle's panel to its limit |
| <Keys keys="enter" /> | Collapse or expand the handle's panel, when it is collapsible |
| <Keys keys="f6" /> <Keys keys="shift+f6" /> | Move focus to the next or previous handle |
