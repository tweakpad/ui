## Usage

Use a Label when you lay out a control yourself. Inside a Field, the Field's `label` already renders and wires one, so a separate Label is only for a control outside a Field. Point `for` at the control's id, or nest the control inside the Label: either way the text becomes the control's accessible name, and a click on it focuses or activates the control.

### Settings toggle

<Preview
  code={`<tp-label style="align-items:center;gap:var(--tp-space-3)">
  <tp-switch default-checked></tp-switch>
  Send weekly usage reports
</tp-label>`}
/>

Nesting suits a compact control whose text sits beside it: the whole line is one click target, with no id to keep unique.

### Optional details

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-2)">
  <tp-label for="label-optional-email" optional>Billing email</tp-label>
  <tp-input id="label-optional-email" type="email" required placeholder="billing@northwind.co"></tp-input>
</div>
<div style="display:grid;gap:var(--tp-space-2)">
  <tp-label for="label-optional-company" optional>Company</tp-label>
  <tp-input id="label-optional-company" placeholder="Northwind Inc."></tp-input>
</div>
<div style="display:grid;gap:var(--tp-space-2)">
  <tp-label for="label-optional-vat" optional>VAT number</tp-label>
  <tp-input id="label-optional-vat" placeholder="GB 123 4567 89"></tp-input>
</div>`}
/>

Mark the few fields people may skip rather than every required one. The hint hides itself while the control is `required`, so a shared form template can set `optional` on every Label and let each control decide.
