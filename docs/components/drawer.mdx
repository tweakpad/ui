## Usage

Drawer is a Dialog attached to an edge of the viewport. It shares Dialog's slots (`trigger`, `title`, `description`, default body, `footer`, `close`), focus management and dismissal, and adds edge placement and swipe gestures. Swiping toward the closing edge dismisses it; the trigger and the close action keep working without gestures. Input controls, selection and native content scrolling keep their normal behavior. Touch dismissing waits for the content scroll edge. Footer content does not implicitly dismiss; use the close slot or `registerCloseAction`.

### Side panels

`edge` takes a logical edge, so `inline-end` is the right side in left-to-right pages and flips in right-to-left ones. Set `swipe-enabled="false"` for a desktop side panel that should not react to drags.

### Backdrop

`backdrop="blur"` keeps the dark fill and blurs the page behind it, which helps when the page content would compete with the drawer. It changes appearance only; `modality` decides whether a backdrop is shown at all. Dialog's `container` modality is not supported because Drawer geometry is viewport-relative; it normalizes to `modal` with a `drawer-modality-unsupported` diagnostic. Non-modal and focus-trap-only modes hide the backdrop and preserve outside pointer interaction. The fill uses `--tp-opacity-backdrop` and remains visible where backdrop filtering is unsupported.

<Preview

  </tp-field>

</tp-drawer>`}

### Snap points

Set `snapPoints` to let a sheet rest at partial heights. Numbers up to `1` are viewport fractions, larger numbers are pixels, and strings accept CSS lengths. With `show-swipe-handle`, the handle also works as a keyboard slider with the arrow keys, Home and End.

<Preview
  title="Snap points"
  code={`<tp-drawer id="drawer-demo-snap" label="Nearby places" description="12 results within 2 km." show-swipe-handle>
  <tp-button slot="trigger" variant="outline">Explore nearby</tp-button>
  <p style="margin:0">Drag the handle to expand the list, or release below the lowest point to close.</p>
  <tp-button slot="close" variant="outline">Done</tp-button>
</tp-drawer>`}
  script={`const drawer = document.querySelector('#drawer-demo-snap');
drawer.snapPoints = [0.25, 0.5, 1];
drawer.defaultSnapPoint = 0.5;`}
/>

`onSnapPointChange` receives each proposed snap point as a cancelable event, and `setSnapPoint()` moves the sheet from code.

### Nested drawers

Put a Drawer inside another Drawer's body to open a follow-up step on top of it. The parent stays open and recedes behind the new sheet; closing the child returns to the parent where it left off.

### Non-dismissible

Set the `dismissible` property to `false` when outside presses, Escape and swipes must not close the drawer, such as a required acknowledgement. The explicit close action still works.

<Preview
  title="Non-dismissible"
  code={`<tp-drawer id="drawer-demo-terms" label="Updated terms of service" description="Effective November 1, 2026.">
  <tp-button slot="trigger" variant="outline">Review terms</tp-button>
  <p style="margin:0">We changed how workspace data is retained after an account is closed. Review the summary before you continue.</p>
  <tp-button slot="close">I agree</tp-button>
</tp-drawer>`}
  script={`document.querySelector('#drawer-demo-terms').dismissible = false;`}
/>

### Optional constituents

- `tp-drawer-swipe-area`: a consumer-positioned opening region. Set `for` to a Drawer ID, `.owner` to a Drawer reference, or place it in that Drawer's swipe-area slot. `swipeDirection` defaults opposite the closing direction; `disabled` defaults false. Native host class/style and the drawer-swipe-area part configure its region; no forced page-sized hit area is added.
- `tp-drawer-provider`: optional common ancestor tracking open descendant Drawers. Nested Drawer lifecycle still belongs to Dialog. Removing the last Drawer clears active geometry.
- `tp-drawer-indent` and `tp-drawer-indent-background`: optional native layout regions inside the nearest provider. Detaching resets geometry and subscriptions. Indent does not invent a page transform by default.
- `tp-drawer-virtual-keyboard-provider`: optional ancestor that observes the real visual viewport, coalesces keyboard geometry and reveals an editable control inside the active descendant Drawer's existing scroll region. It restores geometry after keyboard dismissal and disconnects its observers when removed. It does not own focus or create a second scroller.

Provider and keyboard-provider render their children without layout boxes.
