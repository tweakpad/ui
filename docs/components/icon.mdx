## Usage

An Icon has no catalog of names: its `icon` property takes a definition, a `viewBox` and a list of paths. Import each definition from its own module, such as `@tweakpad/ui/icons/plus`, so a bundle carries only the artwork it draws; a few modules group a related set, such as the media controls or the text formatting marks. The artwork strokes in the current text color, so an Icon takes the color of the text around it, and its extent follows the control it sits in unless `size` sets one.

### Icon beside text

<Preview
  code={`<div style="display:flex;flex-wrap:wrap;align-items:center;gap:var(--tp-space-6)">
  <tp-button variant="outline">
    <tp-icon id="icon-new" slot="icon-start"></tp-icon>
    New project
  </tp-button>
  <span style="display:inline-flex;align-items:center;gap:var(--tp-space-2)">
    Maya Chen
    <tp-icon id="icon-verified" label="Verified" style="color:var(--tp-success)"></tp-icon>
  </span>
</div>`}
  script={`import { plusIcon } from '@tweakpad/ui/icons/plus';
import { circleCheckIcon } from '@tweakpad/ui/icons/circle-check';

document.getElementById('icon-new').icon = plusIcon;
document.getElementById('icon-verified').icon = circleCheckIcon;`}
/>

Without a `label` an Icon is decorative and hidden from assistive technology, which is right when the text beside it already says the same thing, as in the Button. When the icon is the only signal, as the mark after a verified name, a `label` gives it an image role and that name.

### Custom artwork

<Preview
  code={`<div style="display:flex;gap:var(--tp-space-5)">
  <tp-icon id="icon-star-outline" label="Not starred" size="1.5rem"></tp-icon>
  <tp-icon id="icon-star-solid" label="Starred" size="1.5rem" style="color:var(--tp-warning)"></tp-icon>
</div>`}
  script={`const star = 'm12 3 2.8 5.7 6.2.9-4.5 4.4 1.1 6.2L12 17.3 6.4 20.2l1.1-6.2L3 9.6l6.2-.9z';
document.getElementById('icon-star-outline').icon = {
  viewBox: '0 0 24 24',
  paths: [{ d: star, strokeWidth: 1.75 }],
};
document.getElementById('icon-star-solid').icon = {
  viewBox: '0 0 24 24',
  paths: [{ d: star, fill: 'currentColor', stroke: 'none' }],
};`}
/>

Your own marks are definitions too, never HTML strings, so they draw the same way as the library's. A path strokes in the current color with no fill by default; fill it with the current color and no stroke for a solid shape.
