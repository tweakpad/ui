## Usage

Chart draws lines, bars, lollipops, pies, radar shapes and radial rings itself when you set `type`, from `data` and keyed `series` (label and color), as in the sections below. It measures the plot, resolves series colors from the theme (`--tp-chart-1` to `--tp-chart-5` by default), and draws the tooltip and legend. For any other chart, set a `renderer` instead: the frame stays the same, and the tooltip and legend show what your renderer reports. Use plain SVG, as below, or wrap a charting library in the same adapter.

Series records accept `label`, an `IconDefinition` in `icon`, opaque `appearance`, and optional `color` or `theme: { light, dark }` colors.

A renderer is an object with `mount(plot, { inspect, legend })` that returns `{ update(snapshot), destroy() }`. `update` runs on resize, data and theme changes with the current `width`, `height`, `data`, `series`, `colors` and `interaction`; `destroy` removes your nodes and listeners.

<Preview
  width="7"
  title="Your own renderer"
  align="stretch"
  code={`<tp-chart id="chart-demo" label="Monthly revenue" description="Subscriptions grew every month from January to June; services peaked in April." interaction="both"></tp-chart>`}
  script={`const data = [
  { month: 'Jan', subscriptions: 42, services: 18 },
  { month: 'Feb', subscriptions: 48, services: 22 },
  { month: 'Mar', subscriptions: 55, services: 19 },
  { month: 'Apr', subscriptions: 61, services: 31 },
  { month: 'May', subscriptions: 66, services: 24 },
  { month: 'Jun', subscriptions: 74, services: 27 },
];
const svgNS = 'http://www.w3.org/2000/svg';
const node = (name, attributes = {}) => {
  const element = document.createElementNS(svgNS, name);
  for (const [key, value] of Object.entries(attributes)) element.setAttribute(key, value);
  return element;
};
/** A minimal grouped bar renderer. Geometry and marks belong to you, not the library. */
const barRenderer = {
  mount(plot, { inspect, legend }) {
    const svg = node('svg', { role: 'group', 'aria-label': 'Revenue by month, in thousands of dollars' });
    plot.append(svg);
    return {
      update({ width, height, data, series, colors, interaction }) {
        svg.setAttribute('viewBox', \`0 0 \${width} \${height}\`);
        svg.replaceChildren();
        const keys = Object.keys(series);
        const max = Math.ceil(Math.max(...data.flatMap((row) => keys.map((key) => row[key]))) / 20) * 20;
        const left = 44, bottom = height - 24, top = 8, plotHeight = bottom - top;
        for (let tick = 0; tick <= 4; tick++) {
          const y = bottom - (tick * plotHeight) / 4;
          svg.append(node('line', { x1: left, x2: width, y1: y, y2: y, stroke: 'var(--tp-border)', 'stroke-dasharray': tick ? '3 4' : '' }));
          const label = node('text', { x: left - 10, y: y + 4, 'text-anchor': 'end', 'font-size': 12, fill: 'currentColor' });
          label.textContent = '$' + (max * tick) / 4 + 'k';
          svg.append(label);
        }
        const band = (width - left) / data.length;
        data.forEach((row, index) => {
          const x = left + index * band;
          const label = node('text', { x: x + band / 2, y: height - 4, 'text-anchor': 'middle', 'font-size': 12, fill: 'currentColor' });
          label.textContent = row.month;
          svg.append(label);
          const group = node('g', {
            role: 'img',
            tabindex: interaction === 'focus' || interaction === 'both' ? 0 : -1,
            'aria-label': row.month + ': ' + keys.map((key) => series[key].label + ' $' + row[key] + 'k').join(', '),
          });
          group.style.outline = 'none';
          const hit = node('rect', { x: x + 4, y: top, width: band - 8, height: plotHeight, rx: 6, fill: 'transparent' });
          group.append(hit);
          const barWidth = Math.min(28, (band - 24) / keys.length);
          const start = x + (band - barWidth * keys.length) / 2;
          keys.forEach((key, i) => {
            const barHeight = (row[key] / max) * plotHeight;
            group.append(node('rect', { x: start + i * barWidth + 2, y: bottom - barHeight, width: barWidth - 4, height: barHeight, rx: 4, fill: colors[key] }));
          });
          const report = (active, source) => inspect(active ? {
            active: true, source, label: row.month,
            anchor: { getBoundingRectangle: () => hit.getBoundingClientRect(), contextElement: hit },
            payload: keys.map((key) => ({ dataKey: key, name: series[key].label, value: '$' + row[key] + 'k', color: colors[key], payload: row })),
          } : { active: false, source, payload: [] });
          const highlight = (on) => hit.setAttribute('fill', on ? 'var(--tp-muted)' : 'transparent');
          group.addEventListener('pointerenter', () => { highlight(true); report(true, 'pointer'); });
          group.addEventListener('pointerleave', () => { highlight(false); report(false, 'pointer'); });
          group.addEventListener('focus', () => { highlight(true); report(true, 'focus'); });
          group.addEventListener('blur', () => { highlight(false); report(false, 'focus'); });
          svg.append(group);
        });
        legend(keys.map((key) => ({ dataKey: key, value: series[key].label, color: colors[key] })));
      },
      destroy() { svg.remove(); },
    };
  },
};
const chart = document.querySelector('#chart-demo');
chart.series = {
  subscriptions: { label: 'Subscriptions', color: 'var(--tp-chart-1)' },
  services: { label: 'Services', color: 'var(--tp-chart-2)' },
};
chart.data = data;
chart.renderer = barRenderer;`}
/>

The initial dimensions are 320 × 200; ResizeObserver replaces them when the plot becomes measurable. Zero-sized parents retain the last nonzero dimensions. Adapter replacement and disconnect destroy the old instance; reconnect mounts a new one. Late callbacks from a destroyed instance are ignored.

### Inspection

`interaction` sets how people inspect values: `none`, `pointer`, `focus` or `both`. Your renderer calls `inspect()` with the active datum and the same payload for pointer and keyboard, and the component shows it in the library Tooltip. `tooltipOptions` adjusts that tooltip, for example `indicator: 'line'`, and `legendOptions` moves the legend to the `top`.

The Root composes `tp-tooltip`, retaining its positioning, lifecycle, Escape dismissal, and tooltip role. Inactive and empty payloads produce no content.

Formatters replace presentation, not series identity, payload ordering, or active state. Return text, Lit content, or library components; tooltip content must remain noninteractive.

### Accessible data

Every chart needs a text equivalent. `description` should state the takeaway, not restate the axes, and the `table` slot takes a `tp-table` with the complete dataset for people who can't read the graphic. Without either, the component reports a `tp-diagnostic`. Give each mark an accessible name too, and don't rely on color alone when series need telling apart.

### Bars and lines

Set `type` and the chart draws the marks itself: `line`, `bar` or `lollipop`. Each record in `data` is one position along the x axis, and each key of `series` is a field of the records drawn as one series. `x-axis` names the field that positions each record (`key`) and its scale: categories by default, or `number` or `time`. `stacked` piles the bars of each position, as in the chart at the top of this page, and `legendOptions.value` adds each series' `latest` value or its `sum` to the legend. Inspection shows a band behind bars and a crosshair over lines, with every series in the tooltip.

### Values below zero

Bars hang below a line at zero, and lollipops drop their stems to it. A series' `negativeColor` colors its values below zero, so gains and losses read apart at a glance; with one series, `legendOptions = false` leaves the legend out.

### Pies, rings and radar

`pie` draws one slice per series, `radial` one ring per series over a track, and both size each series by its total over the records, which is usually a single record. `radar` puts one spoke per record around the circle, named by the `x-axis` `key`, and draws a filled shape per series. `angle-range` sets where the marks start and end, in degrees clockwise from the top, so `-90 90` draws a half circle; `inner-radius` opens a hole in the middle, and the `center` slot places content there. A legend can stand in a column at the `start` or `end` of the plot under a `title`; `inline` labels each ring, or each line, on the marks themselves. `legendOptions.formatter` builds richer entries, such as a Progress meter per series.

    const entry = document.createElement('span');
    entry.style.cssText = 'display:grid;grid-template-columns:1fr auto;gap:4px 12px;flex:1';
    const name = document.createElement('span');
    name.textContent = label;
    const value = document.createElement('span');
    value.style.color = 'var(--tp-muted-foreground)';
    value.textContent = item.value.toLocaleString() + ' · ' + share + '%';
    const meter = document.createElement('tp-progress');
    meter.value = share;
    meter.label = label + ' share';
    meter.style.gridColumn = '1 / -1';
    meter.style.setProperty('--tp-primary', item.color);
    entry.append(name, value, meter);
    return entry;
  },
};`}

### Loading

While its data loads, `loading` shows placeholder marks in the shape of the chart, hides the values and the tooltip, and marks the chart busy for assistive technology. Clear it when the records arrive.
