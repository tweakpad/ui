## Usage

A Popover opens on press and holds content people work with: fields, choices, a short set of actions. The rest of the page stays usable, and the popup closes on Escape, an outside press or the action in its `close` slot. For read-only content, use Tooltip to describe a control or Preview Card to preview a link; for a task that needs the whole screen's attention, use Dialog.

### Notification preferences

<Preview
  code={`<tp-popover label="Notifications">
  <tp-button slot="trigger" variant="outline">Notifications</tp-button>
  <span slot="title">Notifications</span>
  <span slot="description">Choose what reaches your inbox.</span>
  <div style="display:grid;gap:var(--tp-space-3)">
    <tp-checkbox default-checked>Mentions and replies</tp-checkbox>
    <tp-checkbox default-checked>Weekly project digest</tp-checkbox>
    <tp-checkbox>Product announcements</tp-checkbox>
  </div>
</tp-popover>`}
/>

The `title` and `description` slots name and describe the popup for assistive technology; without a title, `label` names it. Choices like these apply as they change, so the popup needs no close action.

### Filters and quick edits

<Preview
  code={`<tp-popover label="Filter by status" placement="block-end start">
  <tp-button slot="trigger" variant="outline">Status</tp-button>
  <span slot="title">Filter by status</span>
  <tp-radio-group label="Status" default-value="open">
    <tp-radio-group-item value="open">Open</tp-radio-group-item>
    <tp-radio-group-item value="closed">Closed</tp-radio-group-item>
  </tp-radio-group>
</tp-popover>
<tp-popover label="Rename file" placement="inline-end center" show-arrow>
  <tp-button slot="trigger" variant="outline">Rename</tp-button>
  <tp-field label="File name">
    <tp-input default-value="Q3 roadmap.pdf"></tp-input>
  </tp-field>
</tp-popover>`}
/>

`placement` takes a side and an alignment in writing direction: a filter opens below its button, lined up with its start, and a quick edit beside the item it changes, with `show-arrow` pointing back at it. The popup flips to the other side when it would leave the viewport.

### Inviting teammates

<Preview
  code={`<tp-popover label="Invite teammates" modal>
  <tp-button slot="trigger">Invite teammates</tp-button>
  <span slot="title">Invite teammates</span>
  <span slot="description">They'll get an email with a link to join.</span>
  <tp-field label="Email">
    <tp-input type="email" placeholder="name@company.com"></tp-input>
  </tp-field>
  <tp-button slot="close">Send invite</tp-button>
</tp-popover>`}
/>

`modal` keeps focus inside the popup and makes the rest of the page inert while it is open, for a small task that should finish before anything else happens.

### Sync status

<Preview
  code={`<tp-popover label="Sync status" open-on-hover open-delay="200">
  <tp-button slot="trigger" variant="ghost">Synced 2 min ago</tp-button>
  <span slot="title">All changes saved</span>
  <span slot="description">Last synced from MacBook Pro at 14:32.</span>
  <tp-button slot="close" variant="outline" size="sm">Sync now</tp-button>
</tp-popover>`}
/>

With `open-on-hover` the popup also opens after the pointer rests on the trigger, which suits status details that people glance at. Focus alone does not open it, and a press pins a hover-opened popup so its action can be reached.

### Rescheduling a task

<Preview
  code={`<tp-popover label="Reschedule task" placement="block-end start" style="display:grid;justify-items:start;gap:var(--tp-space-3)">
  <tp-button slot="trigger" variant="outline" size="sm">Reschedule</tp-button>
  <div slot="anchor" style="display:flex;justify-content:space-between;gap:var(--tp-space-6);padding:var(--tp-space-3) var(--tp-space-4);border:var(--tp-border-width) solid var(--tp-border);border-radius:var(--tp-radius-lg);font-size:var(--tp-text-sm)">

    <span style="color:var(--tp-muted-foreground)">Due Oct 14</span>
  </div>
  <span slot="title">Reschedule task</span>
  <span slot="description">The popup lines up with the task row, not the button.</span>
  <tp-field label="New due date">
    <tp-input type="date" default-value="2026-10-21"></tp-input>
  </tp-field>
  <tp-button slot="close">Save</tp-button>
</tp-popover>`}
/>

The `anchor` slot positions the popup against another element than the one that opens it. The trigger still opens and closes it; the anchor only supplies the position.

### Sharing a document

<Preview
  code={`<div style="display:grid;justify-items:start;gap:var(--tp-space-3)">
  <tp-popover id="popover-share" label="Share document">
    <tp-button slot="trigger" variant="outline">Share</tp-button>
    <span slot="title">Share document</span>
    <tp-field label="Link">
      <tp-input readonly default-value="https://tweakpad.app/d/8f2c41"></tp-input>
    </tp-field>
    <tp-button slot="close">Done</tp-button>
  </tp-popover>
  <output id="popover-share-output" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Closed</output>
</div>`}
  script={`const popover = document.getElementById('popover-share');
const output = document.getElementById('popover-share-output');
popover.addEventListener('tp-open-change', (event) => {
  if (event.target !== popover || event.detail.cancelled) return;
  output.textContent = event.detail.value ? 'Open' : 'Closed';
});`}
/>

Every way of opening or closing first proposes the change with a cancelable `tp-open-change`, so the application can follow the state, or call `preventDefault()` to keep the popup open while work is pending. Setting `open` opens and closes it from code.

## Keyboard

| Key | Action |
| --- | --- |
| <Keys keys="esc" /> | Closes the popup and returns focus to the trigger. |
