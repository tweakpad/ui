## Usage

Put Text motion inside the heading or paragraph whose text it animates, and keep the typography on that element; the pieces inherit it. Lines are measured from the text's own layout, so splitting never changes the wrapping or the height and nothing below moves. A Text motion on its own reveals the first time it enters the view; inside a Scroll trigger, the trigger decides when. With reduced motion every piece appears at rest at once, and the events still fire. `reveal-repeat` plays the reveal again each time the text comes back into view.

### Section headline

<Preview
  code={`<h2 style="margin:0;font-size:2rem;line-height:1.1;font-weight:600">
  <tp-text-motion split="words" mask="words" reveal="up" stagger="60" reveal-repeat>Ship the release on Friday</tp-text-motion>
</h2>`}
/>

A mask clips each word, so the words rise from behind their own outline instead of sliding in from below. With a mask, a direction travels the piece's own size; without one it travels a short distance and fades. A longer stagger between the pieces reads word by word; a short one reads as a single gesture.

### Brand name

<Preview
  code={`<p style="margin:0;font-size:2.5rem;font-weight:600;letter-spacing:-0.02em">
  <tp-text-motion split="chars" reveal="fade blur" stagger="25" stagger-from="center" reveal-repeat>Open light</tp-text-motion>

Splitting into characters suits a short word that should feel built letter by letter, here from the middle out. Each piece is a character as a reader sees it, and kerning is off from the first frame, so the text never re-wraps when it splits.

### Welcome after setup

<Preview
  code={`<div style="display:grid;gap:var(--tp-space-5);justify-items:start">
  <p style="margin:0;font-size:2rem;line-height:1.1;font-weight:600">
    <tp-text-motion id="text-motion-welcome" split="words" mask="words" reveal="up" stagger="60" reveal-hold>Your workspace is ready</tp-text-motion>
  </p>
  <tp-button id="text-motion-welcome-play" variant="outline">Reveal</tp-button>
</div>`}
  script={`const headline = document.getElementById('text-motion-welcome');
document.getElementById('text-motion-welcome-play').addEventListener('click', () => {
  headline.revealHold = false;
});`}
/>

`reveal-hold` keeps the split text waiting in its start state, so the reveal plays at a moment the application chooses: after a loading screen, when a font arrives, or on a press as here. Clearing it plays the reveal if the text is in view.

Formatting stays around the pieces and a link stays the original element, wrapping like ordinary text. Screen readers read the sentence once, with the link and its full name.

### Custom reveal

<Preview
  code={`<p style="margin:0;font-size:2rem;line-height:1.2;font-weight:600">
  <tp-text-motion id="text-motion-custom" split="words" reveal="fade" reveal-repeat>Launch week starts Monday</tp-text-motion>
</p>`}
  script={`const headline = document.getElementById('text-motion-custom');
document.addEventListener('tp-motion-request', (event) => {
  if (!headline.isConnected) return;
  const { owner, role } = event.request;
  if (owner !== headline || role !== 'reveal') return;
  event.respondWith({
    play: () => {
      const animations = owner.words.map((word, index) =>
        word.animate(
          [
            { opacity: 0, transform: 'translateY(0.6em) rotate(6deg)' },
            { opacity: 1, transform: 'none' },
          ],
          { duration: 600, delay: index * 70, easing: 'cubic-bezier(0.2, 0.9, 0.3, 1.2)', fill: 'backwards' },
        ),
      );
      return {
        finished: Promise.all(animations.map((animation) => animation.finished)),
        cancel: () => animations.forEach((animation) => animation.cancel()),
      };
    },
  });
});`}
/>

The reveal runs through the `reveal` motion role, so a `tp-motion-request` listener can claim it and animate the pieces itself. The pieces are on `words`, `chars` and `lines`; return the animation's `finished` promise and a `cancel` so an interruption settles cleanly. While the custom animation plays, the built-in transitions are off. An animation that depends on line positions rebuilds on `tp-text-split`, which fires whenever the lines change.
