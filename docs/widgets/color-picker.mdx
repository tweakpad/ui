## Usage

Use a Color picker wherever someone chooses a color by eye rather than typing a code. Any CSS color goes in, and the value reads back in the active format, so an application can store hex while a designer edits in a perceptual space. Beyond the default plane, the picker offers channel sliders, a harmony wheel, a hue ring around a triangle, swatches and schemes; listing more than one in `views` adds tabs. The picker fills the inline size it gets, so give it one or place it in a sized column.

### Theme setting in a form

<Preview
  code={`<tp-form id="color-picker-form" style="max-inline-size:24rem">
  <tp-field label="Workspace color" description="Shown in the sidebar and on invitations.">
    <tp-color-picker picker="popup" name="workspace-color" default-value="#6d5dfc"></tp-color-picker>
  </tp-field>
  <div slot="actions">
    <tp-button type="submit">Save</tp-button>
    <tp-button type="reset" variant="outline">Reset</tp-button>
  </div>
</tp-form>`}
  script={`const picker = document.querySelector('#color-picker-form tp-color-picker');
let recent = [];
picker.addEventListener('tp-value-commit', (event) => {
  if (!event.detail.value || event.detail.metadata?.formatChange) return;
  recent = [event.detail.value, ...recent.filter((color) => color !== event.detail.value)];
  picker.recent = recent.slice(0, 5);
});`}
/>

In a settings form the popup keeps the row compact: a swatch opens the panel, whose header compares the original and current colors and copies the value. With a `name` the color submits with the form and returns to its default on reset. Recent colors are application state, since the picker keeps no history: record each commit and hand the last few back through `recent`, and they appear along the bottom of the popup.

### Design token editor

<Preview
  code={`<tp-color-picker label="Surface" views="sliders" default-format="oklch" formats="hex oklch" alpha="false" default-value="oklch(0.586 0.227 281.3)" style="inline-size:20rem"></tp-color-picker>`}
/>

Token work edits one channel at a time, so the sliders view gives every channel of the format its own labeled Slider and value box. Limiting `formats` to the notations your tokens use keeps the format Select short, and turning `alpha` off guarantees opaque values.

### Palette from a harmony

<Preview
  code={`<div style="display:flex;flex-wrap:wrap;align-items:start;gap:var(--tp-space-6)">
  <tp-color-picker id="color-picker-harmony" label="Chart palette" views="wheel" default-harmony="triad" default-value="#039be5" style="inline-size:18rem"></tp-color-picker>
  <div id="color-picker-harmony-preview" style="display:grid;gap:var(--tp-space-2)">
    <tp-button>Primary</tp-button>
    <tp-button>Secondary</tp-button>
    <tp-button>Accent</tp-button>
  </div>
</div>`}
  script={`const picker = document.getElementById('color-picker-harmony');
const buttons = document.querySelectorAll('#color-picker-harmony-preview tp-button');
const paint = () =>
  picker.harmonyColors.forEach((color, index) => {
    buttons[index]?.style.setProperty('--tp-primary', color);
  });
await customElements.whenDefined('tp-color-picker');
await picker.updateComplete;
paint();
picker.addEventListener('tp-value-commit', paint);
picker.addEventListener('tp-harmony-change', () => queueMicrotask(paint));`}
/>

The wheel derives related colors from one base under a harmony rule, and `harmonyColors` hands them back in the active format, base first, so a palette can drive the rest of the interface. The ring around the wheel copies each color on press. Start the rule with `default-harmony`; a `harmony` attribute makes the rule controlled, so the Harmony Select only proposes.

### Brand swatches

<Preview
  code={`<tp-color-picker id="color-picker-swatches" label="Chart series" views="area swatches schemes" default-view="swatches" default-value="#fb8c00" style="inline-size:18rem"></tp-color-picker>`}
  script={`await customElements.whenDefined('tp-color-picker');
const picker = document.getElementById('color-picker-swatches');
picker.swatches = [
  { label: 'Brand', colors: ['#6d5dfc', '#0f766e', '#fb8c00', '#e53935'] },
  { label: 'Neutrals', colors: ['#0f172a', '#475569', '#cbd5e1', '#f8fafc'] },
];
picker.recent = ['#039be5', '#8e24aa', '#43a047'];`}
/>

When a product has a fixed palette, open on the swatches and keep the free surface one tab away. Saved swatches are data, set as a property in flat lists or labeled groups. The schemes tab generates tints, shades and related strips from the current color, or offers your own templates through `schemes`.

### Color with a contrast floor

<Preview
  code={`<div style="display:flex;flex-wrap:wrap;align-items:start;gap:var(--tp-space-6)">
  <tp-color-picker id="color-picker-controlled" label="Button color" value="#2622a5" alpha="false" style="inline-size:18rem"></tp-color-picker>
  <tp-button id="color-picker-controlled-sample" style="--tp-primary:#2622a5;--tp-primary-foreground:#fff">Start free trial</tp-button>
</div>`}
  script={`const picker = document.getElementById('color-picker-controlled');
const sample = document.getElementById('color-picker-controlled-sample');
picker.onValueChange = (event) => {
  const color = event.detail.metadata?.color;
  if (color?.space === 'srgb') {
    const [r, g, b] = color.coords;
    if (0.2126 * r + 0.7152 * g + 0.0722 * b > 0.45) {
      event.preventDefault();
      return;
    }
  }
  picker.value = event.detail.value;
  sample.style.setProperty('--tp-primary', event.detail.value);
};`}
/>

Own the color through `value` when some choices must be refused. Each proposal arrives in `onValueChange` with its floating-point color, and only the values written back are shown; this one refuses colors too light for white button text, so dragging toward white stops the handle. A refused proposal leaves the surfaces, the fields and the form state unchanged. Drags publish proposals while moving and one `tp-value-commit` on release, so expensive work such as saving belongs on the commit.

### Quick choice

<Preview
  code={`<div style="display:flex;flex-wrap:wrap;align-items:start;gap:var(--tp-space-6)">
  <tp-color-picker label="Sticky note color" size="sm" shape="round" fields="false" eyedropper="false" alpha="false" default-value="#fdd835" style="inline-size:15rem"></tp-color-picker>
  <tp-color-picker label="Link color" format-select="false" preview="false" alpha="false" default-value="#3949ab" style="inline-size:15rem"></tp-color-picker>
</div>`}
/>

For approximate choices, such as a note or a label color, the controls around the surface can each be turned off: the numeric fields, the format Select, the preview swatch and the eyedropper. A smaller size and round swatches suit a picker tucked into a sidebar. `readonly` keeps a locked color focusable and submitted while blocking every edit.

## Keyboard

Every dimension of a surface is its own focusable slider. Horizontal arrows follow the writing direction on the plane and the Sliders; the wheel and the hue ring keep their geometry.

| Key | Action |
| --- | --- |
| <Keys keys="left" /> <Keys keys="right" /> | On the plane or triangle, change saturation |
| <Keys keys="up" /> <Keys keys="down" /> | On the plane or triangle, change brightness |
| Arrow keys | On the wheel or hue ring, step the focused hue or saturation; the hue wraps around |
| <Keys keys="PageUp" /> <Keys keys="PageDown" /> | Take a large step on the focused dimension |
| <Keys keys="Home" /> <Keys keys="End" /> | Move the focused dimension to its minimum or maximum |
| <Keys keys="shift" /> with an arrow | Take a large step; <Keys keys="alt" /> takes a small one |
| <Keys keys="escape" /> | During a drag, restore the color from before the press; in the popup, close it and return focus to the trigger |
