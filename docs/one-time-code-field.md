# One-time code field

`tp-otp-field` presents a fixed-length code as grouped character slots while retaining one native text editor, one accessible name, and one form value. Typing, selection, deletion, paste, IME and autofill operate on that editor. Separators never enter the value or accessibility tree.

| Property / attribute                                                                     | Type                                                 | Default           | Behavior                                                                                                                                                                                                                                           |
| ---------------------------------------------------------------------------------------- | ---------------------------------------------------- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `length`                                                                                 | positive integer                                     | required          | Character capacity and exact slot count. Missing/invalid length disables editing and reports a composition diagnostic.                                                                                                                             |
| `value`                                                                                  | string                                               | uncontrolled      | Application-owned value; accept a proposal by publishing a new value synchronously.                                                                                                                                                                |
| `defaultValue` / `default-value`                                                         | string                                               | empty             | Initial uncontrolled value; used by native reset.                                                                                                                                                                                                  |
| `validationType` / `validation-type`                                                     | `numeric`, `alphabetic`, `alphanumeric`, `predicate` | `alphanumeric`    | ASCII digits, Unicode letters, either, or a custom predicate.                                                                                                                                                                                      |
| `characterPredicate`                                                                     | `(character: string) => boolean`                     | none              | Required for predicate validation; receives a Unicode code point.                                                                                                                                                                                  |
| `normalizeValue`                                                                         | `(value: string) => string`                          | none              | Idempotent normalizer applied after initial filtering and before re-filtering/truncation.                                                                                                                                                          |
| `inputMode` / `inputmode`                                                                | native input hint                                    | derived           | Numeric validation suggests numeric; otherwise text. An override does not widen accepted characters.                                                                                                                                               |
| `groupLengths` / `group-lengths`                                                         | readonly number array / JSON                         | one group         | Positive lengths summing to `length`; separators appear between groups.                                                                                                                                                                            |
| `mask`                                                                                   | boolean                                              | false             | Obscures visible characters; the value remains unchanged.                                                                                                                                                                                          |
| `placeholder`                                                                            | string                                               | empty             | Presentational content of empty slots.                                                                                                                                                                                                             |
| `autoComplete` / `autocomplete`                                                          | string                                               | `one-time-code`   | Native autofill hint.                                                                                                                                                                                                                              |
| `noAutofill` / `no-autofill`                                                             | boolean                                              | false             | Opts the native editor out of browser and password-manager autofill (`autocomplete="off"` plus Bitwarden, 1Password, LastPass and Dashlane hints). Also inherited from an enclosing Field or Form. Leave off for fields autofill should help with. |
| `autoSubmit` / `auto-submit`                                                             | boolean                                              | false             | Request owning-form submission immediately after accepted completion.                                                                                                                                                                              |
| `label`                                                                                  | string                                               | `One-time code`   | Fallback accessible name; a surrounding Field supplies its label.                                                                                                                                                                                  |
| `name`, `formOwner` / `form`, `disabled`, `readOnly` / `readonly`, `required`, `invalid` | shared form APIs                                     | standard defaults | One normalized serialized value; required means a complete code.                                                                                                                                                                                   |

`onValueChange(event)` and `tp-value-change` use the shared cancelable value proposal (`value`, `previousValue`, reason `input` or `input-paste`, `sourceEvent`, `cancelled`). A controlled owner must publish the accepted value synchronously. Rejection restores the editor, visible slots, selection and caret; it cannot complete or submit. Keep controlled versus uncontrolled ownership stable for the element's lifetime.

`onValueInvalid(detail)` and `tp-invalid-input` report `{ attemptedValue, reason: 'input' | 'paste', sourceEvent }` when normalization removes or changes attempted input. The normalizer removes whitespace, filters, applies `normalizeValue`, filters again, and truncates by Unicode code point. It does not mutate an application variable supplied as the controlled value.

`onValueComplete(detail)` and `tp-complete` report `{ value, sourceEvent }` after the accepted transition to the required length, and after a complete paste even when the value was already complete. Programmatic assignments and native resets do not simulate user completion. Completion precedes optional auto-submit. Use `tp-form` for the shared validation/submission policy and actual `tp-button` submit/reset actions.

Public parts are `one-time-code-field`, `one-time-code-field-group`, `one-time-code-field-slot`, and `one-time-code-field-separator`. Generated slots expose index and active/focused/filled/empty/selected/complete/disabled/read-only/required/invalid markers. Root exposes aggregate filled/complete/disabled/invalid state. `partContracts` customizes these generated regions; `partPresentation` and the presentation dictionary customize their appearance. `inputElement`/`inputElementReference` expose the sole editor for native selection or focus APIs.

Grouping is structural; spacing, borders, focus, invalid paint and radius come from the shared theme and field recipes. Separators use the public Icon. A visible caret indicates the empty active position without requiring animation. Invalid group lengths or a missing predicate set `data-invalid-composition`, emit `tp-composition-diagnostic`, and prevent completion. The form value is never split into one participant per slot.

The rendered Docs demonstrate simple codes, numeric filtering, separators, alphanumeric codes, disabled and invalid states, four-digit codes, masking, controlled value feedback, a login Card, and explicit or automatic form submission. Examples compose existing public controls and are not extra catalog variants. The grouped case demonstrates three pairs of characters. The invalid case uses Field error content. Interactive examples share their live setup with the code explorer, including event cleanup. The login Card’s Resend action reports the application request; an application supplies its own delivery service.
