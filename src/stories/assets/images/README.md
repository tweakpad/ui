# Sample images

Original images for Image editor stories, documentation examples and verification fixtures. Each
was drawn for this repository as an SVG by a small script, rendered with `rsvg-convert` and
encoded with Pillow. They contain no third-party artwork and are freely usable, without
attribution, inside and outside this project.

| File           | Content                                                                                     | Size              |
| -------------- | ------------------------------------------------------------------------------------------- | ----------------- |
| `harbor.jpg`   | A harbor town at dusk: lit windows, a lighthouse and numbered boats small enough to zoom to | 4800×3200, 417 kB |
| `portrait.jpg` | An illustrated portrait with the subject right of centre, for avatar crops                  | 1600×2000, 61 kB  |
| `sticker.png`  | A tilted sticker on a transparent background, which shows the checker behind the image      | 1400×1000, 68 kB  |
