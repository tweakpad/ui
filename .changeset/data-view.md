Add the Data view component (`tp-data-view`): application records as a compact, read-only grid with stable row identities, configured columns and a cell renderer, a bounded scrolling viewport with fixed-height row virtualization, keyboard navigation by cell or by row, single-column sorting (local by default through the exported `sortDataViewRows`, or `sorting="manual"`), optional single-row selection, row activation, and loading, empty and error states. Table's look now comes from a shared table surface that both use.
