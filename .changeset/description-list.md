Add `tp-description-list` and `tp-description-list-item` for label–value pairs. Each item takes its label from `label` and its value from its content; the list renders one native description list. `orientation` stacks the pairs (`vertical`, the default) or places them side by side and wraps them (`horizontal`); `layout` places each label beside its value (`inline`, the default, with the labels in a shared column) or above it (`stacked`), and an item can set its own `layout`; `align="center"` aligns the labels toward their values, with Show more following the values. `limit` shows only the first items and adds a link-style Show more button that expands the rest in place and turns into Show less; in a vertical list, hidden items keep their place in the layout, so opening never moves the values above. `open`/`default-open`, a cancelable `tp-open-change`, `tp-open-change-complete`, `disabled`, `hidden-until-found` and `messages` (strings or functions of the hidden and total counts) configure it. Collapsible's shared disclosure controller can now leave its content unnamed and leave hiding to its consumer, and the shared disclosure panel styles accept a closed extent other than zero. The custom elements manifest now lists each attribute's own default: overridden defaults (such as `orientation` on Citation list, Description list, Menu or Radio group) and defaults set from constants no longer show the inherited value or the constant's name.
