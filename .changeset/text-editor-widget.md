Add the `tp-text-editor` widget (`@tweakpad/ui/widgets`, registered by `@tweakpad/ui/register/widgets`), a rich text field for formatted documents. The document belongs to an editing engine that the application installs and assigns to `engine`, built from the engine's modules by an adapter factory of `@tweakpad/ui/text-editor`; that entry also provides the built-in tools, default layouts, strings and types, and `@tweakpad/ui/widgets` re-exports it. A toolbar above the content offers undo and redo, block types, lists, quotes and code blocks, text marks, superscript and subscript, and alignment as Toggles, Toggle groups and Menus behind one tab stop, moved through with the arrow keys, with tooltips that show each tool's shortcut; tool groups that do not fit move into a More menu whose label states how many groups it holds. Every document change from a tool, a shortcut, a paste or the `run` and `setContent` methods first dispatches the cancelable `tp-text-editor-request`, and a rejected change dispatches `tp-text-editor-request-failed`; while `readonly` is set, a paste is rejected the same way. `defaultValue` in `format` (`html`, `markdown`, `text` or `json`) supplies the initial content, shown as a static preview until the engine is ready unless the format is `json`. The read-only `value` is a snapshot of the committed document, serialized on request by `getContent(format)`. `tp-value-change` follows each applied change, `tp-value-commit` follows each applied request that changed the document and focus leaving the editor after typing, and `tp-text-editor-ready` and `tp-text-editor-error` report the engine's mount. The editor submits its content with a form through `name` and `form`, form reset restores `defaultValue`, and it performs no validation. Its accessible name comes from a Field label, else `label`, else its own `aria-label`, else the default name in `strings`. `disabled`, also from a disabled fieldset or Field, leaves nothing in it focusable, opens no tooltip or menu and submits no value. `tools`, `layout`, `nodes`, `strings` and `placeholder` configure it, and `state`, `subscribe`, `focus` and `blur` read and drive it. `textEditorStrings` holds the English defaults, `emptyBlockHint`, `instructions` and `grip` among them; the hint in an empty block names no key, and `moreTools` takes a `{count}` placeholder, the number of tool groups the More menu holds.
