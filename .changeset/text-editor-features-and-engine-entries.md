'@tweakpad/ui': patch
---

Text editor: the engine adapters and the optional controls are opt-in by import. `createTiptapEngine` and `createLexicalEngine` move from `@tweakpad/ui/text-editor` to their own entries, `@tweakpad/ui/text-editor/adapters/tiptap` and `@tweakpad/ui/text-editor/adapters/lexical`, so an application bundles only the adapter it imports; `@tweakpad/ui/text-editor` stays engine-free and `@tweakpad/ui/widgets` no longer re-exports the factories. The widget's block editing, tables, images, links, selection toolbar and suggestion lists are now features: `textEditorBlocks()`, `textEditorTables({ stickyHeaders })`, `textEditorImages({ upload, accept, maxFileSize })`, `textEditorLinks()`, `textEditorSelectionToolbar()` and `textEditorSuggestions()` from `@tweakpad/ui/widgets`, assigned to the new `features` property; without any, `tp-text-editor` is the core editor (toolbar, marks, block kinds, colors, alignment), at about half the size. The `imageUpload`, `image-accept`, `image-max-file-size` and `sticky-table-headers` members are removed in favor of the feature options. A feature's built-in tools exist only while it is assigned: the default layouts leave them out silently and a layout that places one reports `text-editor-layout-unknown` naming the feature; two features of one name report `text-editor-feature-duplicate`. The built-in tools split into a core set and one set per feature, and the content converters no longer load the tools and their icons. The size report gains a "Text editor (all features)" row and checks that the core ships no feature module. The alternative text field of a selected image shows only once its upload resolved the source; a pending image shows its File upload alone. The default image URL policy now also allows `blob:` object URLs, which only the page itself can create, so an upload hook can resolve a preview of the file; the documentation examples resolve the dropped file itself instead of a stock picture. The custom nodes example embeds a sample tide table page shipped with the examples (`/pages/tide-table.html`, a Storybook static directory) instead of an external placeholder site; the example's embed also accepts pages of the document's own origin, and its frame has a fixed height.
