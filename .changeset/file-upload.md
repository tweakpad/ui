Add `tp-file-upload`: a dashed drop surface over a native file input with accept, count, size and duplicate limits, custom validators with metadata, rejected files kept as error items, previews, chips, rows and image grid layouts, an optional upload adapter with progress, retry and cancellation, opt-in clipboard paste scoped to the control or the page, and Field and Form integration. Attachment gains `messages` and a cancelable `tp-remove`; `formatBytes`/`parseByteSize` move to Foundation; Field revalidates on `tp-field-validity`; new `upload-cloud` and `imageIcon` icons.
