Add the `tp-emoji-picker` widget (`@tweakpad/ui/widgets`, registered by `@tweakpad/ui/register/widgets`): a searchable, virtualized grid of emoji grouped by category, with sticky category labels, an underlined tab bar of category icons that follows scrolling and jumps to a category, a preview of the highlighted emoji, a skin tone menu, application-supplied recent emoji and custom image emoji groups. It works inline or as a popup behind a trigger Button, takes part in forms, and reports value, query, skin tone and open changes through cancelable events. A compact English dataset is built in; `@tweakpad/ui/emoji` adds data types, skin tone, support detection and lookup helpers, a local storage cache and an adapter that loads the complete Emojibase dataset from a URL the application provides, without adding a dependency. Emoji the platform cannot draw are hidden by version and flag support, or up to `emojiVersion`. Adds the `--tp-font-emoji` font role. Searchable Select gains grid `columns`, owns its virtual window when `virtualized` is set without `mountedItems`, shows Clear only while its lane has something to clear, renders the empty state and status row after the list instead of inside the listbox, and turns off browser scroll anchoring in its list so a virtual window no longer jumps by a row while scrolling. Large choice lists filter faster: duplicate detection and collection ordering no longer grow quadratically with the number of options.
