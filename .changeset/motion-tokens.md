Add the motion token family: `--tp-duration-fast` (200ms), `--tp-duration-normal` (280ms) and the new `--tp-duration-slow` (560ms), registered as times so scripts read canonical values such as `0.28s`, plus `--tp-easing-standard` and the new `--tp-easing-enter` and `--tp-easing-exit`. `TOKEN_FAMILIES.motion` lists them, so `REQUIRED_TOKEN_ROLES` and the token-set assertions now require them. Popups, dialogs and their backdrops arrive on the enter easing and leave on the exit easing; Drawer and Toast keep the standard easing for swipe continuity. Image and Text motion reveals and Image hover zoom default to the slow duration on the enter easing. Script-driven motion follows the same roles and the motion scale: Carousel track, auto height and scrollbar fade (which also fixes the carousel falling back to 300ms with the built stylesheet), Carousel effects without an `easing`, Flow layout and viewport moves (`fitViewTo`, `zoomTo`, `setCenter` now default to the normal duration instead of 250ms), Map zoom steps, Tree view row reordering and the Easing editor range. Timeline connectors now scale with the motion policy. `CarouselEffect` gains an optional `easingRole`.
