Every component and widget now has its documentation page in the package (`docs/components/*.mdx`, `docs/widgets/*.mdx`), and every element's own API carries descriptions in the Custom Elements Manifest: class summaries, attributes and properties, methods, events, slots and shadow parts. API tables list only what an element declares itself; members inherited from a base class are no longer repeated on every element.
