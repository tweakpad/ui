# @tweakpad/ui

## 0.2.0

### Minor Changes

- e37903f: Add `tp-citation` and `tp-citation-list`. A citation is an inline reference to a source: an outlined chip with muted text that can show a site icon (`src`, with a default mark when the image fails), a label and a number. With an accepted `href` it is a link; a site address opens in a new tab unless `target` is set, and while hovered or focused the chip brightens and shows an external-link mark over the end of its label without changing its width. A `description` or `preview` slot adds a Preview card with the site icon, host, title and description. `superscript` raises a footnote-style marker without changing the line height. A Citation list numbers its entries from `start`; in-text markers name an entry with `source` to take its number, title and preview, and a marker whose `href` is the entry's fragment moves focus to that entry when activated. Numbered markers keep a small space from the word they follow. Badge now shows its focus ring on any focusable badge part, and Preview card no longer centers its content when `align="center"` is set.
- 4df1343: Add `tp-cursor` and `tp-cursor-zone`: a decorative custom pointer that hides the native cursor for mouse and pen users and trails the pointer with a spring (stiffness, damping, mass, rest thresholds, published position and velocity) in the top layer, with zones that declare a named state, cloned template content, scoped `--tp-cursor-*` appearance, native passthrough, center or bounds attraction and physics overrides. Reduced motion keeps the cursor and snaps it; touch never engages it. Adds the Foundation `SpringFollower2D` and `FrameLoop`, and the shared `--tp-cursor-hidden` style query in the element base styles.
- 02849eb: Add `tp-description-list` and `tp-description-list-item` for label–value pairs. Each item takes its label from `label` and its value from its content; the list renders one native description list. `orientation` stacks the pairs (`vertical`, the default) or places them side by side and wraps them (`horizontal`); `layout` places each label beside its value (`inline`, the default, with the labels in a shared column) or above it (`stacked`), and an item can set its own `layout`; `align="center"` aligns the labels toward their values, with Show more following the values. `limit` shows only the first items and adds a link-style Show more button that expands the rest in place and turns into Show less; in a vertical list, hidden items keep their place in the layout, so opening never moves the values above. `open`/`default-open`, a cancelable `tp-open-change`, `tp-open-change-complete`, `disabled`, `hidden-until-found` and `messages` (strings or functions of the hidden and total counts) configure it. Collapsible's shared disclosure controller can now leave its content unnamed and leave hiding to its consumer, and the shared disclosure panel styles accept a closed extent other than zero. The custom elements manifest now lists each attribute's own default: overridden defaults (such as `orientation` on Citation list, Description list, Menu or Radio group) and defaults set from constants no longer show the inherited value or the constant's name.
- 037dc3c: Add `tp-file-upload`: a dashed drop surface over a native file input with accept, count, size and duplicate limits, custom validators with metadata, rejected files kept as error items, previews, chips, rows and image grid layouts, an optional upload adapter with progress, retry and cancellation, opt-in clipboard paste scoped to the control or the page, and Field and Form integration. Attachment gains `messages` and a cancelable `tp-remove`; `formatBytes`/`parseByteSize` move to Foundation; Field revalidates on `tp-field-validity`; new `upload-cloud` and `imageIcon` icons.
- ad72936: The default `--tp-font-mono` stack now starts with Cascadia Mono, followed by the platform monospace fonts. Everything that presents code or machine values uses it: Code block, code spans and blocks in Markdown, One-time code field characters (now in `font-mono`) and the Easing editor's curve notation. Input and Text area gain a `mono` attribute that shows the value in `font-mono` and turns off spell checking, autocorrection and autocapitalization; the widgets use it for their value editors (Color picker hex and channel fields, Easing editor parameters and duration, Flow number properties and the zoom level), and `FlowPropertyDefinition.mono` opts text properties in (number properties default to mono). The default stylesheet also gives native `code`, `kbd`, `samp` and `pre` elements `font-mono` at zero specificity. Font files are not bundled; install or load Cascadia Mono in your application, or set `--tp-font-mono` to your own stack. Code block lines now render in `font-mono`; before, the code inherited the browser's default monospace font instead of the token.
- 322dc68: List item is now List. The container `tp-list-item-group` is renamed `tp-list` (`TpList`) and the divider `tp-list-item-separator` is renamed `tp-list-separator` (`TpListSeparator`); `tp-list-item` keeps its name and still works on its own. The host of `tp-list` now carries the `list` role and its `aria-label`, so the inner stack no longer has a role; direct `tp-list-item` members still become list items unless they set their own role. Part names follow the tags: the container part `list-item` is now `list`, the row part `list-item-root` is now `list-item`, and `list-item-separator` is now `list-separator`; update `partPresentation` keys and `::part()` selectors to match. The old names have no aliases.
- f36e3cc: Add the motion token family: `--tp-duration-fast` (200ms), `--tp-duration-normal` (280ms) and the new `--tp-duration-slow` (560ms), registered as times so scripts read canonical values such as `0.28s`, plus `--tp-easing-standard` and the new `--tp-easing-enter` and `--tp-easing-exit`. `TOKEN_FAMILIES.motion` lists them, so `REQUIRED_TOKEN_ROLES` and the token-set assertions now require them. Popups, dialogs and their backdrops arrive on the enter easing and leave on the exit easing; Drawer and Toast keep the standard easing for swipe continuity. Image and Text motion reveals and Image hover zoom default to the slow duration on the enter easing. Script-driven motion follows the same roles and the motion scale: Carousel track, auto height and scrollbar fade (which also fixes the carousel falling back to 300ms with the built stylesheet), Carousel effects without an `easing`, Flow layout and viewport moves (`fitViewTo`, `zoomTo`, `setCenter` now default to the normal duration instead of 250ms), Map zoom steps, Tree view row reordering and the Easing editor range. Timeline connectors now scale with the motion policy. `CarouselEffect` gains an optional `easingRole`.
- 136257c: Add `tp-overflow-list`, which wraps its element children in rows and replaces the items that do not fit with one count of the omitted items. `limit` shows at most that many items; `max-rows` fits as many items as the available width allows within that many rows, refitting as the container, the items, the count or the fonts change, without moving the content below for a stale fit and with an intrinsic size (for tables, flex and grid tracks) that does not depend on how many items show. `collapse-from` omits items from the `end` (default) or the `start`. The default count is a secondary Badge reading `+N` and announced as "N more" (`messages` replaces both); an element in the `count` slot replaces it. Omitted items stay in the document, inert and hidden from assistive technology; `hiddenCount`, `hiddenItems`, `data-overflowing` and a non-cancelable `tp-overflow-change` report them. Layout reads of Text motion, Text transform and Overflow list now share one batched pass per turn, and `observeSlots` can also watch `hidden` attributes.
- 8a76a8e: Add `tp-text-transform`, which presents one value as text through a named preset: case (`uppercase`, `lowercase`, `capitalize`, `sentence`), identifier cases (`camel`, `pascal`, `kebab`, `snake`, `constant`, `humanize`), and localized `number`, `integer`, `decimal`, `percent`, `currency`, `compact`, `scientific`, `unit`, `bytes` and `duration` formatting with `currency`, `unit`, `decimals` and a `format` options record. `defineTextPreset` adds page-wide presets and `formatter` replaces the preset for one element. `truncate` shortens the text at its start, middle or end to fit its width, by characters or whole words (`truncate-by`), `max-length` caps the count, and a tooltip shows the full text while shortened; assistive technology always hears the complete, spelled-out text. Time's description tooltip popup now receives the `time-description` part, `formatBytes` takes a `long` display, and `observeLanguage` and a text-only `observeSubtree` option are shared by Time and Text transform.
