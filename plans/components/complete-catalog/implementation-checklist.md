## Architecture and reuse

Story-only LitElement owns project data, filtering, dialogs and demo transactions. Existing components retain focus, portals, keyboard, validation, selection, scrolling and motion ownership. Light DOM preserves shared themes and public component presentation. Layout CSS is scoped to the demo and uses theme tokens. Stable keyed rows and stateful panels preserve interaction state. Lifecycle cleanup for application shortcut and pending refresh timers.
