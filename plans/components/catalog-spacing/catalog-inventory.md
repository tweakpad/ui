## Cross-cutting findings and dispositions

- Slider: external value wrapper had 6.4px flex gap but centered Thumb reduced visible clearance to 1.6px. Replace the wrapper with existing Output; structural layout handles optional Label/Output and dictionary selects endpoint-safe gap. Same behavior used by the compact Slider example and Message Scroller.
- Dialog/AlertDialog: header/body/footer padding and gaps were component CSS. Move unchanged default density into the owning content recipe; preserve header-hidden and corner-close clearance.
- Calendar: navigation/weekday padding and month gap moved from implementation CSS to calendar recipe; layout and measured sizing remain structural.
- Bubble: prose demos recreated paragraph spacing. Content now supplies a column flow with dictionary gap and margin reset; demos use direct paragraphs.
- Card: header action region lacked its own action flow/gap and footer did not wrap. Existing Action/Footer own arrangement; dictionary supplies Action gap.
- Empty state: replace custom inline action div with actual unjoined ButtonGroup; retain independent help action.
- Switch: label separation now belongs to its presentation recipe; the selector accounts for the native input between the switch and Label.
- ButtonGroup: an unjoined Pagination composition keeps Pagination's own dictionary gap instead of replacing it with a second default.
- Message Scroller: remove local Card header/footer, InputGroup addon, TextArea, Empty state and transcript padding overrides; value readout uses Slider Output. Frame height/width and native scroller containment are application geometry.
- Form actions, Field labels/descriptions/errors, InputGroup addons, Button/Toggle icons, selection/menu rows, navigation rows, attachments/list items, pagination, toast, tabs and status primitives already select density in shared dictionaries. Use their actual slots/groups; do not wrap them in independently spaced substitutes.

## Retained source measurements

- Gallery/demo page grids separate independent examples and are application layout. Skeleton profiles, aspect-ratio media, scroll-area documents and resizable-panel content are application content, not control padding.
- Carousel gap and ToggleGroup spacing are documented numeric layout properties. Provider scroll measurements, intrinsic placeholders, canvas plotting, pointer travel, clipping and accessible hit-target expansion are geometry, not default visual spacing.
- Navigation floating/inset outer cavity is structural viewport/panel geometry; internal row/header/footer density remains dictionary-owned. Joined ButtonGroup suppresses the existing Pagination gaps only while joined, and restores its ordinary recipe when detached.
- Zero margins/padding neutralize native host defaults; auto margins center/alignment. They do not define density.

## Browser coverage

The live fixture enumerates 61 base controls plus 169 authored examples (230 total, including the added fine-step Slider). All 230 passed document-overflow checks at 1200px/light/LTR and 390px/dark/RTL through Chrome DevTools MCP. Results are in local `tmp/component-verification/catalog-spacing/{desktop,narrow}-audit.json`. The initial timer-based run stalled and is not counted; completed runs await component updates without background timers.

Focused screenshots and geometry cover Slider, Bubble, Card, Dialog, Calendar, Empty state and the Message Scroller composition. Dialog retained 16px region padding, 6.4px action gaps and corner-close clearance. Calendar retained 3.2px navigation/weekday padding, 6.4px month gap and 44px day cells. Empty state's actual unjoined ButtonGroup supplies its 6.4px gap. Switch's Label separation is 6.4px. These are shared recipe values, not demo overrides.

Overflow checks are not a complete visual or interaction certification of all 230 cases. Remaining broad catalog interaction/visual gates stay open in the checklist. Slider's latest vertical geometry, fine-step drag, keyboard, forms, accessibility and documentation checks are recorded separately there.
