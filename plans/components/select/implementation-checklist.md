Repeated public parts are configured through item/group records and part contracts; no new catalog identity.
- Public vocabulary / tokens / parts / presentation review: Exactly published eleven parts, no undeclared size axis; common tp token roles; optional Foundation anatomy remains nearest ancestor configuration. Native semantic DOM is required combobox/listbox anatomy, not a Button imitation.
