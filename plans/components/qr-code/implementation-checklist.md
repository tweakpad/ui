## Architecture and reuse

- Component folder and responsibility boundaries: `src/components/qr-code/` (`index.ts`, `qr-code.ts` element, `messages.ts`, `export.ts` color resolution and rasterization); `src/foundation/qr/` (types, errors, bits, segments, tables, reed-solomon, matrix, mask, encode, path, index) DOM-free; `src/foundation/clipboard.ts` (moved from `foundation/code/clipboard.ts`, plus `copyData`); `src/foundation/download.ts` internal.
- Supported exports / registration / constituent API impact: new `TpQrCode` and types from `@tweakpad/ui`; `copyText`/`copyData` move from `@tweakpad/ui/code` to the Foundation root export (no shim); new `@tweakpad/ui/qr` subpath; `TpCopyButton.data` and `types` in copy details.
- Public vocabulary / tokens / parts / presentation review: parts and keys from `qrl-public-definition`/`qrl-presentation-keys`; CSS variables `--tp-qr-code-size`, `--tp-qr-code-foreground`, `--tp-qr-code-background` follow the `--tp-image-*` / `--tp-calendar-*` precedent; tokens `--tp-border`, `--tp-radius-xl`, `--tp-spacing`, `--tp-foreground`, `--tp-background` (light values through a scoped `color-scheme: light`, as `recipes/media-player.ts` scopes dark); events `tp-download`/`tp-download-error` follow the `tp-copy`/`tp-copy-error` action-event pattern.
