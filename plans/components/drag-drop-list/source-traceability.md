## Test translation and exclusions

- `helpers/tests/move.test.ts`: all 60 cases translated into sorting-source.test.ts. Additional invalid-index, prototype-key, null-item and frozen-data tests enforce A06/A20.
- `abstract/tests/drag-event-order.test.ts` and `manager-modifiers.test.ts`: start-before-over, inheritance, repeated manager use and source replacement/disposal exercised by manager.test.ts and DOM groups 2/15.
- `dom/tests/keyboard-sensor.test.ts`: logical aliases/case/default bindings exercised by activation tests and real custom/default keyboard input.
- `dom/tests/pointer-sensor.test.ts`: delay/controller cancellation translated into activation tests and DOM group 13, with custom-controller exception cleanup added. Mocked capture is explicitly distinguished from native input.
- `dom/tests/sortable-utilities.test.ts` and `sortable-transition.test.ts`: actual composed type guards, independent disabled lanes, partial/default/null transitions in sortable.test.ts and manager.test.ts.
- `dom/tests/optimistic-sorting-plugin.test.ts`: unchanged sparse membership and changed index/group/instance snapshots covered by manager tests and DOM groups 1/8/9/16. Lit collections deliberately use keyed preview state rather than upstream DOM mutation (A16).
- `dom/tests/scroll-utilities.test.ts`: scrolling behavior/threshold/intent translated through the dedicated local service and DOM groups 11/18. Internal upstream positional helper arguments are not an exported local API; behavior is preserved through explicit service options.
- `dom/tests/modifiers-import.test.ts`: Node built-package import verifies the same no-DOM boundary.
- `abstract/tests/plugin-registry.test.ts`: public plugin registration/configuration is explicitly excluded by drag-drop.md §1.2. Owned sensor/modifier/service lifetimes are tested through the supported local interfaces, not an invented plugin API.
