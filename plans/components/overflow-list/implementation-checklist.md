# Component implementation and evidence record

## Delivery and source record

- Component(s) / public identity: Overflow list (`tp-overflow-list`, class `TpOverflowList`); catalog kind presentational-primitive.
- Requested work / claim: Complete new component: a wrapping container of Consumer items that shows at most `limit` items, or as many as fit within `max-rows` rows of the available inline size, and replaces the rest with one count (`+N` Badge by default, any Consumer element in `slot="count"`), collapsing from the start or the end (`collapse-from`).
- Scope source: User request 2026-10-14 ("We need a new component called overflow list … configurable maxItems … two modes … maxRows … `+{hidden-element-count}` … configurable to be any element as an advanced case … overflow marker can be from the start or from the end using collapseFrom"); user decisions 2026-10-14: the default count is static (no action), Avatar group adoption is a separate follow-up, the cap is named `limit` (peer vocabulary of Description list and Select).
- In-scope changes and existing gaps: new spec contract (Foundation §18.24 Overflow list, CL §22 Overflow list, coverage rows, A.1 evidence, §11.1 state row); shared owners `foundation/layout-batch.ts` (replaces the Text motion line-pass scheduler and the Text transform fit batch), `foundation/logical-size.ts`, `observeSlots` `hidden` option, `ChangeReason` `layout` comment; `foundation/overflow-fit.ts`; `src/components/overflow-list/`; family, recipe, catalog, register, exports; docs, stories, examples, fixture, changeset. Out of scope (recorded follow-ups): Avatar group automatic overflow, Select multiple-chip `+N`.
- Repository baseline / unrelated changes: `8a76a8e` (clean worktree at start). A concurrent session is adding Description list (spec v0.26.0 `e55cfa1d`); preserve its spec and library changes.

## Architecture and reuse

- Component folder and responsibility boundaries: `src/foundation/overflow-fit.ts` (framework-free partitions: `limitPartition`, greedy wrap simulation `fitPartition`); `src/foundation/layout-batch.ts` (phased cross-instance layout batch); `src/foundation/logical-size.ts` (writing-mode-aware sizes); `src/components/overflow-list/`: `overflow-list.ts` (element: membership, manual assignment, render, outputs, diagnostics), `fit.ts` (`OverflowFitController`: observation, measurement, fit, check, lock, sizer sizes), `messages.ts`, `index.ts`.
- Supported exports / registration / constituent API impact: new exports `TpOverflowList`, `OverflowListMessages`, `OverflowCollapseFrom`; catalog tuple `['Overflow list', 'tp-overflow-list', 'presentational-primitive']`; `register.ts` defines it. Removed internal module `foundation/text-split/scheduler.ts` (not exported publicly; no consumers outside Text motion).
- Public vocabulary / tokens / parts / presentation review: `limit` (Description list, Select), `maxRows`/`max-rows`, `collapseFrom`/`collapse-from` (user), Count (CL Avatar), `messages` (peer pattern), `data-overflowing` (new state marker, §11.1 row), `tp-overflow-change` (`tp-<noun>-change`, not cancelable like `tp-layout-change`), reasons `initial`/`layout` (registered); spacing token `--tp-space-1`; no new token roles.
