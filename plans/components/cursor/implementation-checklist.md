# Component implementation and evidence record

## Delivery and source record

- Component(s) / public identity: Cursor, `tp-cursor` with its zone sub-element `tp-cursor-zone` (CL `ucl21-cursor`, Foundation §18.22 `sec-1822-custom-cursor`)
- Requested work / claim: complete component. A decorative custom pointer that hides the native cursor for mouse-like pointers, trails the pointer with a configurable spring (stiffness, damping, mass, rest thresholds, published velocity) in the top layer, and takes its look from author-declared zones (named state, template content, adopted `--tp-cursor-*` properties, native passthrough, center or bounds attraction, physics overrides, pressed marker, JS API and events).
- Scope source: user message of 2026-10-11 ("We now want to create a component to use a custom cursor pointer … velocity, damping, stiffness, mass, etc on the configuration …"), answers of 2026-10-11 ("Full set (Recommended)" zone looks; "Instant follow (Recommended)" under reduced motion; "Native passthrough, Pressed state, Stick to zone bounds, Per-zone physics"; "Published output (Recommended)" velocity), approved plan `~/.claude/plans/we-need-to-create-hazy-deer.md`.
