## Architecture and reuse

- Component folder and responsibility boundaries: `src/components/visually-hidden/{index.ts,visually-hidden.ts}`; the element owns only its host styles, the slot and the focusable-content diagnostic. The declarations live in `src/foundation/visually-hidden.ts` (framework-free, internal, not exported from the package root).
- Supported exports / registration / constituent API impact: new `TpVisuallyHidden` export; catalog tuple `['Visually hidden', 'tp-visually-hidden', 'presentational-primitive']`; `register.ts` definition; families index entry. Button diagnostic message text changes (code unchanged).
- Public vocabulary / tokens / parts / presentation review: tag `tp-visually-hidden` and part slot `visually-hidden` per `req-cl-91-tags`; no properties, tokens or hooks; diagnostic code `visually-hidden-focusable-content` follows `button-accessible-name-missing`.
