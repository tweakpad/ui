## Architecture and reuse

- Component folder and responsibility boundaries: `src/components/file-upload/`: `index.ts`; `types.ts` (public types); `messages.ts` (dictionary and formatter); `accept.ts` (normalization, matching, labels); `selection.ts` (validation pipeline); `items.ts` (ordered item store and previews); `transfer.ts` (drop snapshot, folder traversal, pre-check, document guard); `uploads.ts` (adapter queue); `styles.ts` (structural CSS); `file-upload.ts` (Lit binding). Pure modules have co-located unit tests.
- Supported exports / registration / constituent API impact: new exports `TpFileUpload`, `DEFAULT_FILE_UPLOAD_MESSAGES` and types; catalog row `['File upload', 'tp-file-upload', 'compound-reexport']`; registration; `HTMLElementTagNameMap`. Attachment gains `messages` and `DEFAULT_ATTACHMENT_MESSAGES`; Foundation gains `formatBytes`, `parseByteSize`, `listFormatter`; icons gain `upload-cloud` and `imageIcon`.
- Public vocabulary / tokens / parts / presentation review: `size` (canonical axis, reflected); positive Booleans with `defaultTrue` for default-true toggles (`keepRejected`, `allowDrop`, `preventDocumentDrop`, `showItems`, `showPreviews`, `removable`, `retryable`, `autoUpload`) as in Drawer and Code block; `messages` as in Code block; `hintTreatment` follows Attachment and Empty state `mediaTreatment`; markers from the state vocabulary; parts from `fupl-public-definition`.
