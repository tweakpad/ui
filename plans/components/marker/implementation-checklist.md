## Architecture and reuse

- Component folder and responsibility boundaries: `src/components/marker/marker.ts` binds the property, part state, Content reference and ambient role; `src/presentation/motion.ts` owns the shimmer structure (`shimmerStyles`) beside the other ambient helpers and exposes `ambientPeriod` used by `ambientAnimation`.
- Supported exports / registration / constituent API impact: `TpMarker` gains `shimmer`; `markerMotionRoles` exported from the Marker module like `skeletonMotionRoles`/`spinnerMotionRoles`; no new elements, parts or registration changes.
- Public vocabulary / tokens / parts / presentation review: property `shimmer` (reference name, no peer synonym); hooks prefixed `--tp-shimmer-*` because the effect is shared (reference uses one `--shimmer-*` set for every shimmering element, and Attachment's title uses the same effect); no new token roles; no new axes or presentation keys.
