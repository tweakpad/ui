## Architecture and reuse

- Component folder and responsibility boundaries: `src/components/tree-view/` with `tree-view.ts` (root element: lanes, rendering, events, methods, focus), `tree-item.ts` (item element: row, slots, parts, markup group), `reorder.ts` (drag-and-drop binding), `segments.ts` (records-mode transient motion regions), `messages.ts`, `types.ts`, `index.ts`. Framework-free engines in `src/foundation/tree/` (`model.ts`, `selection.ts`, `expansion.ts`, `keyboard.ts`, `lazy.ts`, `projection.ts`, `index.ts`) with colocated tests; `src/foundation/virtual-list.ts` + `virtual-range.ts`; `src/foundation/disclosure-panel.ts`.
- Supported exports / registration / constituent API impact: new exports `TpTreeView`, `TpTreeItem`, types, `DEFAULT_TREE_VIEW_MESSAGES`; Foundation exports for the engines; `collapsibleMotionRoles` remains exported (alias of the shared roles). No removal.
- Public vocabulary / tokens / parts / presentation review: names follow the authored contract `ucl20-tree-view` and peers: `value`/`defaultValue`, `selectionMode` (Accordion, Toggle group), `expanded`/`defaultExpanded`, `tp-value-change`, `tp-action` (Menu), `tp-loading-status-change` (Avatar), status values from `ImageLoadStatus`, `size` sm/default (Toggle group, Button), part prefix `tree-view-`. New token `--tp-tree-view-indent` (component-scoped spacing variable per §13.3).
