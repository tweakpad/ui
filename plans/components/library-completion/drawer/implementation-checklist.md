- Source chain: shadcn bases/base/ui/drawer.tsx imports Base Drawer; Nova styles492–534 supply appearance. Base drawer/root/DrawerRoot→Dialog/useRenderDialogRoot, root/useDrawerSnapPoints, viewport/DrawerViewport→DialogViewport/useSwipeDismiss/scrollable, popup/DrawerPopup, content/DrawerContent, swipe-area/DrawerSwipeArea, provider/DrawerProvider, indent/DrawerIndent, indent-background, virtual-keyboard-provider and their tests inspected. Foundation is stricter on atomic proposals, sequential adjacency, logical edges, and all-axis snap geometry; use it over upstream limitations.
- Existing TpDrawer is an edge-style TpDialog with no gesture/snap implementation. TpDialog remains the actual shared lifecycle/state/focus owner. Existing SurfaceState/ControllableState/OwnedPortal/OutsideInert/FloatingDismiss/Presence/motion remain owners.
- Design decision: native modal dialog makes a distinct containing viewport unable to clip its top-layer Surface, and using a native dialog viewport produces two AX dialogs. Shared Dialog therefore uses its existing top-layer popover path with existing OutsideInert for modal isolation; all siblings retain one common layer owner. Native dialog semantic host remains valid for ordinary Dialog, while Drawer uses a popover Viewport and a single inner role=dialog Surface. Update implementation-specific native :modal fixture assertions to observable contract invariants; do not weaken focus/inert checks. Reopen affected Dialog-family regression evidence.
- Atomic coordination: add an optional external lane to existing ControllableState.transaction; SurfaceState participates without replacing its owner or changing standalone requests. Drawer adds snap lane only. All snapshot getters publish before commit callbacks, synchronous rejected owner writes are consumed, and cancellation preserves the pair.
- Direct Chrome MCP available. No native touch/wheel injection; unexercised physical input remains blocked, not substituted with synthetic proof.
