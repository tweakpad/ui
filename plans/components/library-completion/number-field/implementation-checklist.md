## Architecture and reuse

NumberField is a Foundation composition over an authored logical root and an actual TpInput. The numeric state owns the number and editing buffer; the existing TpTextControl delegates to an installed editing model while retaining its native input/rendering/caret/composition and TpFormElement lifecycle. Its standalone string state remains dormant while bound and resumes on release. No duplicate string proposal/form lane is emitted. Root value proposals dispatch through the actual Input so existing Field event association remains valid; Field reads an optional semantic fieldValue channel, defaulting to the ordinary value for every other control. The Input's existing ElementInternals serializes the canonical number, not locale display text. Explicit form association uses the existing public formOwner channel with cleanup. Group/step actions are real existing controls; numerical, press and scrub policy remain in Foundation.

LocaleService owns shared Intl formatting and parsing; Meter/Progress retain the same formatting behavior. NumberField numerical normalization keeps reference directional snapping/explicit rounding; Slider's bounded multi-thumb snapping is distinct and is not replaced with NumberField policy. This mapping introduces no spacing API or paint.
