## Architecture and reuse

- Component folder and responsibility boundaries: `src/foundation/markdown/` (framework-free: `types.ts`, `block.ts`, `inline.ts`, `entities.ts`, `html.ts`, `resolve.ts`, `repair.ts`, `slug.ts`, `url.ts`, `index.ts`, tests). `src/components/markdown/` (`markdown.ts` element, `render.ts` tree → Lit, `fence-meta.ts`, `types.ts`, `index.ts`).
- Supported exports / registration / constituent API impact: new `TpMarkdown`, types and defaults exported from `src/components/index.ts`; Foundation exports from `src/foundation/index.ts` and subpath `@tweakpad/ui/markdown`; `dedentCode` moves to `src/foundation/dedent.ts` and stays re-exported from the Code block entry.
- Public vocabulary / tokens / parts / presentation review: event `tp-markdown-render` follows `tp-code-copy` naming; `size` reuses Card vocabulary; parts follow `markdown-*` keys from `mdl-presentation-keys`; flow spacing is component-scoped `--tp-markdown-flow` mapped to a `--tp-space-*` role.
