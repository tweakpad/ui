## Usage

Place one `tp-cursor` anywhere; it occupies no space and draws in the top layer, so dialogs and menus never cover it. With the default `scope="document"` it replaces the pointer on the whole page. Every example here sets `scope="region"`, which limits following to the cursor's parent element (or the element whose id is in `region`), so the rest of the page keeps the native pointer.

The cursor is decorative: its surface is hidden from assistive technology and never a hit target, so focus order and activation are unchanged. Touch and coarse pointers never engage it, and under reduced motion it snaps to the pointer instead of trailing. Use it for portfolios, galleries and landing pages, not for dense application screens.

### Following

The spring is tuned with `stiffness`, `damping` and `mass`. Lower stiffness lags further behind; lower damping overshoots and settles. The frame loop stops once the cursor rests and starts again when the pointer moves.

### Zones

Wrap content in `tp-cursor-zone` to change the cursor while the pointer is inside it. A zone is layout-neutral (`display: contents`), so wrapping never changes the content's box. `for` addresses one cursor by id; without it, a zone addresses every cursor on the page.

- `state` is published on the cursor as `data-cursor-state` and reported with `tp-cursor-state-change`.
- `--tp-cursor-size`, `--tp-cursor-color`, `--tp-cursor-blend`, `--tp-cursor-opacity` and `--tp-cursor-radius` set on the zone are adopted while it is active.
- A `<template>` child replaces the cursor's content, the default ring included, with a label, badge or icon. Keep it non-interactive.

`--tp-cursor-blend: difference` inverts the cursor over what is beneath it, so a white cursor stays visible on light and dark areas alike. Nested zones work; the innermost wins.

### Sticking

`stick="center"` pulls the cursor to the middle of the zone through the same spring. `stick="bounds"` also morphs the default ring into the zone's rectangle. Zones can carry their own `stiffness`, `damping` and `mass` while active.

Bounds come from the zone's element children, so a zone that wraps only text sticks to nothing.

### Custom look and several cursors

Slot any content into `tp-cursor` to replace the default ring. Several cursors can share a region with their own physics, such as a stiff dot and a lagging ring, and a zone with `for` reacts on one of them only.

### Native passthrough

Put `native` on a zone around text entry, embedded documents, players or anything else that needs the real pointer. Inside it the native pointer returns and the cursor hides.

### Programmatic state

`setState()` sets a state that persists until it is cleared with `null` or a zone takes over. Style each state from CSS through the `data-cursor-state` marker on the host.

<Preview
  title="Programmatic state"
  align="stretch"
  code={`<div id="cursor-state" style="display:grid;justify-items:center;gap:var(--tp-space-4);padding:var(--tp-space-8) var(--tp-space-6);border:var(--tp-border-width) dashed var(--tp-border);border-radius:var(--tp-radius-xl)">
  <style>
    #cursor-state tp-cursor[data-cursor-state="loading"] { --tp-cursor-size: var(--tp-space-12); --tp-cursor-opacity: 0.4; }
    #cursor-state tp-cursor[data-cursor-state="blocked"] { --tp-cursor-color: var(--tp-destructive); --tp-cursor-radius: var(--tp-radius-sm); }
  </style>
  <tp-cursor scope="region"></tp-cursor>
  <tp-toggle-group label="Cursor state" variant="outline">
    <tp-toggle value="loading">Loading</tp-toggle>
    <tp-toggle value="blocked">Blocked</tp-toggle>
  </tp-toggle-group>
</div>`}
  script={`const root = document.getElementById('cursor-state');
const cursor = root.querySelector('tp-cursor');
root.querySelector('tp-toggle-group').addEventListener('tp-value-change', (event) => {
  cursor.setState(event.detail.value[0] ?? null);
});`}
/>

`tp-cursor-state-change` fires before every change with its `reason`, `hover` or `programmatic`, and can be canceled to keep the current state.

### Reduced motion

Under `prefers-reduced-motion`, or with `motion-policy="reduce"`, the cursor stays but follows the pointer instantly and zone transitions are immediate. `hide-native="false"` keeps the native pointer under the cursor, for an overlay look.
