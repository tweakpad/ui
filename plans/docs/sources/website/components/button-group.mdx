## Usage

A Button group only arranges and joins its members; each `tp-button` keeps its full contract, including its own name, disabled state and activation. Give the group a `label` so assistive technology announces the set.

### Sizes

The group does not force a size or variant on its members. Set the same `size` on every Button when the set should share one height.

### Orientation

`orientation="vertical"` stacks members and moves the seams to the block axis. Members stretch to the widest one; order and keyboard behavior never change.

### Pagination

Pagination can sit in a group as one member, or split across nested groups that share the same page. A `partContracts` render delegate draws each link as an outline Button so the seams match.

<Preview
  title="Grouped pagination"
  align="stretch"
  code={`<div id="button-group-pages" style="display:grid;gap:var(--tp-space-4);justify-items:center">
  <tp-button-group label="Order pages">
    <tp-pagination label="Orders" page="2" pages="5"></tp-pagination>
  </tp-button-group>
  <tp-button-group label="Order navigation">
    <tp-button-group label="Page numbers">
      <tp-pagination label="Order pages" page="2" pages="5" data-pages-only></tp-pagination>
    </tp-button-group>
    <tp-button-group label="Previous and next">
      <tp-pagination label="Previous and next orders" page="2" pages="5" data-directions-only></tp-pagination>
    </tp-button-group>
  </tp-button-group>
</div>`}
  script={`import { html } from 'lit';

await customElements.whenDefined('tp-pagination');
const paginations = [...document.querySelectorAll('#button-group-pages tp-pagination')];
const asButton = {
  renderDelegate: ({ state, properties, bind, content }) => {
    properties['.variant'] = state.current ? 'secondary' : 'outline';
    return html\`<tp-button \${bind}>\${content}</tp-button>\`;
  },
};
for (const pagination of paginations) {
  if (pagination.hasAttribute('data-pages-only')) {
    pagination.showPrevious = false;
    pagination.showNext = false;
  }
  if (pagination.hasAttribute('data-directions-only')) {
    pagination.showPageLinks = false;
    pagination.showLabels = false;
  }
  pagination.partContracts = {
    'pagination-page-link': asButton,
    'pagination-previous': asButton,
    'pagination-next': asButton,
  };
  pagination.addEventListener('tp-value-change', (event) => {
    event.detail.sourceEvent?.preventDefault();
    for (const sibling of paginations) sibling.page = event.detail.value;
  });
}`}
/>

### Unjoined

`joined` is on by default. Set the `joined` property to `false` to keep each Button's own corners and add the standard gap while keeping the group semantics.

<Preview
  title="Unjoined"
  code={`<tp-button-group id="button-group-unjoined" label="Dialog actions">
  <tp-button variant="outline">Cancel</tp-button>
  <tp-button>Save changes</tp-button>
</tp-button-group>`}
  script={`document.getElementById('button-group-unjoined').joined = false;`}
/>

Button group implies no selection. When the members choose one shared value, such as text alignment, use a Toggle group instead.
