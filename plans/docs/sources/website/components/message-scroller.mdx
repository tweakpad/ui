## Usage

The scroller owns only scrolling: it opens at the latest message, follows growth while the reader is at the end, and keeps their place when they scroll away. Your application owns the messages and transport; Message and Bubble supply the rows.

Explicit composition is one Viewport containing one Content of Items, plus an optional Return control. Scroll up in the example above and the Return control appears to bring the reader back to the end.

### Streaming replies

While the reader is pinned to the end, `follow` keeps the viewport on the growing reply. A turn marked `scroll-anchor` holds its prompt at the reading line, so the question stays in view while the answer fills in below it. Update streamed text in place and keep the Item's `message-id`.

### Turns in a group chat

`scroll-anchor` marks where a turn starts, independent of who wrote it. In a group chat, a Marker announcing a new participant can start the turn, and their first message lands below it. `previous-item-peek` keeps that many pixels of the preceding message visible above each new turn, so the reader keeps some context.

### Jump to a message

`scrollToMessage`, `scrollToStart` and `scrollToEnd` return a receipt whose `finished` promise settles as `completed`, `superseded` or `rejected`. Use them for an outline, search results or a "jump to unread" control.

### Reader position

`provider.subscribeVisibility` reports the visible message ids and `currentAnchorId`, the last anchored turn that reached the reading line, which drives an outline. `provider.scrollable` holds independent `start` and `end` flags for content beyond each edge; subscribe with `true` to receive the current value too. Here `reading-line="16"` places the reading line just below the top, and the outline's commands pass `scrollMargin: 0` so a turn they jump to lands above it and becomes current.

### Entrance animation

The scroller has no animation property; animate a new message's inner presentation with opacity and transform after mounting it, so the Item's height stays stable. Check `resolvesReducedMotion` first to honor the reader's motion preference.
