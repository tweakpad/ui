## Usage

Each `tp-accordion-item` renders a heading with a native button trigger and a content panel. Put the trigger text in `slot="label"`; everything unslotted becomes the panel. Give every item a stable, unique `value`, which is what `value` and `default-value` refer to. Headings default to `h2`; set `heading-level` on each item to fit the page outline.

`variant` describes how items relate visually: `plain` adds no chrome, `line` separates items, `outline` wraps them in one container and `separated` gives each its own surface. It never changes behavior.

The `leading` and `trailing` slots take numbers, icons, badges or status text, but nothing interactive: they live inside the trigger button. `content-alignment="label"` lines the panel up with the label, whatever the leading content's width. `indicator-position` moves the chevron.

### Content motion

<Preview
  title="Line-by-line reveal"
  align="stretch"
  code={`<tp-accordion id="accordion-motion" variant="outline" collapsible style="max-inline-size:34rem">
  <tp-accordion-item value="setup">
    <span slot="label">Set up your workspace</span>
    <p>Pick a name and URL. You can change both later in workspace settings.</p>
    <p>Invite the people you work with most; they get an email with a link that expires in 7 days.</p>
    <p>Import projects from Jira, Linear or a CSV export.</p>
  </tp-accordion-item>
  <tp-accordion-item value="integrations">
    <span slot="label">Connect your tools</span>
    <p>Link GitHub to attach pull requests to tasks.</p>
    <p>Add Slack to get a digest of mentions and due dates every morning.</p>
  </tp-accordion-item>
</tp-accordion>`}
  script={`const accordion = document.querySelector('#accordion-motion');

accordion.addEventListener('tp-motion-request', (event) => {
  if (event.request.role !== 'content') return;
  event.respondWith({
    play(request) {
      const entering = request.phase === 'enter';
      const lines = [...request.owner.querySelectorAll('p')];
      if (!entering) lines.reverse();
      const animations = lines.map((line, index) =>
        line.animate(
          entering
            ? [{ opacity: 0, transform: 'translateY(6px)' }, { opacity: 1, transform: 'none' }]
            : [{ opacity: 1, transform: 'none' }, { opacity: 0, transform: 'translateY(-4px)' }],
          { duration: 220, delay: index * 80, easing: 'ease-out', fill: 'both' },
        ),
      );
      const finished = Promise.all(animations.map((animation) => animation.finished)).then(() =>
        animations.forEach((animation) => animation.cancel()),
      );
      return { finished, cancel: () => animations.forEach((animation) => animation.cancel()) };
    },
  });
});`}
/>

Each item asks for motion with a bubbling `tp-motion-request`. Claim only the `content` role to stagger the panel's paragraphs; the accordion still measures the panel, animates its height and decides which item is open. Because the request bubbles, a listener on one item claims motion for that item only, and a listener on the accordion covers all of them.
