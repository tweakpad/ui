## Usage

The source comes from the element's text content, dedented and trimmed, or from the `code` property. In markup, escape `<` and `&` as `&lt;` and `&amp;`, or set `code` from script. `label` adds a header with the title and language; the `title` slot replaces it with your own content.

### Custom title

<Preview
  title="Title slot"
  align="stretch"
  code={`<tp-code-block language="bash" style="max-inline-size:40rem;margin-inline:auto">
  <span slot="title" style="display:inline-flex;align-items:center;gap:var(--tp-space-2)">
    Deploy to production
    <tp-badge variant="warning">Requires approval</tp-badge>
  </span>
  npx tweakpad deploy --env production --confirm
</tp-code-block>`}
/>

Content in the `title` slot replaces the `label` text in the header, for example to add a Badge. Slotted elements are not part of the source, so the copied code stays exactly the command.

### Line numbers and highlights

`line-numbers` adds a gutter that stays put while long lines scroll. `highlight-lines` takes lines and ranges such as `2,5-7` to draw attention to the part that matters.

### Diffs

`added-lines` and `removed-lines` mark lines with a gutter marker, a tint and visually hidden text, so the change is clear without relying on color.

<Preview
  title="Diff"
  align="stretch"
  code={`<tp-code-block language="javascript" label="cart.js" line-numbers removed-lines="2-4" added-lines="5" style="max-inline-size:40rem;margin-inline:auto">
  export function subtotal(items) {
    let sum = 0;
    for (const item of items) sum += item.total;
    return sum;
    return items.reduce((sum, item) => sum + item.total, 0);
  }
</tp-code-block>`}
/>

### Collapsible

`collapsible` clips long files to `collapsed-lines` (12 by default) and adds an Expand control. Use it for reference files where the first lines tell most of the story.

### Without a header

Without `label` the copy action floats in the top corner. Set `copyable="false"` to remove it, and `wrap` to wrap long lines instead of scrolling.

### Languages and theming

The built-in highlighter covers TypeScript, JavaScript, HTML, CSS, JSON, Bash and diffs; other languages render as plain text. Syntax colors are `--tp-syntax-*` tokens, so setting them on an ancestor restyles every block inside it.

<Preview
  title="CSS"
  align="stretch"
  code={`<tp-code-block language="css" label="theme.css" style="max-inline-size:40rem;margin-inline:auto">
  :root {
    --tp-radius: 0.75rem;
    --tp-syntax-keyword: light-dark(#6d28d9, #c4b5fd);
  }

  @media (width &lt;= 40rem) {
    .workspace { grid-template-columns: 1fr; }
  }
</tp-code-block>`}
/>

The wrapper above sets four `--tp-syntax-*` roles, and both blocks inside pick them up, light and dark alike. `language="diff"` colors a unified patch as written; use `added-lines` and `removed-lines` instead when you want to mark changes in highlighted source.

For full grammar coverage, assign a Shiki-based highlighter from `@tweakpad/ui/code` to the `highlighter` property. The block renders plain text first and swaps in colors without shifting layout.
