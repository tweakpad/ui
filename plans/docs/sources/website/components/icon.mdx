## Usage

An Icon has no catalog of names: assign an `IconDefinition` to its `icon` property. In an app you import one definition module, such as `@tweakpad/ui/icons/plus`, so only the artwork you use is bundled. The examples here inline their definitions.

### Meaning

Without `label` an Icon is decorative and hidden from assistive technology, which is right when text beside it already says the same thing. A non-empty `label` gives it `role="img"` and an accessible name, for the case where the icon is the only signal.

### Size and color

`size` takes any CSS length and sets a square extent; without it the Icon uses the theme's medium icon size. The artwork strokes with `currentColor`, so it follows the surrounding text color.

### Custom artwork

A definition is a `viewBox` and a list of paths, never an HTML string, so your own marks render on the same path as the library's. Paths default to a 2-unit `currentColor` stroke with no fill; set `fill: 'currentColor'` and `stroke: 'none'` for solid shapes.

  title="Custom definition"
  code={`<div style="display:flex;gap:var(--tp-space-5)">

  <tp-icon id="icon-custom-solid" label="Starred" size="1.5rem" style="color:var(--tp-warning)"></tp-icon>
</div>`}
  script={`const star = 'm12 3 2.8 5.7 6.2.9-4.5 4.4 1.1 6.2L12 17.3 6.4 20.2l1.1-6.2L3 9.6l6.2-.9z';

  viewBox: '0 0 24 24',

  viewBox: '0 0 24 24',
  paths: [{ d: star, fill: 'currentColor', stroke: 'none' }],
};`}
