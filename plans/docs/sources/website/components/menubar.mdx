## Usage

Each child is a full Menu, so items, checks, radios and submenus work exactly as they do in [Menu](../menu/). The bar adds one shared active-menu value: opening one Menu closes the other, and once a menu is open, hovering another trigger switches to it. Use it for application commands, not site navigation.

### Keyboard

Only one trigger is in the tab order. Arrow keys, Home and End move between triggers, and ArrowDown opens the focused Menu. Give each Menu a `value` so the bar can identify it; an `aria-label` names the bar itself.

### Tracking the open menu

`tp-value-change` reports the active Menu's `value`, or an empty string when everything closes. Cancel it to keep the current menu active.

<Preview
  title="Active menu"
  code={`<div style="display:grid;gap:var(--tp-space-3);justify-items:center">
  <output id="menubar-tracked-output" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">No menu open</output>
  <tp-menubar id="menubar-tracked" aria-label="Mail">
    <tp-menu value="message" label="Message">
      <tp-button slot="trigger" variant="ghost">Message</tp-button>
      <tp-menu-item value="reply">Reply</tp-menu-item>
      <tp-menu-item value="forward">Forward</tp-menu-item>
    </tp-menu>
    <tp-menu value="mailbox" label="Mailbox">
      <tp-button slot="trigger" variant="ghost">Mailbox</tp-button>
      <tp-menu-item value="archive">Archive</tp-menu-item>
      <tp-menu-item value="junk">Move to junk</tp-menu-item>
    </tp-menu>
  </tp-menubar>
</div>`}
  script={`const bar = document.querySelector('#menubar-tracked');
const output = document.querySelector('#menubar-tracked-output');
bar.addEventListener('tp-value-change', (event) => {
  if (event.target !== bar) return;
  output.textContent = event.detail.value ? \`Open: \${event.detail.value}\` : 'No menu open';
});`}
/>

### Disabled

`disabled` on the bar disables every trigger without overwriting each Menu's own state; a single Menu can also be disabled on its own.
