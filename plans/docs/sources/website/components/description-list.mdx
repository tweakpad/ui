## Usage

A Description list renders one native `dl`. Each `tp-description-list-item` names its value with `label` and holds the value as content. Place items directly inside the list, in reading order; other children are not shown.

### Values

A value can be any content: text, a link, or components such as a Badge, a Time or a Copy button. Set `layout="stacked"` on one item to run a long value under its label.

In a vertical list, inline labels share one column whose width follows the widest label, up to 40% of the list, so the values line up.

### Show more

`limit` is the number of items shown while the list is closed. A link-style Show more button below the list reveals the rest, which expand into place, and then reads Show less. Hidden items are not shown, focusable or announced. Set `default-open` to start open, or control `open` yourself.

`messages` sets the button text. Each message is a string or a function that receives the number of hidden items and the total, as here. When a page has several lists, name each button specifically, such as "Show more billing details".

### Summary row

`orientation="horizontal"` places the pairs side by side and wraps them when space runs out. Combined with `layout="stacked"`, which puts each label above its value, it suits a summary strip above a record.

### Alignment and stacking

`align="center"` aligns each label to the end of its column so it meets its value in the middle. In narrow panels, `layout="stacked"` on the list places every label above its value.
