## Usage

Each part renders its native table element, so column layout, `colspan`, `rowspan` and header relationships work as in plain HTML. Use `tp-table-head` with `scope="row"` for the cell that names a row. Table is for reading data; it has no grid keyboard model, so compose Buttons, Menus or Inputs in cells for actions.

Constrain the Table with ordinary CSS such as `max-block-size`, and it becomes a focusable scroll region named by `label`. `sticky-header`, `sticky-footer`, `sticky-start-columns` and `sticky-end-columns` pin each edge independently and follow RTL: here the region names and the half-year totals stay in view while the months scroll between them.
