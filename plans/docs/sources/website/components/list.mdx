## Usage

`tp-list` holds `tp-list-item` rows and `tp-list-separator` dividers. Both are layout only: there is no selection, activation or keyboard model of their own. Controls in the `actions` slot keep their own focus and behavior, so one row can hold several independent actions.

### Content and actions

The default slot is the title and `description` adds supporting text; use the `title` and `description` slots when either needs markup. Empty regions collapse, so a title-only row needs nothing extra.

### Variants and sizes

`variant` is `ghost`, `outline` or `subdued`; `size` steps the density down through `sm` and `xs` for tight panels and menus.

### Media

The `media` slot takes an Icon, Avatar or image. `media-treatment` tells the row what it holds, `icon` or `image`, so the media gets the matching extent. With a description, media aligns to the first line of text.

### Lists and separators

`tp-list` carries the `list` role and its `aria-label` on the host, and its direct `tp-list-item` rows become list items. Name every list. Put `tp-list-separator` between rows for a divided list. A single `tp-list-item` also works on its own, outside a list, as in the examples above.

### Links

A whole row can be a native link: give the `list-item` part a `renderDelegate` that renders an `a` around the supplied `bind` and `content`. Controls in `actions` render beside the link, so they stay separate tab stops; decorative icons there let clicks reach the link.

<Preview
  title="Link rows"
  align="stretch"
  code={`<tp-list id="list-links" aria-label="Help resources" style="max-inline-size:30rem;margin-inline:auto;inline-size:100%">
  <tp-list-item variant="outline" data-href="#links" description="Set up your workspace in ten minutes.">
    Getting started guide
    <tp-icon slot="actions" data-icon="chevron"></tp-icon>
  </tp-list-item>
  <tp-list-item variant="outline" data-href="#links" description="Invoices, seats and tax settings.">
    Billing questions
    <tp-button slot="actions" variant="outline" size="sm">Contact sales</tp-button>
  </tp-list-item>
  <tp-list-item variant="outline" data-href="https://status.example.com/" data-external description="Opens the status page in a new tab.">
    System status
    <tp-icon slot="actions" data-icon="external"></tp-icon>
  </tp-list-item>
</tp-list>`}
  script={`import { html } from 'lit';

const icons = {
  chevron: { viewBox: '0 0 24 24', paths: [{ d: 'm9 18 6-6-6-6', strokeWidth: 2 }] },
  external: { viewBox: '0 0 24 24', paths: [{ d: 'M15 3h6v6M10 14 21 3M18 13v6a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2V8a2 2 0 0 1 2-2h6', strokeWidth: 2 }] },
};
for (const item of document.querySelectorAll('#list-links tp-list-item')) {
  const external = item.hasAttribute('data-external');
  item.partContracts = {
    'list-item': {
      renderDelegate: ({ bind, content }) => html\`<a href=\${item.dataset.href} target=\${external ? '_blank' : '_self'} rel=\${external ? 'noopener noreferrer' : ''} \${bind}>\${content}</a>\`,
    },
  };
}
for (const icon of document.querySelectorAll('#list-links tp-icon')) icon.icon = icons[icon.dataset.icon];`}
/>

### Custom content layout

Each part's `renderDelegate` can also wrap its content, for example to add a trailing duration column to the `list-item-content` part. With `media-treatment="image"`, an `img` in `media` gets a square thumbnail.
