## Usage

The browser still picks and loads the file: Image passes `src`, `srcset`, `sizes` and `<source>` children to a native `<picture>`, so lazy loading and responsive candidates work as usual. With a lazy `srcset` of width descriptors and no `sizes`, it sets `sizes="auto, 100vw"` so the browser fetches the laid-out width. Set `alt=""` for a decorative image.

### Ratio and fit

`ratio` (width ÷ height) reserves a fixed frame before the image loads, so nothing shifts. `fit` decides how the picture fills it, as `object-fit` does. Round the frame with `border-radius` on the host.

### Placeholder and fallback

While loading, Image shows a pulsing skeleton; `placeholder="spinner"` adds a spinner and `none` shows nothing. If the image fails or has no source, it shows a muted surface with a broken-image icon, or your `fallback` slot content, which stays exposed to assistive technology.

### Hover zoom

`zoom="in"` scales the picture up while the pointer hovers, and `zoom="out"` settles it from enlarged to natural size. The frame never changes size. Set `zoomed` to drive the effect from a surrounding card instead.

<Preview
  title="Hover zoom"
  align="stretch"
  code={`<div style="display:grid;grid-template-columns:repeat(2,1fr);gap:var(--tp-space-3);max-inline-size:32rem;margin-inline:auto;inline-size:100%">
  <tp-image ratio="1" zoom="in" style="border-radius:var(--tp-radius-lg)" src="https://images.unsplash.com/photo-1497215728101-856f4ea42174?w=640&q=75&auto=format&fit=crop" alt="Desks by a window"></tp-image>

Here the whole card drives the zoom, so the photo responds wherever the pointer enters the card.

### Reveal and groups

`reveal` animates an image into place the first time it scrolls into view, from tokens such as `fade up` or `zoom-in`. Wrap a set in `tp-image-group` to wait until every image has loaded, then reveal them in order, `stagger` milliseconds apart.

<Preview
  title="Staggered group"
  align="stretch"
  code={`<tp-image-group reveal="fade up" stagger="120" style="display:grid;grid-template-columns:repeat(4,1fr);gap:var(--tp-space-3);max-inline-size:40rem;margin-inline:auto;inline-size:100%">

Images outside a group reveal on their own as each loads. Tune them with `--tp-image-reveal-duration`, `--tp-image-reveal-easing` and `--tp-image-reveal-delay`, set on a container to apply to every image inside; a growing delay staggers a grid. Add `reveal-repeat` to replay the reveal each time an image scrolls back into view. Scroll the box to see it.

### Parallax

`parallax` moves the picture inside its frame as the page, or the nearest scrolling container, scrolls past. The image is enlarged by `parallax-depth` so the frame edges never show; add `zoom-in` or `zoom-out` to scale it as it travels.
