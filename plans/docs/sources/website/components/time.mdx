## Usage

Set `datetime` to an ISO string, an epoch number or a `Date`; without it the element reads its own text, so server-rendered dates upgrade in place. Relative text refreshes on one shared timer when it can next change, and focusing or hovering a value shows the full date and time.

### Modes

`auto` (the default) is relative within 30 days and absolute beyond. `calendar` says "Yesterday at 16:20"; `duration` shows a length of time.

### Presets and patterns

`preset` names a locale-aware format. `pattern` takes Unicode date-field symbols for an exact layout; quote literal words.

<Preview
  title="Absolute formats"
  code={`<div style="display:grid;gap:var(--tp-space-2);justify-items:center;font-size:var(--tp-text-sm)">
  <tp-time mode="absolute" preset="date-long" datetime="2026-10-05T14:30:00Z" time-zone="UTC"></tp-time>
  <tp-time mode="absolute" preset="full" datetime="2026-10-05T14:30:00Z" time-zone="UTC"></tp-time>
  <tp-time mode="absolute" pattern="EEE d MMM yyyy 'at' HH:mm" datetime="2026-10-05T14:30:00Z" time-zone="UTC"></tp-time>
</div>`}
/>

Write `yyyy-MM-dd`, not Moment-style `YYYY-MM-DD`: unsupported letters render literally and raise a diagnostic instead of silently formatting a different year.

### Dates and time zones

A date-only value stays on its calendar day in every time zone and compares by days. Instants format in the browser's zone unless `time-zone` names one, and `hour-cycle` forces 12- or 24-hour clocks.

### Calendar phrases

`mode="calendar"` names nearby days, such as "Today at 09:12" or "Last Friday at 16:40", and falls back to an absolute date beyond a week. Month and weekday names come from the locale; the surrounding phrases come from the `messages` property, with `{time}`, `{weekday}` and `{date}` placeholders, so you can translate or reword them.

### Other precisions

A value keeps the precision it was written with: a month, a yearless date such as a birthday, an ISO week or a time of day each format as exactly that, never as a full date with invented parts.

### Countdowns and elapsed time

`mode="duration"` on an instant shows the time until or since it as a ticking length, such as a call timer or a sale countdown. `precision` sets the smallest unit shown, which also slows the updates. `tense="past"` shows a slightly future instant, for example from a server clock that runs ahead, as "now" instead of "in 3 seconds".

In `auto` mode, `threshold` (an ISO duration, `P30D` by default) sets how far from now values stay relative before they switch to absolute text.

### Description

The tooltip shows `tooltip-pattern` (default `dd/MM/yy HH:mm`) and makes the value focusable. It is skipped when it would repeat the visible text; `tooltip="false"` removes it and the tab stop.

### Unreadable input

Input that cannot be read as a date, time or duration keeps the authored content and exposes `data-invalid`, so a server-rendered label never turns into a wrong date.
