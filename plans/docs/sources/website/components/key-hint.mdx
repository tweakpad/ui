## Usage

A Key hint only describes a shortcut; your application implements it. Compose one `tp-key-hint` per key inside a `tp-key-hint-group`, which owns spacing and separators.

### Generated notation

`key` renders platform notation and a readable accessible name. `mod` is Command on macOS and Ctrl elsewhere; `platform` pins a platform, otherwise it is detected.

<Preview
  title="Modifiers"
  code={`<div style="display:grid;gap:var(--tp-space-3);justify-items:start">
  <tp-key-hint-group platform="mac" separator="none">
    <tp-key-hint key="control"></tp-key-hint>
    <tp-key-hint key="alt"></tp-key-hint>
    <tp-key-hint key="shift"></tp-key-hint>
    <tp-key-hint key="command"></tp-key-hint>
  </tp-key-hint-group>
  <tp-key-hint-group platform="windows">
    <tp-key-hint key="control"></tp-key-hint>
    <tp-key-hint key="shift"></tp-key-hint>
    <tp-key-hint>P</tp-key-hint>
  </tp-key-hint-group>
</div>`}
/>

### Separators and sequences

`separator` is `plus` by default, `none` for adjacent keycaps, and `then` for a sequence. Nest groups to describe a chord followed by another chord.

<Preview
  title="Sequence"
  code={`<tp-key-hint-group separator="then" label="Comment on selection">
  <tp-key-hint-group separator="none">
    <tp-key-hint key="mod"></tp-key-hint>
    <tp-key-hint>K</tp-key-hint>
  </tp-key-hint-group>
  <tp-key-hint-group separator="none">
    <tp-key-hint key="mod"></tp-key-hint>
    <tp-key-hint>C</tp-key-hint>
  </tp-key-hint-group>
</tp-key-hint-group>`}
/>

### In controls

Place a hint inside a Button's `icon-end` slot, an Input group addon or a Tooltip. The owning control keeps focus and activation; the hint stays informative.

<Preview
  title="Button and tooltip"
  code={`<tp-button variant="outline">
  Accept invite
  <tp-key-hint slot="icon-end" key="enter"></tp-key-hint>
</tp-button>
<tp-tooltip>
  <tp-button slot="trigger" variant="outline">Save</tp-button>
  Save changes
  <tp-key-hint-group separator="none">
    <tp-key-hint key="mod"></tp-key-hint>
    <tp-key-hint>S</tp-key-hint>
  </tp-key-hint-group>
</tp-tooltip>`}
/>

In an Input group, put the shortcut in an addon slot such as `inline-end`; the group lays out the addon and the Key hint group spaces the keys.

<Preview
  title="Input group"
  align="stretch"
  code={`<tp-input-group style="max-inline-size:22rem;margin-inline:auto;inline-size:100%">
  <tp-input label="Search" type="search" placeholder="Jump to a project"></tp-input>
  <tp-key-hint-group slot="inline-end" separator="none">
    <tp-key-hint key="mod"></tp-key-hint>
    <tp-key-hint>P</tp-key-hint>
  </tp-key-hint-group>
</tp-input-group>`}
/>

### Icon keys

A key's content replaces the generated notation, so it can hold a `tp-icon`, which takes the key's icon size. Give icon-only keys a `label` for their accessible name.

<Preview
  title="Icon keys"
  code={`<p id="key-hint-icons" style="margin:0;display:flex;align-items:center;gap:var(--tp-space-2)">
  Move between results with
  <tp-key-hint-group separator="none">
    <tp-key-hint label="Up arrow"><tp-icon data-icon="up"></tp-icon></tp-key-hint>
    <tp-key-hint label="Down arrow"><tp-icon data-icon="down"></tp-icon></tp-key-hint>
  </tp-key-hint-group>
  and open with
  <tp-key-hint label="Return"><tp-icon data-icon="return"></tp-icon></tp-key-hint>
</p>`}
  script={`const icons = {
  up: { viewBox: '0 0 24 24', paths: [{ d: 'm18 15-6-6-6 6', strokeWidth: 2 }] },
  down: { viewBox: '0 0 24 24', paths: [{ d: 'm6 9 6 6 6-6', strokeWidth: 2 }] },
  return: { viewBox: '0 0 24 24', paths: [{ d: 'M20 4v7a4 4 0 0 1-4 4H4M9 10l-5 5 5 5', strokeWidth: 2 }] },
};
for (const icon of document.querySelectorAll('#key-hint-icons tp-icon')) icon.icon = icons[icon.dataset.icon];`}
/>

### Localization and direction

`keyLabels` on a group replaces the visible text and spoken name of generated keys, and the `then` entry translates the sequence word; children inherit it. Spacing is logical, so hints follow right-to-left text. Set `dir="ltr"` on a group when the notation must keep left-to-right order.

<Preview
  title="Localized and right-to-left"
  code={`<div style="display:grid;gap:var(--tp-space-4);justify-items:start">

    <tp-key-hint-group id="key-hint-french" separator="then" platform="windows" label="Commenter la sélection">

    </tp-key-hint-group>
  </p>
  <div dir="rtl" lang="ar" style="display:flex;align-items:center;gap:var(--tp-space-3)">
    <span>اضغط
      <tp-key-hint-group separator="none"><tp-key-hint key="mod"></tp-key-hint><tp-key-hint>K</tp-key-hint></tp-key-hint-group>
      للبحث</span>
    <tp-button variant="outline">إرسال<tp-key-hint slot="icon-end" key="enter" label="إدخال"></tp-key-hint></tp-button>

</div>`}
  script={`await customElements.whenDefined('tp-key-hint-group');

  control: { text: 'Ctrl', label: 'Contrôle' },
  then: 'puis',
};`}
/>
