## Usage

A Separator fills its container along its axis: full width when horizontal, full height when vertical. It reserves no spacing of its own, so the surrounding layout sets the gap.

### Orientation

<Preview
  title="Vertical"
  code={`<div style="display:flex;align-items:center;gap:var(--tp-space-3);block-size:var(--tp-space-6)">
  <tp-button variant="ghost" size="sm">Edit</tp-button>
  <tp-separator orientation="vertical"></tp-separator>
  <tp-button variant="ghost" size="sm">Duplicate</tp-button>
  <tp-separator orientation="vertical"></tp-separator>
  <tp-button variant="ghost" size="sm">Archive</tp-button>
</div>`}
/>

A vertical Separator takes the height of its container, so give the row a block size or let a flex row stretch it.

Separators are decorative by default and hidden from assistive technology. Set the `decorative` property to `false` when the rule marks a real boundary between groups; it then exposes `role="separator"` with its orientation.
