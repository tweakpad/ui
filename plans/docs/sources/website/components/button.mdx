`variant` is visual emphasis only. A Button does not own selection, open or pending state; pair it with a Toggle or a disclosure component for those.

### Icon only

In an icon size only the marks are visible. The label stays in the content, hidden visually, and names the Button for assistive technology, so write the action as the label instead of adding `aria-label`.

<Preview
  title="Icon only"
  code={`<tp-button size="icon" variant="outline">

  New document
</tp-button>
<tp-button size="icon-sm" variant="ghost">
  <svg slot="icon-start" aria-hidden="true" width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M3 6h18M8 6V4h8v2M19 6l-1 14H6L5 6"/></svg>
  Delete
</tp-button>`}
/>

`icon-xs`, `icon-sm`, `icon` and `icon-lg` make square Buttons that match the heights of `xs`, `sm`, the default and `lg`, so an icon action lines up with text Buttons of the same size.

### Marks

Use the `icon-start` and `icon-end` slots for custom marks, and mark them decorative. `loading-position` composes the library's Spinner and exposes busy semantics without disabling the action.

<Preview
  title="Marks and loading"
  code={`<tp-button variant="outline">
  <span slot="icon-start" aria-hidden="true">←</span>
  Back
</tp-button>
<tp-button>
  Next
  <span slot="icon-end" aria-hidden="true">→</span>
</tp-button>
<tp-button loading-position="leading">Saving</tp-button>`}
/>

A Button in a text size whose label is empty shows only its marks, with one gap between them and the icon padding at both edges, as in a trigger that pairs an icon with a chevron. Nothing visible names it, so give it an `aria-label`. Text added to the label later shows the label again.

<Preview
  title="Icon and chevron"
  code={`<tp-button variant="outline" size="sm" aria-label="Text color">
  <svg slot="icon-start" aria-hidden="true" width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M4 20h16M6 16l6-12 6 12M8 12h8"/></svg>
  <svg slot="icon-end" aria-hidden="true" width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m6 9 6 6 6-6"/></svg>
</tp-button>`}
/>

### Links

Set `href` and the Button renders a native anchor while keeping any visual variant. `target`, `rel` and `download` are forwarded.

<Preview
  title="As a link"
  code={`<tp-button href="#links">Read the guide</tp-button>
<tp-button variant="outline" href="#links" download="report.csv">Download report</tp-button>`}
/>

### Forms

The default `type` is `button`, so a Button never submits by accident. A named submit Button contributes its `name` and `value` as the submitter.

<Preview
  title="Form actions"
  code={`<form style="display:flex;gap:var(--tp-space-2)">
  <tp-button type="submit" name="intent" value="save">Save</tp-button>
  <tp-button type="reset" variant="outline">Reset</tp-button>
</form>`}
/>

### Disabled

<Preview
  title="Disabled"
  code={`<tp-button disabled>Unavailable</tp-button>
<tp-button disabled focusable-when-disabled variant="outline">Discoverable</tp-button>`}
/>

`focusable-when-disabled` keeps a disabled Button in the tab order, exposing `aria-disabled` without allowing activation.
