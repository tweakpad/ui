## Usage

Set `value` to a number, a bigint or text, or leave it unset and write the input as the element's content, so server-rendered text upgrades in place. `preset` names the transform; the default, `text`, presents the input unchanged. The element paints no surface and inherits font and color, so it fits in table cells, list rows and labels.

### Case and identifiers

Case presets change how words are capitalized and follow the locale of the closest `lang`. Identifier presets split names at spaces, `-`, `_`, `.`, case changes and acronyms, so a property key such as `billingEmail` can become the label "Billing email".

`capitalize` and `sentence` change only the first letter of a word and leave the rest as written, so acronyms survive. `camel`, `pascal` and `snake` complete the identifier presets.

### Numbers, currency and units

Numeric presets format through `Intl.NumberFormat` with tabular figures. `currency` takes an ISO 4217 code for the `currency` preset, `unit` a unit identifier such as `kilometer` or `megabyte-per-second`, and `decimals` fixes the fraction digits. `percent` reads a ratio, so `0.82` is 82%.

Abbreviated forms are spelled out for assistive technology: "1.2M" is read as "1.2 million" and "50 MB/s" as "50 megabytes per second". Each numeric value renders as a `data` element carrying the raw number. Grouped text such as `1,234` is not read as a number; it stays as written and the element sets `invalid`.

### Bytes and durations

`bytes` formats a byte count with binary units (1 KB = 1024 B). `duration` reads seconds and shows them as a clock, read aloud as "1 hour, 2 minutes, 5 seconds". Both reject negative values.

### Locales

Without `locale`, the closest `lang` decides separators, digits and currency placement, and a change to `lang` updates the text in place. Set `locale` to fix one value to a language regardless of the page.

### Truncation

`truncate` keeps the text on one line that fits the element's width, placing the omission (`…`) at the `end`, the `middle` or the `start`. Use `middle` for file names whose extension matters and `start` for paths whose last segment matters. `truncate-by="words"` removes whole words instead of characters. Drag the handle to see each value refit.

While shortened, the value can be focused and shows the full text in a tooltip; `tooltip="false"` removes the tooltip and the tab stop. Assistive technology always hears the complete text once. Inside a flex or grid track the element can shrink below its full text without changing height.

### Length limits

`max-length` caps the characters or words kept. On its own it cuts at the end and the text still wraps; with `truncate`, the cap applies on top of the width and the omission goes where `truncate` places it.

### Formatters

The `formatter` property replaces the preset for one element. It receives a context with the input, the locale and `apply()`, which runs any preset, and returns text, or `{ text, accessibleText }` when assistive technology should hear something else. Its output is always text, never markup.

<Preview
  title="Formatter"
  code={`<div id="text-transform-formatter" style="display:grid;gap:var(--tp-space-2);font-size:var(--tp-text-sm)">
  <tp-text-transform data-format="seats" value="0.18"></tp-text-transform>
  <tp-text-transform data-format="order" value="482"></tp-text-transform>
</div>`}
  script={`const formatters = {
  seats: (context) => \`\${context.apply('percent')} of seats left\`,
  order: ({ value }) => ({ text: \`#ORD-\${String(value).padStart(6, '0')}\`, accessibleText: \`Order \${value}\` }),
};
await customElements.whenDefined('tp-text-transform');
for (const value of document.querySelectorAll('#text-transform-formatter tp-text-transform')) {
  value.formatter = formatters[value.dataset.format];
}`}
/>

For options beyond the attributes, assign `Intl.NumberFormatOptions` to the `format` property, or `{ style, guide }` for `duration`.

### Named presets

`defineTextPreset(name, definition)` from `@tweakpad/ui` names a format once for the whole page, either a built-in preset with options or a formatter. Elements then use it like any preset, and every element with that name updates when it is defined or replaced. Built-in names are reserved.

<Preview
  title="Named presets"
  code={`<div style="display:grid;gap:var(--tp-space-2);font-size:var(--tp-text-sm)">
  <span>Team plan <tp-text-transform preset="plan-price" value="480"></tp-text-transform> per year</span>
  <span>Business plan <tp-text-transform preset="plan-price" value="1200"></tp-text-transform> per year</span>
  <span>Assigned to <tp-text-transform preset="desk" value="14"></tp-text-transform></span>
</div>`}
  script={`import { defineTextPreset } from '@tweakpad/ui';

defineTextPreset('plan-price', { preset: 'currency', format: { currency: 'EUR', maximumFractionDigits: 0 } });
defineTextPreset('desk', ({ value }) => ({
  text: \`D-\${String(value).padStart(3, '0')}\`,
  accessibleText: \`Desk \${value}\`,
}));`}
/>

An element that names a preset before it exists shows its input as text until the definition arrives. The same goes for input a numeric preset cannot read: it stays as written, and the element exposes `data-invalid` for styling.
