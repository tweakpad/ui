## Usage

Put a native `<video>` or `<audio>` and one layout inside the player. The player owns a single media store; every control reads state from it and changes playback through its request pipeline, so buttons, keys and gestures always agree.

### Audio

An `<audio>` element works the same way. `tp-media-audio-layout` is the standard audio player: an always-visible bar in the page's color scheme with play, the timeline, speed and volume, plus skip buttons when there is room. It takes the same `hide` and `seek-buttons` options as the video layout.

<Preview
  title="Audio layout"
  align="stretch"
  code={`<tp-media-player content-title="T-Rex roar" style="max-inline-size:36rem;margin-inline:auto;inline-size:100%">
  <audio src="https://interactive-examples.mdn.mozilla.net/media/cc0-audio/t-rex-roar.mp3" preload="metadata"></audio>
  <tp-media-audio-layout id="media-player-audio-layout"></tp-media-audio-layout>
</tp-media-player>`}
  script={`// In @tweakpad/ui 0.1.1 the audio layout's bar takes the dark over-video scheme;
// this keeps it in the page's color scheme until the library fix ships.
document.querySelector('#media-player-audio-layout').partPresentation = {
  'media-controls': { styleHook: { 'color-scheme': 'inherit' } },
};`}
/>

### Choosing controls

`hide` removes built-in controls from a layout by name, and `seek-buttons` adds skip back and forward next to play. Seek distance comes from the player's `seek-step`.

Hidden controls are gone, not disabled. Controls the media cannot support, such as picture-in-picture in some browsers, hide themselves.

### Live streams

A stream is live when the media reports `streamType: 'live'` or an infinite duration, and it has a DVR window when it reports `targetLiveWindow`. The video layout then switches to its live variant: a live button that seeks to the edge and a timeline that spans only the window. Streaming engines report these members through their media element; this example adds them to a looping clip to simulate a 20-second window.

<Preview
  title="Live with DVR (simulated)"
  align="stretch"
  code={`<tp-media-player id="media-player-live" content-title="Launch keynote" style="max-inline-size:44rem;margin-inline:auto">
  <tp-media-video-layout></tp-media-video-layout>
</tp-media-player>`}
  script={`const player = document.querySelector('#media-player-live');
const video = Object.assign(document.createElement('video'), {
  src: 'https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4',
  loop: true,
  playsInline: true,
  preload: 'auto',
  width: 1280,
  height: 720,
});
// Simulation only: real live media reports these members itself.
const seekableEnd = () => (video.seekable.length ? video.seekable.end(video.seekable.length - 1) : 0);
Object.defineProperties(video, {
  streamType: { get: () => 'live' },
  targetLiveWindow: { get: () => 20 },
  liveEdgeStart: { get: () => Math.max(0, seekableEnd() - 3) },
});
player.prepend(video);`}
/>

### Quality and audio tracks

Media without native rendition or audio-track lists, such as an HLS or DASH engine, supplies them through `mediaAdapter`. Each list is array-like and an event target; renditions add `selectedIndex`, where `-1` means adaptive. The settings menu then gains Quality and Audio submenus. This mock records the selection without changing the video.

<Preview
  title="Tracks adapter (mock)"
  align="stretch"
  code={`<tp-media-player
  id="media-player-tracks"
  content-title="Product walkthrough"
  poster="https://images.unsplash.com/photo-1498050108023-c5249f4df085?w=1280&q=80"
  style="max-inline-size:44rem;margin-inline:auto"
>
  <video
    src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4"
    width="1280"
    height="720"
    preload="metadata"
    playsinline
  ></video>
  <tp-media-video-layout></tp-media-video-layout>
</tp-media-player>`}
  script={`const list = (items) => Object.assign(new EventTarget(), items, { length: items.length });

let selected = -1;
let active = 1;
const renditions = list([
  { id: '1080p', width: 1920, height: 1080, bitrate: 6_000_000 },
  { id: '720p', width: 1280, height: 720, bitrate: 3_000_000 },
  { id: '360p', width: 640, height: 360, bitrate: 800_000 },
]);
for (let index = 0; index < renditions.length; index++) {
  Object.defineProperty(renditions[index], 'active', { get: () => index === active });
}
Object.defineProperty(renditions, 'selectedIndex', {
  get: () => selected,
  set(index) {
    selected = index; // your engine would switch levels here
    if (index >= 0) active = index;
    renditions.dispatchEvent(new Event('change'));
    renditions.dispatchEvent(new Event('activechange'));
  },
});

const audioTracks = list([
  { id: 'main', kind: 'main', label: 'English', language: 'en' },
  { id: 'commentary', kind: 'commentary', label: 'Director commentary', language: 'en' },
]);
for (let index = 0; index < audioTracks.length; index++) {
  let enabled = index === 0;
  Object.defineProperty(audioTracks[index], 'enabled', {
    get: () => enabled,
    set(value) {
      if (enabled === value) return;
      enabled = value;
      audioTracks.dispatchEvent(new Event('change'));
    },
  });
}

await customElements.whenDefined('tp-media-player');
document.querySelector('#media-player-tracks').mediaAdapter = { videoRenditions: renditions, audioTracks };`}
/>

### Keyboard

With focus anywhere in the player, Space or K plays and pauses, the arrow keys seek and change volume, M mutes, F toggles fullscreen and C toggles captions. Shortcuts are published through `aria-keyshortcuts` and appear in the layout's tooltips. Set `hotkey-scope="document"` to route keys from anywhere on the page to the most recently used player.
