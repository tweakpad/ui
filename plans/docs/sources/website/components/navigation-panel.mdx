## Usage

The panel owns layout and state: navigation in a sticky column, your page in `tp-navigation-panel-inset`, and a trigger that toggles between them. Links are real anchors, so mark the current page with `active`.

`compact="false"` states that this is wide mode. The panel has no built-in breakpoint: set `compact` from your own layout logic, or give it a `responsiveAdapter` that observes the viewport and reports when to switch.

### Collapse modes

`collapse-mode="compact"` collapses to an icon rail that keeps every destination reachable, with each link's `tooltip` naming it. The default `off-canvas` slides the panel away entirely, and `none` keeps it open.

### Menus

A `tp-menu` can be an item's main content, like a team switcher or account menu, or sit beside a link as its row actions. Put a `tp-navigation-panel-action` in the menu's `trigger` slot; `show-on-hover` hides a row action until its item is hovered or focused, while still reserving its space.
