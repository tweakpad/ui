## Usage

A visually hidden native file input is the control: it takes focus, opens the picker with Enter or Space and carries the Field label and errors. Clicking anywhere on the drop surface also opens the picker, and dropping files on it adds them. Accepted files submit with the form under `name`. The component never transfers a file unless you give it an upload adapter.

### Drop surface

The surface generates its title and a hint from `accept` and the size limit. The `title` and `description` slots replace them with your own wording, and `media` replaces the upload mark. `show-trigger` adds a Browse Button; it duplicates the surface's own action and is not a separate tab stop. `size="sm"` makes a compact surface for sidebars and dialogs.

Without `multiple` a new file replaces the current one, which suits a single logo or backup.

### Limits and validation

`accept` takes extensions, media types and wildcards such as `image/*`; it filters the picker and checks every dropped file too. `max-file-size`, `min-file-size` and `max-total-size` accept bytes or size text such as `25MB`. With `multiple`, `max-files` caps the count: a batch fills the remaining slots and rejects the rest. `hint-treatment="badges"` lists the rules as Badges instead of a sentence.

<Preview
  title="Rejected files"
  align="stretch"
  code={`<tp-file-upload id="file-upload-limits" name="receipts" multiple max-files="5" accept=".pdf,.jpg,.png" max-file-size="5MB" hint-treatment="badges" style="inline-size:100%;max-inline-size:30rem;margin-inline:auto">
  <span slot="title">Add receipts</span>
</tp-file-upload>`}
  script={`await customElements.whenDefined('tp-file-upload');
const upload = document.querySelector('#file-upload-limits');
const file = (name, size, type) => new File([new Uint8Array(size)], name, { type });
upload.addFiles([
  file('taxi-berlin-0412.pdf', 184_000, 'application/pdf'),
  file('hotel-folio-scan.png', 7_400_000, 'image/png'),
  file('dinner-receipt.heic', 1_200_000, 'image/heic'),
]);`}
/>

Rejected files stay in the list as error items with the reason, and they block form submission until they are removed. Set `keep-rejected="false"` to only announce them and report them through `tp-file-reject`.

For rules about a file's contents, assign a `fileValidator` function. It receives each file in turn and returns nothing to accept it, a message or `{ code, message }` to reject it, or `{ meta, description }` to attach metadata such as a row count.

<Preview
  title="Custom validator"
  align="stretch"
  code={`<tp-file-upload id="file-upload-validator" name="contacts" multiple accept=".csv" style="inline-size:100%;max-inline-size:30rem;margin-inline:auto">
  <span slot="title">Import contacts</span>
  <span slot="description">CSV with name, email and phone columns</span>
</tp-file-upload>`}
  script={`await customElements.whenDefined('tp-file-upload');
const upload = document.querySelector('#file-upload-validator');
upload.fileValidator = async (file) => {
  const [header = '', ...rows] = (await file.text()).trim().split(/\\r?\\n/);
  const columns = header.toLowerCase().split(',').map((cell) => cell.trim());
  const missing = ['name', 'email', 'phone'].filter((column) => !columns.includes(column));
  if (missing.length) return { code: 'csv-columns', message: \`Missing columns: \${missing.join(', ')}.\` };
  return { meta: { rows: rows.length }, description: \`\${rows.length} contacts\` };
};
upload.addFiles([
  new File(['name,email,phone\\nMaya Chen,maya@northwind.co,555-0101\\nJonas Weber,jonas@northwind.co,555-0102\\n'], 'crm-export.csv', { type: 'text/csv' }),
  new File(['full_name,email\\nAmara Okafor,amara@northwind.co\\n'], 'newsletter-list.csv', { type: 'text/csv' }),
]);`}
/>

A thrown error or rejected promise rejects the file; it is never accepted by accident.

### Uploads

Assign an `uploader` to transfer files. It is called once per accepted file with an `AbortSignal` and an `onProgress(loaded, total)` callback, and its result is stored as the item's `response`. Files queue and start in order with `upload-concurrency` in flight; a rejected promise shows the error with a Retry Button, and removing a file aborts its upload. Set `auto-upload="false"` to start them yourself with `upload()`.

<Preview
  title="Upload adapter"
  align="stretch"
  code={`<tp-file-upload id="file-upload-adapter" name="assets" multiple upload-concurrency="2" style="inline-size:100%;max-inline-size:30rem;margin-inline:auto">
  <span slot="description">Files upload as soon as they are added</span>
</tp-file-upload>`}
  script={`await customElements.whenDefined('tp-file-upload');
const upload = document.querySelector('#file-upload-adapter');
const attempts = new Map();

// Stands in for fetch or XMLHttpRequest: reports progress, and fails a file named "*-fail*" once.
upload.uploader = (item, { signal, onProgress }) => new Promise((resolve, reject) => {
  const total = item.file.size || 1;
  let loaded = 0;
  const timer = setInterval(() => {
    loaded = Math.min(total, loaded + total / 12);
    onProgress(loaded, total);
    if (loaded < total) return;
    clearInterval(timer);
    const attempt = (attempts.get(item.id) ?? 0) + 1;
    attempts.set(item.id, attempt);
    if (item.file.name.includes('-fail') && attempt === 1) reject(new Error('Server returned 503. Try again.'));
    else resolve({ url: \`/files/\${encodeURIComponent(item.file.name)}\` });
  }, 250);
  signal.addEventListener('abort', () => {
    clearInterval(timer);
    reject(signal.reason);
  });
});

const file = (name, size, type) => new File([new Uint8Array(size)], name, { type });
upload.addFiles([
  file('launch-video-cut.mp4', 4_800_000, 'video/mp4'),
  file('press-kit.zip', 2_100_000, 'application/zip'),
  file('pricing-sheet-fail.pdf', 640_000, 'application/pdf'),
]);`}
/>

Listen for `tp-upload-complete` and `tp-upload-error` to update your own state. Without an adapter, files stay selected and you can drive their status with `setItemState()`.

### Forms

Inside a Field, the label names the control, `required` reports a missing file and rejected files show their message. Each accepted file is appended to the form data under `name`, and Reset clears the files. When your server refuses a file after upload, `rejectFile()` moves it to the error items.

  title="Field and form"
  align="stretch"
  code={`<tp-form id="file-upload-form" aria-label="Upload signed contract" style="max-inline-size:30rem;margin-inline:auto">
  <tp-field label="Signed contract" description="PDF up to 5 MB">
    <tp-file-upload name="contract" required accept="application/pdf" max-file-size="5MB" hint-treatment="none" size="sm" show-trigger></tp-file-upload>
  </tp-field>
  <div slot="actions">
    <tp-button type="reset" variant="outline">Reset</tp-button>
    <tp-button type="submit">Submit</tp-button>
  </div>
  <output id="file-upload-form-output" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)"></output>
</tp-form>`}
  script={`const form = document.querySelector('#file-upload-form');
const output = document.querySelector('#file-upload-form-output');
form.onFormSubmit = (values, { data }) => {
  output.textContent = \`Submitted \${data.getAll('contract').map((file) => file.name).join(', ')}\`;
};
form.addEventListener('tp-reset', () => { output.textContent = ''; });`}
/>

Here the server check runs right after the files are added: `rejectFile()` turns the duplicate into an error item with your message, and it blocks submission until it is removed.

<Preview
  title="Server rejection"
  align="stretch"
  code={`<tp-file-upload id="file-upload-server" name="invoices" multiple accept="application/pdf" size="sm" style="inline-size:100%;max-inline-size:30rem;margin-inline:auto"></tp-file-upload>`}
  script={`await customElements.whenDefined('tp-file-upload');
const upload = document.querySelector('#file-upload-server');
const invoice = (name) => new File(['%PDF-1.7'], name, { type: 'application/pdf' });
const { accepted } = await upload.addFiles([invoice('INV-2048.pdf'), invoice('INV-2031.pdf')]);
// A simulated server already holds INV-2031 and refuses it a moment later.
setTimeout(() => {
  const duplicate = accepted.find((file) => file.name === 'INV-2031.pdf');
  if (upload.isConnected && duplicate) upload.rejectFile(duplicate, 'INV-2031 was already submitted on Oct 2.');
}, 800);`}
/>

`readonly` keeps the control focusable and its files submitted, but refuses changes and hides Remove; `disabled` refuses every change and submits nothing.
