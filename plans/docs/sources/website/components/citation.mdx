## Usage

A Citation sits in running text after the statement it supports. Its label names the source, and with an `href` it is a link to it. Use one style per passage: labelled chips like the one above, or numbered markers that point to a Citation list.

### Labels and icons

The default slot is the label, such as a site name or a source title; long labels end in an ellipsis. `src` adds a site icon, which keeps its space while it loads. Without `src`, or when the image fails, the `icon` slot is used, else a generic web mark.

A site address, one that starts with `http://` or `https://`, opens in a new tab unless you set `target`. While a labelled site citation is hovered or focused, an external-link mark fades in over the end of the label without changing its width, so the surrounding text never moves. Without an accepted `href` the citation is plain text and takes no tab stop.

### Source preview

A `description` adds a preview card that opens after a short hover or on keyboard focus. It shows the site icon, the host, `source-title` and the description. Use `source-title` for the full title when the label is only the site name. The `preview` slot takes extra content for the card.

The preview is supplementary. The citation still activates its link normally, and the destination page should carry everything a reader needs.

### Numbered references

For footnote-style references, list the sources in a `tp-citation-list` and point to them from the text. The list numbers its entries in document order from `start`. An in-text citation names an entry by its `id` with `source` and takes its number, address, title and preview from it, so an empty `source` citation renders as a plain number. `superscript` raises it like a footnote marker.

Give each marker its entry's fragment as `href`, as above: activating the marker moves focus to the entry, and the entry opens the site. Without its own `href`, a marker links straight to the source. Editing an entry updates every citation that names it.

### List layout

`orientation="horizontal"` lets the entries wrap in rows, which suits a compact source strip under a generated answer. Set `index` on a citation to override its position.
