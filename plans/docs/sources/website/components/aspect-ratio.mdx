## Usage

Set `ratio` to width divided by height, such as `1.7778` for 16:9 or `1` for a square. The box takes its width from the container and derives its height, so content can't stretch it. Always pass a ratio; the 16:9 default exists only for compatibility.

Reserving the box before media loads prevents layout shift in feeds, galleries and video embeds. Width comes from the surrounding layout; the ratio is the only size input.

### Fit

  </tp-aspect-ratio>

`fit` sets how images and video fill the box, like `object-fit`: `cover` crops, `contain` letterboxes and `fill` stretches. It never changes the ratio. The box adds no image semantics, so keep `alt` on the image itself.
