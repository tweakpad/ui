## Usage

Navigation Menu is for moving between pages: links keep native activation, modifier keys, targets and Tab order, and nothing gets command-menu roles. For application commands, use Menu or Menubar.

### Panels and direct links

An Item with a `trigger` and `content` slot opens a panel on hover or press; an Item holding only a link is a plain destination. Panels share one measured viewport, so switching between Items animates size instead of reopening.

### Current page

Mark the current destination with the `active` attribute so it is exposed as `aria-current="page"`. Add `close-on-click` to a link when following it should also close the panel, such as an in-page anchor.

<Preview
  title="Active link"
  code={`<tp-navigation-menu aria-label="Account">
  <tp-navigation-menu-item value="settings">
    <tp-button slot="trigger" variant="ghost">Settings</tp-button>
    <div slot="content" style="display:grid;min-inline-size:12rem">
      <a href="#profile" active>Profile</a>
      <a href="#billing" close-on-click>Billing</a>
      <a href="#notifications" close-on-click>Notifications</a>
    </div>
  </tp-navigation-menu-item>
  <tp-navigation-menu-item><a href="#support">Support</a></tp-navigation-menu-item>
</tp-navigation-menu>`}
/>

### Vertical

With `orientation="vertical"`, open the panel beside the list using `placement="inline-end start"` so the remaining destinations stay reachable.
