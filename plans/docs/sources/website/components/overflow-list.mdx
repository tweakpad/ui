## Usage

The items are the element children of the list, in document order. Items that do not fit are replaced by one count, `+3` by default, which assistive technology reads as "3 more". The list adds no role or focus behavior to its items, so interactive items keep their own semantics. Omitted items stay in the document but are not shown, focusable or announced.

### Item limit

`limit` shows at most that many items. Use it when the number of items matters more than the space they take, such as the first few assignees on a card.

### Row limit

`max-rows` fits as many items as the available width allows within that many wrapped rows, with the count beside them. The list refits when its container resizes, and never changes height until its fitted rows do, so the content below stays in place. Drag the handle to see it refit.

`limit` and `max-rows` combine: the fit never shows more than `limit` items. Items should keep their own width, since an item that grows to fill its row can't be measured.

### In a table

In a table cell, flex row or grid track, the list asks for the width of its items on one row and can shrink down to the count, so the column sizes as if nothing were omitted. In a flex row, give the list room to grow, for example with `flex: 1`.

### Collapse from the start

`collapse-from="start"` keeps the last items and places the count before them, for sequences where the most recent entries matter most.

### Custom count

An element in the `count` slot replaces the default count while items are omitted. It gets no generated content: listen for `tp-overflow-change` and read `hiddenCount` and `hiddenItems` to fill it. Here the count is a Button that opens a Popover with the omitted labels. The count needs a box of its own, so the Popover is wrapped in a span, and it must state the number of omitted items in its text or accessible name.

<Preview
  title="Custom count"
  align="stretch"
  code={`<div style="max-inline-size:22rem;margin-inline:auto;inline-size:100%">
  <tp-overflow-list id="overflow-list-skills" max-rows="1">
    <tp-badge variant="outline">Design systems</tp-badge>
    <tp-badge variant="outline">Accessibility</tp-badge>
    <tp-badge variant="outline">TypeScript</tp-badge>
    <tp-badge variant="outline">Figma</tp-badge>
    <tp-badge variant="outline">Motion</tp-badge>
    <tp-badge variant="outline">User research</tp-badge>
    <tp-badge variant="outline">Prototyping</tp-badge>
    <span slot="count">
      <tp-popover label="More skills">
        <tp-button slot="trigger" id="overflow-list-skills-button" variant="outline" size="xs" aria-label="More skills"></tp-button>
        <ul id="overflow-list-skills-more" style="margin:0;padding-inline-start:var(--tp-space-4)"></ul>
      </tp-popover>
    </span>
  </tp-overflow-list>
</div>`}
  script={`await customElements.whenDefined('tp-overflow-list');
const list = document.getElementById('overflow-list-skills');
const button = document.getElementById('overflow-list-skills-button');
const more = document.getElementById('overflow-list-skills-more');
const update = () => {
  const labels = list.hiddenItems.map((item) => item.textContent.trim());
  button.textContent = \`+\${labels.length}\`;
  button.setAttribute('aria-label', \`\${labels.length} more skills\`);
  more.replaceChildren(...labels.map((label) => Object.assign(document.createElement('li'), { textContent: label })));
};
list.addEventListener('tp-overflow-change', update);
update();`}
/>

To change only the text of the default count, set `messages` with `count` (visible, `+N`) and `countLabel` (accessible, `N more`); each is text or a function of the omitted and total counts.
