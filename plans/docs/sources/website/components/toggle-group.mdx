## Usage

Put `tp-toggle` elements with unique `value`s inside the group. The selection is always an ordered list of values, in both modes, so `default-value` takes a JSON array. Give the group a `label`; it is one tab stop and arrow keys move between items without selecting.

### Multiple selection

`multiple` lets each item toggle independently, as in a formatting toolbar. Icon-only items need an `aria-label`, and an `icon-*` size on the group makes them square.

### Spacing

`spacing` is the gap in spacing units (default 2). Zero joins the items into one segmented control with shared seams.

### Orientation and size

The group's `size` and `variant` override the items' own. `size` takes the Button's set: `xs`, `sm`, the default and `lg` for text, and the square `icon-xs`, `icon-sm`, `icon` and `icon-lg` for icon-only items. `orientation="vertical"` stacks the items and switches arrow navigation to Up and Down.

### Rich items

Items can hold more than a word, such as a sample above its name. Reshape an item through its `partContracts`: here `styleHook` stacks the content and gives each item its own weight. A Field names the group, and its description reports the selection.

<Preview
  title="Font weight"
  code={`<tp-field label="Heading weight" style="inline-size:auto">
  <tp-toggle-group id="toggle-group-weight" variant="outline" size="lg" default-value='["medium"]'>
    <tp-toggle value="light" data-weight="300" aria-label="Light"><span aria-hidden="true">Aa</span><span>Light</span></tp-toggle>
    <tp-toggle value="regular" data-weight="400" aria-label="Regular"><span aria-hidden="true">Aa</span><span>Regular</span></tp-toggle>
    <tp-toggle value="medium" data-weight="500" aria-label="Medium"><span aria-hidden="true">Aa</span><span>Medium</span></tp-toggle>
    <tp-toggle value="bold" data-weight="700" aria-label="Bold"><span aria-hidden="true">Aa</span><span>Bold</span></tp-toggle>
  </tp-toggle-group>
  <span slot="description">Headings use <strong id="toggle-group-weight-output">Medium</strong></span>
</tp-field>`}
  script={`const group = document.querySelector('#toggle-group-weight');
const output = document.querySelector('#toggle-group-weight-output');
await customElements.whenDefined('tp-toggle');
for (const item of group.querySelectorAll('tp-toggle')) {
  item.partContracts = {
    toggle: { styleHook: { 'block-size': 'auto', 'padding-block': 'var(--tp-space-2)' } },
    'toggle-content': { styleHook: { 'flex-direction': 'column', 'font-weight': item.dataset.weight } },
  };
}
group.addEventListener('tp-value-change', (event) => {
  if (event.target !== group) return;
  const [value] = event.detail.value;
  if (!value) {
    event.preventDefault();
    return;
  }
  output.textContent = group.querySelector(\`tp-toggle[value="\${value}"]\`).getAttribute('aria-label');
});`}
/>

### Keeping one selected

In single mode, pressing the selected item clears the selection. When an empty selection makes no sense, cancel that proposal in `tp-value-change`.

<Preview
  title="Required choice"
  code={`<div style="display:grid;gap:var(--tp-space-3);justify-items:center">
  <tp-toggle-group id="toggle-group-plan" label="Billing period" variant="outline" spacing="0" default-value='["yearly"]'>
    <tp-toggle value="monthly">Monthly</tp-toggle>
    <tp-toggle value="yearly">Yearly</tp-toggle>
  </tp-toggle-group>
  <output id="toggle-group-plan-output" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">$96 per seat, billed yearly</output>
</div>`}
  script={`const group = document.querySelector('#toggle-group-plan');
const output = document.querySelector('#toggle-group-plan-output');
group.addEventListener('tp-value-change', (event) => {
  const [period] = event.detail.value;
  if (!period) {
    event.preventDefault();
    return;
  }
  output.textContent = period === 'yearly' ? '$96 per seat, billed yearly' : '$10 per seat, billed monthly';
});`}
/>

### Disabled

<Preview
  title="Disabled items"
  code={`<tp-toggle-group label="Export format" variant="outline" default-value='["csv"]'>

Arrow navigation skips disabled items. `disabled` on the group disables every item while keeping each item's own setting for later.
