## Usage

Autocomplete's value is the text itself: picking a suggestion replaces the text, and a form receives whatever is typed. When the value must be one of the items, use Select with `searchable` instead. Supply items as `<option>` children, and label the field with `tp-field` or `label`.

### Matching

<Preview
  title="Prefix matching"
  align="stretch"
  code={`<tp-field label="Country" description="Type the start of each word: un st" style="inline-size:100%;inline-size:100%;max-inline-size:22rem;margin-inline:auto">
  <tp-autocomplete style="inline-size:100%" matching="prefix" placeholder="Search countries">
    <option>United Kingdom</option>
    <option>United States</option>
    <option>United Arab Emirates</option>
    <option>South Africa</option>
    <option>South Korea</option>
    <option>New Zealand</option>
  </tp-autocomplete>
</tp-field>`}
/>

The default `fuzzy` matching ranks results by relevance and tolerates typos, so "rasberry" still finds Raspberry. `prefix`, `contains` and `exact` keep the items in their given order and suit codes, names and lists where a typo match would be noise. Matched text is highlighted in every mode.

`completion-mode="both"` fills in the highlighted suggestion as you type, selecting the completed part so typing continues naturally. `auto-highlight` highlights the first suggestion, so Enter accepts it. `show-clear` adds a clear button.

### Keywords

<Preview
  title="Searching hidden fields"
  align="stretch"
  code={`<tp-field label="Command" description="Try: invoice, teammate, dark" style="inline-size:100%;inline-size:100%;max-inline-size:22rem;margin-inline:auto">
  <tp-autocomplete style="inline-size:100%" id="autocomplete-commands" placeholder="Search commands"></tp-autocomplete>
</tp-field>`}
  script={`const commands = [
  { value: 'Create invoice', keywords: ['bill', 'billing', 'payment'] },
  { value: 'Invite member', keywords: ['teammate', 'user', 'people'] },
  { value: 'Change theme', keywords: ['dark', 'light', 'appearance'] },
  { value: 'Export data', keywords: ['csv', 'download', 'backup'] },
];
await customElements.whenDefined('tp-autocomplete');
const autocomplete = document.querySelector('#autocomplete-commands');
autocomplete.items = commands.map(({ value }) => value);
autocomplete.matchFields = (item) => commands.find((command) => command.value === item)?.keywords ?? [];`}
/>

The `items` property accepts strings, records and groups when the list comes from data. `matchFields` adds searchable text that is never displayed, such as aliases or keywords. Results can also come from a server through the `source` property.

### Records

<Preview
  title="Ranking over several fields"
  align="stretch"
  code={`<tp-field label="Help center" description="Try: refund, password, seats" style="inline-size:100%;max-inline-size:22rem;margin-inline:auto">
  <tp-autocomplete style="inline-size:100%" id="autocomplete-articles" placeholder="Search articles"></tp-autocomplete>
</tp-field>`}
  script={`import { createIndexSource } from '@tweakpad/ui';

const articles = [
  { title: 'Request a refund', summary: 'Refunds for annual plans within 30 days of purchase.' },
  { title: 'Reset your password', summary: 'Get a sign-in link by email when you forget your password.' },
  { title: 'Add or remove seats', summary: 'Change how many members your plan pays for.' },
  { title: 'Download invoices', summary: 'Receipts and refund credit notes for every billing period.' },
  { title: 'Turn on two-step sign-in', summary: 'Protect your password with an authenticator app.' },
];
await customElements.whenDefined('tp-autocomplete');
const autocomplete = document.querySelector('#autocomplete-articles');
autocomplete.itemToText = (article) => article.title;
autocomplete.source = createIndexSource(articles, {
  fields: ['title', 'summary'],
  boost: { title: 3 },
  extract: (article, field) => article[field],
});`}
/>

`createIndexSource()` builds the same typo-tolerant index the component uses, over any records you pass. Here it searches each article's title and summary but weights the title three times, so "refund" lists *Request a refund* before the invoices article that only mentions it. `itemToText` names each record in the list and the field.

### Server search

<Preview
  title="Search source"
  align="stretch"
  code={`<tp-field label="Departure airport" description="Results arrive after a simulated 600 ms request." style="inline-size:100%;max-inline-size:22rem;margin-inline:auto">
  <tp-autocomplete style="inline-size:100%" id="autocomplete-server" search-delay="250" placeholder="City or airport code"></tp-autocomplete>
</tp-field>`}
  script={`const airports = [
  'Amsterdam Schiphol (AMS)', 'Barcelona El Prat (BCN)', 'Berlin Brandenburg (BER)',
  'Dublin (DUB)', 'Frankfurt (FRA)', 'Lisbon Humberto Delgado (LIS)', 'London Heathrow (LHR)',
  'London Gatwick (LGW)', 'Madrid Barajas (MAD)', 'Milan Malpensa (MXP)', 'Munich (MUC)',
  'Paris Charles de Gaulle (CDG)', 'Rome Fiumicino (FCO)', 'Vienna (VIE)', 'Zurich (ZRH)',
];
await customElements.whenDefined('tp-autocomplete');
document.querySelector('#autocomplete-server').source = {
  // Stands in for fetch('/api/airports?q=' + query, { signal }).
  search(query, { signal }) {
    return new Promise((resolve, reject) => {
      const timer = setTimeout(() => {
        const text = query.trim().toLowerCase();
        resolve(airports.filter((airport) => airport.toLowerCase().includes(text)).slice(0, 8));
      }, 600);
      signal.addEventListener('abort', () => {
        clearTimeout(timer);
        reject(signal.reason);
      });
    });
  },
};`}
/>

A source's `search(query, context)` returns results directly or as a promise, in the order they should appear. `search-delay` waits for a pause in typing, and each new query aborts the previous one through `context.signal`. While a request is pending the list is marked busy and keeps the previous suggestions, or shows a loading row when there are none. `createRequestSource()` wraps a URL and a response mapper into a source for you.

### Forms

<Preview
  title="In a form"
  align="stretch"
  code={`<form id="autocomplete-form" style="display:grid;gap:var(--tp-space-4);inline-size:100%;max-inline-size:22rem;margin-inline:auto">
  <tp-field label="Job title">
    <tp-autocomplete style="inline-size:100%" name="title" required submit-on-item-click placeholder="e.g. Product designer">
      <option>Product designer</option>
      <option>Product manager</option>
      <option>Frontend engineer</option>
      <option>Data analyst</option>
    </tp-autocomplete>
  </tp-field>
  <tp-button type="submit" style="justify-self:start">Save profile</tp-button>
  <output id="autocomplete-form-result" style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)"></output>
</form>`}
  script={`const form = document.querySelector('#autocomplete-form');
form.addEventListener('submit', (event) => {
  event.preventDefault();
  form.querySelector('#autocomplete-form-result').value = 'Saved: ' + new FormData(form).get('title');
});`}
/>

With `name`, the form receives the text, including text that matches no suggestion. `required` requires text. Enter with nothing highlighted submits the form, and Escape first closes the suggestions, then clears the text. `submit-on-item-click` submits as soon as a suggestion is picked, which suits a search box that has nothing else to fill in.
