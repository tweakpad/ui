## Usage

One group owns the sizes of its panels. Panels and handles must be direct children in order, and every pointer, keyboard and programmatic change goes through the same constraint solver. Give the group a block size; panels share its space along `orientation`. Nest another group inside a panel for the second axis, as above.

### Sizes and limits

`default-size`, `min-size` and `max-size` take percentages, pixels or other lengths; a unitless value is a percentage. Double-clicking a handle restores its panel's default size.

### Collapsible panels

A `collapsible` panel snaps to `collapsed-size` when dragged below its minimum, and Enter on its handle toggles it. `collapse()`, `expand()` and `isCollapsed()` drive it from your own controls.

### Layout changes

`tp-layout-change` reports each committed layout as panel IDs and percentages, and `tp-layout-change-complete` fires once when a drag settles. Save layouts from the settled event, keyed by stable panel IDs.

### Controlled sizes

Set `sizes` to own the layout, in panel order, and accept each proposal in `onSizesChange` by assigning `event.detail.value` back; ignoring it keeps the previous layout. Strings are percentages and numbers are pixels. Like the persistence adapter, `sizes` must be set before the group connects.

  title="Layout presets"
  align="stretch"

      <div style="padding:var(--tp-space-4);font-size:var(--tp-text-sm)">checkout.tsx</div>
    </tp-resizable-panel>
    <tp-resizable-handle label="Resize code" with-handle></tp-resizable-handle>
    <tp-resizable-panel id="resizable-controlled-preview" min-size="15%">

  script={`// sizes must be set before the group first connects, so this demo swaps in a fresh copy.
await customElements.whenDefined('tp-resizable-panel-group');
const authored = document.querySelector('#resizable-controlled');
const group = authored.cloneNode(true);
group.sizes = ['50%', '50%'];

  if (!event.defaultPrevented) group.sizes = event.detail.value;
};

document.querySelector('#resizable-preset-split').addEventListener('click', () => {
  group.sizes = ['50%', '50%'];
});
document.querySelector('#resizable-preset-focus').addEventListener('click', () => {
  group.sizes = ['80%', '20%'];
});`}

### Saved layout

Give the group a `persistence-key` and a `persistenceAdapter` with `load(key)` and `save(key, layout)`, and it restores the saved layout on connect and saves each settled one. The library has no storage policy of its own, and the adapter must be in place before the group connects.

<Preview
  title="Persisted sizes"
  align="stretch"
  code={`<div style="display:grid;gap:var(--tp-space-3)">
  <tp-resizable-panel-group id="resizable-saved" persistence-key="docs-mail-layout" style="block-size:10rem;border:var(--tp-border-width) solid var(--tp-border);border-radius:var(--tp-radius-lg)">
    <tp-resizable-panel id="resizable-saved-folders" default-size="25%" min-size="15%">
      <div style="padding:var(--tp-space-4);font-size:var(--tp-text-sm)">Folders</div>
    </tp-resizable-panel>
    <tp-resizable-handle label="Resize folders" with-handle></tp-resizable-handle>
    <tp-resizable-panel id="resizable-saved-messages" min-size="30%">
      <div style="padding:var(--tp-space-4);font-size:var(--tp-text-sm)">Messages</div>
    </tp-resizable-panel>
  </tp-resizable-panel-group>
  <span style="color:var(--tp-muted-foreground);font-size:var(--tp-text-sm)">Drag the handle, then press Refresh or reload the page.</span>
</div>`}
  script={`// The adapter must be set before the group first connects, so this demo swaps in a fresh copy.
await customElements.whenDefined('tp-resizable-panel-group');
const authored = document.querySelector('#resizable-saved');
const group = authored.cloneNode(true);
group.persistenceAdapter = {
  load: (key) => {
    try {
      return JSON.parse(localStorage.getItem(key) ?? 'null');
    } catch {
      return null;
    }
  },
  save: (key, layout) => {
    try {
      localStorage.setItem(key, JSON.stringify(layout));
    } catch {}
  },
};
authored.replaceWith(group);`}
/>
