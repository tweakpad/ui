## Architecture and reuse

- Component folder and responsibility boundaries: `src/widgets/color-picker/` — `color-picker.ts` (host: lanes, composition, event translation, form/Field, recents, eyedropper, popup forwarding), `model.ts` (float working-space state, channel edit, format switch, alpha policy, sticky HSV), `dimensions.ts` (per-format descriptors, `stepForKey`), `gradients.ts`, `recent.ts`, `eyedropper.ts`, `strings.ts`, `types.ts`, `styles.ts` (structure only), `surfaces/` (`surface-element.ts` base, `area.ts`, `wheel.ts`, `triangle.ts`, `geometry.ts`, `paint.ts`), `views/` (render helpers `sliders-view.ts`, `fields-row.ts`, `swatches-view.ts`, `schemes-view.ts`), `color/` (framework-free math: `types`, `named`, `convert`, `parse`, `serialize`, `channels`, `gamut`, `equality`, `harmony`, `scheme`, `index`), tests beside each module. Shared: `src/foundation/pointer-drag.ts`, `src/foundation/canvas-surface.ts`, `src/icons/pipette.ts`, `src/icons/wand-sparkles.ts`, `src/presentation/families/color-picker.ts`, `src/presentation/recipes/color-picker.ts`.
- Supported exports / registration / constituent API impact: `@tweakpad/ui/widgets` exports `TpColorPicker`, the three surface classes, types and the color module API; `@tweakpad/ui/register/widgets` defines `tp-color-picker` (dependencies recursively); main entries untouched. No existing component API changes; `documentation-examples.ts` gains an optional `registerImports` argument (existing callers unchanged).
- Public vocabulary / tokens / parts / presentation review: event names follow `tp-<noun>-change` / `-commit`; reasons from `foundation/types.ts` `ChangeReason`; axes `size` (canonical values), `picker` and `shape` (component-specific values with explicit meaning, CL §10.6); markers from the state vocabulary; part slots `color-picker-*`; one spacing variable `--_tp-color-picker-space` plus derived private variables; tokens `--tp-background`, `--tp-muted`, `--tp-foreground`, `--tp-border`, `--tp-input`, `--tp-ring`, `--tp-radius-*`, `--tp-space-*`, `--tp-control-height-*`, `--tp-target-size-min`, `--tp-shadow-*`, `--tp-duration-*`; no literal colors in recipes (value-domain paint arrives as inline custom properties).
