# Component implementation and evidence record: Easing editor (`tp-easing-editor`)

## Delivery and source record

- Component(s) / public identity: Easing editor, `tp-easing-editor` (`TpEasingEditor`), widget catalog kind `flattening-compound`; internal constituent elements `tp-easing-editor-graph` (render and input surface) and `tp-easing-editor-frames` (render surface), not catalog entries. New shared Foundation owners: `src/foundation/easing/` (curve records, notations, evaluation, sampling, CSS serialization) and `src/foundation/dimension-step.ts` (keyboard step model lifted from the color picker).
- Requested work / claim: complete widget. Parametric, Bézier (with overshoot), spring and custom curves; preset picker with name and curve thumbnail; compact (dialog) and extended layouts, the compact presets overlaying the graph with scrolling; export through adapters (CSS built in, others pluggable); optional duration control (default 0.01–1 s Slider); background preview of a shape (circle outline, circle fill, square) animating opacity, scale, rotation or displacement, replayed on each adjustment and on a play Button; compact frames bar of ticks. The graph presentation is designed for reuse by later curve widgets.
- Scope source: user instruction 2026-10-11 ("We need to create a new widget for handling and configuring easing curves … reused to later expand it to other usages that requires calibration by curves. Either parametric, bezier or custom curves … overshoot … preset selector … compact form or as a extended form … export it as CSS via adapter … time control … preview with a shape … frames visualizer"), with reference images 17–20 (overshoot graph with hatched band, frames ticks, preset grid with thumbnails, x1–y2 sliders). ## Architecture and reuse

- Component folder and responsibility boundaries: `src/widgets/easing-editor/`: `easing-editor.ts` (host: lanes, composition, commit model, part registration), `types.ts` (public types, strings interface), `strings.ts`, `styles.ts` (structure), `parameters.ts` (parameter definitions per kind), `presets.ts` (built-in table), `adapters.ts` (CSS adapter + interface), `preview.ts` (keyframes per property/shape), `views/presets.ts` (preset groups and thumbnails), `surfaces/graph.ts`, `surfaces/frames.ts`, `surfaces/geometry.ts` (range, mapping, path building) with tests. `src/foundation/easing/`: `types.ts`, `parse.ts`, `serialize.ts`, `evaluate.ts`, `parametric.ts`, `spring.ts`, `sample.ts`, `convert.ts`, `css.ts`, `index.ts` with tests. `src/foundation/dimension-step.ts` (keyboard step model) consumed by the color picker's `dimensions.ts` (delegation) and the graph surface.

The color picker keeps its exports; `dimensions.ts` re-exports the foundation step model.
